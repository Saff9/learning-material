## How to use

1. Open a section from the sidebar (or the table above).
2. Use the **search** icon in the top bar to jump to any note.
3. Code blocks have a copy button.
4. Dark/light mode toggle is in the top-right.

All content is served from this machine at `http://localhost:8000`.
