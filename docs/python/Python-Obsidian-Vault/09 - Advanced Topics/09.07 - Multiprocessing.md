## Deep Dive: Why Multiprocessing?
Because of the Global Interpreter Lock (GIL), traditional Python threads cannot execute CPU-bound code on multiple cores simultaneously. The `multiprocessing` module bypasses the GIL by spawning entirely new Python interpreter processes. Each process has its own memory space and its own GIL.

## Modern Process Pool Executor

Just like with threading, the modern approach to multiprocessing utilizes `concurrent.futures`.

```python
import math
import time
from concurrent.futures import ProcessPoolExecutor

def compute_heavy_task(n: int) -> float:
    """
    A CPU-bound task simulating heavy computation.
    """
    result: float = 0.0
    for i in range(n):
        result += math.sqrt(i)
    return result

def main() -> None:
    workloads: list[int] = [5_000_000, 6_000_000, 7_000_000]
    
    start_time: float = time.perf_counter()
    
    with ProcessPoolExecutor(max_workers=3) as executor:
        results: list[float] = list(executor.map(compute_heavy_task, workloads))
        
    end_time: float = time.perf_counter()
    
    print(f"Results: {results}")
    print(f"Completed in {end_time - start_time:.2f} seconds")

if __name__ == "__main__":
    main()
```

## Using Functools and Itertools

When mapping functions across processes, the function must take a single argument. If your function takes multiple arguments, `functools.partial` is highly effective. 

Additionally, `itertools.batched` (Python 3.12+) is useful to send large data in chunks to minimize inter-process communication (IPC) overhead.

```python
import math
from functools import partial
import itertools
from concurrent.futures import ProcessPoolExecutor

def power_calculator(base: int, exponent: int) -> int:
    """Calculates power."""
    return base ** exponent

def process_chunk(chunk: tuple[int, ...], exponent: int) -> list[int]:
    """Processes a batch of numbers."""
    return [power_calculator(n, exponent) for n in chunk]

def main() -> None:
    data: range = range(1, 1000)
    
    # 1. Create a partial function locking the exponent to 3 (cubes)
    chunk_processor = partial(process_chunk, exponent=3)
    
    # 2. Chunk data using Python 3.12+ batched
    chunks = itertools.batched(data, 100)
    
    with ProcessPoolExecutor() as pool:
        # map applies the partial function to each chunk
        results: list[list[int]] = list(pool.map(chunk_processor, chunks))
        
    # Flatten results using itertools
    flat_results: list[int] = list(itertools.chain.from_iterable(results))
    print(f"First 10 cubes: {flat_results[:10]}")

if __name__ == "__main__":
    main()
```

## Sharing Data Between Processes

Because processes have isolated memory, sharing state requires specialized objects like `multiprocessing.Manager`.

```python
import multiprocessing
from multiprocessing.managers import DictProxy
import time

def worker(shared_dict: DictProxy, key: str, value: int) -> None:
    """Updates a shared dictionary in a separate process."""
    print(f"Process working on {key}...")
    time.sleep(0.5)
    shared_dict[key] = value ** 2

def main() -> None:
    with multiprocessing.Manager() as manager:
        shared_dict: DictProxy = manager.dict()
        
        processes: list[multiprocessing.Process] = []
        for i, char in enumerate(["A", "B", "C", "D"], start=1):
            p = multiprocessing.Process(target=worker, args=(shared_dict, char, i))
            processes.append(p)
            p.start()
            
        for p in processes:
            p.join()
            
        print(f"Final shared dictionary state: {dict(shared_dict)}")

if __name__ == "__main__":
    main()
```
