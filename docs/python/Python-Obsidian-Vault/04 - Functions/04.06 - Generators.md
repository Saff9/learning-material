## Basic Generator

Generators allow you to define an iterative algorithm by maintaining state automatically. They are lazy, meaning they evaluate values only when requested.

```python
from typing import Generator

def count_up_to(n: int) -> Generator[int, None, None]:
    """Generates integers from 1 up to n."""
    count: int = 1
    while count <= n:
        yield count
        count += 1

if __name__ == "__main__":
    for num in count_up_to(5):
        print(num)  # 1, 2, 3, 4, 5
```
*Note: `Generator[YieldType, SendType, ReturnType]` is the strict annotation format.*

## Generator Expressions vs List Comprehensions

Generators are highly memory efficient compared to lists.

```python
import tracemalloc

def profile_memory() -> None:
    """Profiles memory difference between list comprehensions and generators."""
    tracemalloc.start()
    
    # List comprehension (creates full list in memory)
    squares_list: list[int] = [x**2 for x in range(1_000_000)]
    current, peak = tracemalloc.get_traced_memory()
    print(f"List comprehension memory: {peak / 10**6:.2f} MB")
    
    tracemalloc.reset_peak()
    
    # Generator expression (lazy evaluation)
    squares_gen = (x**2 for x in range(1_000_000))
    current, peak = tracemalloc.get_traced_memory()
    print(f"Generator memory: {peak / 10**6:.2f} MB")
    
    tracemalloc.stop()

if __name__ == "__main__":
    profile_memory()
```

## `itertools` Deep Dive

The `itertools` module provides advanced tools to consume and combine generators.

```python
import itertools
from typing import Iterator

def itertools_example() -> None:
    # 1. Infinite counter
    counter: Iterator[int] = itertools.count(start=10, step=2)
    print(list(itertools.islice(counter, 5)))  # [10, 12, 14, 16, 18]

    # 2. Chaining generators
    gen1 = (x for x in range(3))
    gen2 = (x for x in range(3, 6))
    chained: Iterator[int] = itertools.chain(gen1, gen2)
    print(list(chained))  # [0, 1, 2, 3, 4, 5]

if __name__ == "__main__":
    itertools_example()
```

## Asynchronous Generators Deep Dive

With modern async Python, you can yield values asynchronously.

```python
import asyncio
from typing import AsyncGenerator

async def async_ticker(delay: float, ticks: int) -> AsyncGenerator[int, None]:
    """Yields an incrementing tick count every `delay` seconds."""
    for i in range(ticks):
        await asyncio.sleep(delay)
        yield i

async def main() -> None:
    # Use async for to consume an async generator
    async for tick in async_ticker(0.5, 3):
        print(f"Tick: {tick}")

if __name__ == "__main__":
    asyncio.run(main())
```

## Advanced Generator Methods (`send`, `close`, `throw`)

```python
from typing import Generator

def echo() -> Generator[str, str, None]:
    """A coroutine-style generator that receives values via send()."""
    received: str = yield "Started"
    while True:
        try:
            received = yield f"Echo: {received}"
        except ValueError:
            received = yield "Value Error Handled!"

if __name__ == "__main__":
    e = echo()
    print(next(e))               # Prime the generator: 'Started'
    print(e.send("Hello"))       # 'Echo: Hello'
    print(e.throw(ValueError))   # 'Value Error Handled!'
    e.close()                    # Closes the generator
```

## Python GIL and PEP 703 (Free-Threading)

Generators traditionally execute within Python's Global Interpreter Lock (GIL). However, with PEP 703 (making the GIL optional in Python 3.13+), generators running in different threads can truly run in parallel without blocking each other. This is highly beneficial for data processing pipelines that utilize multiple parallel generators consuming CPU-heavy tasks.

## 🧪 Practice

### Exercise 1: File Reader Generator
```python
from typing import Generator
import os

def read_lines(filename: str) -> Generator[str, None, None]:
    """Yields stripped lines from a file sequentially."""
    if not os.path.exists(filename):
        return
    with open(filename, 'r', encoding='utf-8') as f:
        for line in f:
            yield line.strip()
```

### Exercise 2: Paged Data
```python
from typing import Generator, Any

def paginate(items: list[Any], page_size: int) -> Generator[list[Any], None, None]:
    """Yields chunks of a list sequentially."""
    for i in range(0, len(items), page_size):
        yield items[i:i + page_size]

if __name__ == "__main__":
    for page in paginate(list(range(25)), 10):
        print(page)
```
