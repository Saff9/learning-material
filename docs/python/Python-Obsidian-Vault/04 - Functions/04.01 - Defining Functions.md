## Basic Function Definition

In modern Python, it is highly recommended to use **type annotations** and **docstrings**.

```python
def greet() -> None:
    """
    Prints a simple greeting message.
    """
    print("Hello, World!")

greet()
```

## Functions with Parameters

```python
def greet_person(name: str) -> None:
    """
    Greets a person by their name.
    
    Args:
        name (str): The name of the person to greet.
    """
    print(f"Hello, {name}!")

greet_person("Alice")
```

## Return Values

```python
def add(a: int | float, b: int | float) -> int | float:
    """
    Adds two numbers and returns the result.
    """
    return a + b

result: int | float = add(3, 5)
print(result)  # 8
```

## Multiple Return Values

In Python, returning multiple values returns a `tuple`.

```python
def get_min_max(numbers: list[int]) -> tuple[int, int]:
    """
    Returns the minimum and maximum values from a list of numbers.
    """
    return min(numbers), max(numbers)

minimum: int
maximum: int
minimum, maximum = get_min_max([3, 1, 4, 1, 5])
```

## Default Parameters

```python
def greet_with_default(name: str, greeting: str = "Hello") -> None:
    """
    Greets someone with a customizable or default greeting.
    """
    print(f"{greeting}, {name}!")

greet_with_default("Alice")           # Hello, Alice!
greet_with_default("Bob", "Hi")       # Hi, Bob!
```

## Arbitrary Arguments (*args, **kwargs)

```python
from typing import Any

def sum_all(*numbers: int) -> int:
    """
    Sums an arbitrary number of positional arguments.
    """
    return sum(numbers)

print(sum_all(1, 2, 3, 4))  # 10

def print_info(**kwargs: Any) -> None:
    """
    Prints arbitrary keyword arguments.
    """
    for key, value in kwargs.items():
        print(f"{key}: {value}")

print_info(name="Alice", age=25)
```

## ⚡ Advanced: Async/Await Deep Dive

Python supports asynchronous programming to handle I/O-bound tasks concurrently without blocking the main thread.

```python
import asyncio

async def fetch_data(id: int) -> dict[str, str]:
    """
    Simulates an asynchronous data fetch operation.
    """
    print(f"Task {id}: Starting fetch...")
    await asyncio.sleep(1)  # Simulate network delay
    print(f"Task {id}: Fetch complete.")
    return {"id": str(id), "data": "Sample Data"}

async def main_async() -> None:
    """
    Runs multiple fetch tasks concurrently using asyncio.gather.
    """
    # Create a list of tasks
    tasks = [fetch_data(i) for i in range(3)]
    
    # Run them concurrently in the event loop
    results: list[dict[str, str]] = await asyncio.gather(*tasks)
    print("All results:", results)

# Run the event loop
if __name__ == "__main__":
    asyncio.run(main_async())
```

## 🧠 Advanced: Python GIL & Free-threading (PEP 703)

The **Global Interpreter Lock (GIL)** has historically prevented multiple native threads from executing Python bytecodes at once. This meant CPU-bound tasks couldn't fully leverage multi-core processors using threading.
With **PEP 703 (Making the Global Interpreter Lock Optional in CPython)**, Python 3.13+ introduces experimental "free-threading" support. This evolution will allow multi-threaded Python functions to achieve true parallelism for CPU-bound tasks in the future, dramatically changing how we architect high-performance Python code.

    """Convert Celsius to Fahrenheit."""
    return (c * 9/5) + 32.0
