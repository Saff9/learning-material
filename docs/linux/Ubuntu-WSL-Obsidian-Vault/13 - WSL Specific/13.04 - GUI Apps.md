# GUI Apps in WSL

## 🎯 What You'll Learn
- Run Linux GUI apps in WSL
- Use Windows X server
- WSLg (built-in GUI)

---

## 🖥️ WSLg (Windows 11)

WSLg is built into Windows 11 and recent Windows 10:

```bash
# Just install GUI app and run
sudo apt install x11-apps
xeyes

# Or install full desktop
sudo apt install firefox
firefox

# Or install IDE
sudo apt install gimp
gimp
```

No configuration needed! It just works.

---

## 🖥️ Windows 10 / Manual X Server

Install VcXsrv or Xming on Windows, then:

```bash
# Set display
export DISPLAY=$(cat /etc/resolv.conf | grep nameserver | awk '{print $2}'):0

# Or
export DISPLAY=$(ip route | grep default | awk '{print $3}'):0

# Run GUI app
xeyes
```
