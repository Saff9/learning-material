## ⚙️ wsl.conf (Per-Distro)

Location: `/etc/wsl.conf`

```ini
[automount]
enabled = true
mountFsTab = true
root = /mnt/
options = "metadata,umask=22,fmask=11"

[network]
generateHosts = true
generateResolvConf = true

[interop]
enabled = true
appendWindowsPath = true

[user]
default = yourusername

[boot]
systemd = true
```

### Sections Explained

| Section | Purpose |
|---------|---------|
| automount | Windows drive mounting |
| network | Network configuration |
| interop | Windows interop |
| user | Default user |
| boot | Boot options |

---

## ⚙️ .wslconfig (Global)

Location: `%UserProfile%\.wslconfig` (Windows side)

```ini
[wsl2]
memory=8GB
processors=4
swap=2GB
swapFile=C:\temp\wsl-swap.vhdx
localhostForwarding=true
dnsTunneling=true
firewall=true
autoProxy=true
nestedVirtualization=true
```

### Options

| Option | Default | Description |
|--------|---------|-------------|
| memory | 50% of total | Max memory |
| processors | All cores | CPU cores |
| swap | 25% of memory | Swap size |
| localhostForwarding | true | Forward localhost |
| dnsTunneling | false | DNS tunneling |

## 🔄 Apply Changes

```powershell
# After editing config, restart WSL
wsl --shutdown
# Then reopen WSL
```
