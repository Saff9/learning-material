## 🔗 Pipes (|)

A **pipe** connects the stdout of one command to the stdin of another.

```bash
command1 | command2 | command3
```

```
stdin -> [command1] -> stdout -> stdin -> [command2] -> stdout -> stdin -> [command3] -> stdout -> terminal
```

### Simple Examples

```bash
# Count lines in a file
cat file.txt | wc -l
# Same as: wc -l file.txt

# Find running processes
ps aux | grep firefox

# Sort and remove duplicates
cat words.txt | sort | uniq

# View long output with less
ls -la /usr/bin | less

# Count files in directory
ls | wc -l
```

### Pipe vs Redirection

| Feature | Pipe (\|) | Redirection (> or <) |
|---------|-----------|---------------------|
| Connects | Command to command | Command to file |
| Data flow | Memory (fast) | Disk (slower) |
| Creates file | No | Yes |
| Use case | Chaining commands | Saving/loading files |

## 🔀 Process Substitution

Process substitution treats the output of a command as a file.

```bash
# Compare output of two commands
diff <(echo "line1\nline2") <(echo "line1\nline3")

# Use command output where a file is expected
wc -l <(ls /usr/bin)

# Both input and output
sort <(cat file1) > >(tee sorted.txt)
```

**Syntax:**
- `<(command)` — Output is readable as a file
- `>(command)` — Input is writable as a file

## 👥 Command Grouping

### Subshell ()

Commands run in a subshell (separate process):

```bash
# Group commands and redirect all output
(
    echo "Starting backup..."
    tar czf backup.tar.gz /home/user/documents
    echo "Backup complete!"
) > backup.log 2>&1

# Change directory temporarily
(cd /tmp && ls)  # Back to original directory after
```

### Current Shell {}

Commands run in current shell:

```bash
# Group commands and redirect
{
    echo "Line 1"
    echo "Line 2"
} > output.txt

# Must have spaces and semicolon/newline
{ echo "A"; echo "B"; } > file.txt
```

**Difference:**

```bash
# Subshell: variable changes don't affect parent
(x=5; echo $x)  # Prints 5
echo $x          # Empty (x not set in parent)

# Current shell: variable changes persist
{ x=5; echo $x; }  # Prints 5
echo $x             # Prints 5
```

## 📄 Here Documents and Here Strings

### Here Document (<<)

```bash
# Multi-line input to a command
cat << EOF
This is line 1
This is line 2
Home directory: $HOME
EOF

# With tab suppression (<<-)
cat <<- EOF
	This line has a tab
	This too
EOF
# Tabs are removed from output

# Without variable expansion (<< 'EOF')
cat << 'EOF'
$HOME won't be expanded
EOF
```

### Here String (<<<)

```bash
# Single line input
cat <<< "Hello World"

# Useful with grep
grep "pattern" <<< "This is a test pattern string"

# Compare with pipe
echo "test" | grep "es"
grep "es" <<< "test"  # Same result, no pipe needed
```

## 🎯 Advanced Pipe Examples

### Find Top 10 Largest Files

```bash
find /home -type f -exec ls -lh {} + | \
    awk '{ print $5 ": " $9 }' | \
    sort -rh | \
    head -10
```

### Monitor Log File in Real-time

```bash
tail -f /var/log/syslog | grep "error" | \
    while read line; do
        echo "$(date): $line" >> error.log
    done
```

### Process Multiple Files

```bash
# Find all .txt files, count lines in each
find . -name "*.txt" -print0 | \
    while IFS= read -r -d '' file; do
        lines=$(wc -l < "$file")
        echo "$lines: $file"
    done | sort -n
```

### Parallel Processing with xargs

```bash
# Process files in parallel (4 at a time)
find . -name "*.jpg" -print0 | \
    xargs -0 -P 4 -I {} convert {} {}.png
```

## 🧪 Practice

```bash
# 1. Count unique words in a file
cat file.txt | tr ' ' '\n' | sort | uniq -c | sort -nr

# 2. Find files modified in last 24 hours
find /var/log -mtime -1 -type f | xargs ls -lh

# 3. Compare two directory listings
diff <(ls dir1) <(ls dir2)

# 4. Create a script using here document
cat << 'SCRIPT' > myscript.sh
#!/bin/bash
echo "Hello from script"
SCRIPT
chmod +x myscript.sh

# 5. Process substitution with sort
sort -k2 <(ps aux) | head

# 6. Group commands with error handling
{
    echo "Starting..."
    false  # This fails
    echo "This won't print"
} || echo "Command group failed"
```
