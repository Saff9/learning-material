## 🏗️ Command Anatomy

```
command [options] [arguments]
```

```bash
ls -la /home
# │   │   │
# │   │   └── Argument: target directory
# │   └────── Options: -l (long), -a (all)
# └────────── Command: list directory
```

### Components

| Component | Description | Example |
|-----------|-------------|---------|
| **Command** | The program to run | `ls`, `cat`, `grep` |
| **Options** | Modify behavior | `-l`, `--help` |
| **Arguments** | Target of the command | `/home`, `file.txt` |

---

## ⚙️ Options (Flags)

### Short Options

Single letter, prefixed with `-`:

```bash
ls -l          # Long format
ls -a          # All files
ls -la         # Combined: long + all
ls -l -a       # Same as above
```

### Long Options

Word-based, prefixed with `--`:

```bash
ls --all       # Same as -a
ls --human-readable  # Same as -h
ls --color=auto      # With value
```

### Short vs Long

| Style | Example | Use Case |
|-------|---------|----------|
| Short | `ls -lah` | Quick typing, scripts |
| Long | `ls --all --human-readable` | Readability, scripts |

## 📥 Arguments

### Types of Arguments

```bash
# Single argument
cat file.txt

# Multiple arguments
cp file1.txt file2.txt /backup/

# Optional arguments
ls              # No argument = current directory
ls /home        # With argument

# Required arguments
mv file1 file2  # Both required
cd /home        # One required
```

### Positional vs Named

```bash
# Positional (order matters)
cp source.txt dest.txt

# Named (order doesn't matter)
find / -name "*.txt" -type f
#      ^ target    ^ name option   ^ type option
```

---

## 🔀 Order Matters

```bash
# Usually: options first, then arguments
cp -r -v source/ dest/

# Some commands accept options after arguments
cp source/ dest/ -rv

# But this is not universal — always check!
```

## 🎯 Common Syntax Patterns

### Pattern 1: Simple Command
```bash
command
# pwd, date, clear
```

### Pattern 2: Command + Options
```bash
command -options
# ls -la, ps aux
```

### Pattern 3: Command + Arguments
```bash
command argument
# cat file.txt, cd /home
```

### Pattern 4: Command + Options + Arguments
```bash
command -options arguments
# cp -r source/ dest/
# grep -i "pattern" file.txt
```

### Pattern 5: Command + Subcommand
```bash
command subcommand [options] [arguments]
# git status
# git commit -m "message"
# systemctl status ssh
# docker ps -a
```

## 🧪 Practice

```bash
# 1. Identify components
cp -r -v /home/user/docs /backup/
# Command: cp
# Options: -r (recursive), -v (verbose)
# Arguments: /home/user/docs, /backup/

# 2. Try different option styles
ls -lah
ls --all --human-readable
ls -l -a -h

# 3. Experiment with order
ls /tmp -la    # Works in bash
ls -la /tmp    # Preferred style

# 4. Multiple arguments
echo "Hello" "World" "!"

# 5. Command with subcommand
git --version
```
