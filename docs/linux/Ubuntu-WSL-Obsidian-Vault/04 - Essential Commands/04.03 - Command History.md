## 📜 Viewing History

```bash
# Show all history
history

# Show last 20 commands
history 20

# Show history with timestamps
HISTTIMEFORMAT="%Y-%m-%d %H:%M:%S " history
```

## 🔍 Searching History

### Interactive Search (Ctrl+R)

```bash
# Press Ctrl+R, then type to search
# (reverse-i-search)`grep': grep -r "pattern" .

# Press Ctrl+R again for next match
# Press Enter to execute
# Press Right arrow to edit
# Press Ctrl+C to cancel
```

### grep Search

```bash
# Search history for "apt"
history | grep apt

# Search with context
history | grep -C 2 "apt install"
```

## ⚡ History Expansion

### Special References

| Syntax | Meaning | Example |
|--------|---------|---------|
| `!!` | Last command | `sudo !!` |
| `!n` | Command number n | `!42` |
| `!-n` | nth most recent | `!-1` (same as !!) |
| `!string` | Last command starting with string | `!ls` |
| `!?string` | Last command containing string | `!?apt` |
| `!$` | Last argument of previous command | `mkdir dir && cd !$` |
| `!*` | All arguments of previous command | `echo !*` |
| `!:n` | nth argument of previous command | `echo !:2` |
| `!:0` | Command name only | `echo !:0` |

### Examples

```bash
# Run last command with sudo
apt update
sudo !!
# Same as: sudo apt update

# Use last argument
mkdir /very/long/path/to/new/directory
cd !$
# Same as: cd /very/long/path/to/new/directory

# Use first argument
cp file1.txt /backup/
ls !:1
# Same as: ls file1.txt

# Modify last command
ls *.txt
!!:s/txt/md/
# Same as: ls *.md
```

## ⚙️ History Configuration

Add to `~/.bashrc`:

```bash
# Don't store duplicates
export HISTCONTROL=ignoredups:erasedups

# Ignore specific commands
export HISTIGNORE="ls:cd:pwd:exit:history"

# Larger history
export HISTSIZE=10000
export HISTFILESIZE=20000

# Append, don't overwrite
shopt -s histappend

# Save after every command
export PROMPT_COMMAND="history -a; history -c; history -r; $PROMPT_COMMAND"

# Timestamp format
export HISTTIMEFORMAT="%Y-%m-%d %H:%M:%S "
```

## 🧪 Practice

```bash
# 1. View your history
history | tail -20

# 2. Search interactively
# Press Ctrl+R, type "apt"

# 3. Run last command with sudo
ls /root
sudo !!

# 4. Use last argument
touch /tmp/testfile.txt
ls -la !$

# 5. Run a specific history number
# First find a number: history | grep "something"
# Then: !42

# 6. Clear history
history -c
```
