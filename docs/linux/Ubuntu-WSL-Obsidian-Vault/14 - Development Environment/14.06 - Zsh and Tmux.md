## 🚀 1. Zsh (Z Shell) & Oh My Zsh

Zsh is a powerful shell that offers better autocompletion, globbing, and customization than standard Bash.

### Installation

```bash
# Install Zsh
sudo apt update && sudo apt install zsh -y

# Verify installation
zsh --version

# Set Zsh as your default shell
chsh -s $(which zsh)
```
*(You may need to restart your terminal or log out/log in for the default shell change to take effect).*

### Install Oh My Zsh

Oh My Zsh is a framework for managing your Zsh configuration.

```bash
sh -c "$(curl -fsSL https://raw.githubusercontent.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"
```

### Essential Zsh Plugins

Install these game-changing plugins:

1. **zsh-autosuggestions** (Suggests commands as you type based on history)
   ```bash
   git clone https://github.com/zsh-users/zsh-autosuggestions ${ZSH_CUSTOM:-~/.oh-my-zsh/custom}/plugins/zsh-autosuggestions
   ```
2. **zsh-syntax-highlighting** (Highlights commands as you type)
   ```bash
   git clone https://github.com/zsh-users/zsh-syntax-highlighting.git ${ZSH_CUSTOM:-~/.oh-my-zsh/custom}/plugins/zsh-syntax-highlighting
   ```

### 📄 Example `.zshrc` Configuration

Edit your `~/.zshrc`:

```bash
# Set theme (powerlevel10k is highly recommended, but 'robbyrussell' is default)
ZSH_THEME="robbyrussell"

# Plugins
plugins=(
  git
  zsh-autosuggestions
  zsh-syntax-highlighting
  colored-man-pages
  extract
)

source $ZSH/oh-my-zsh.sh

# Useful Aliases
alias c="clear"
alias update="sudo apt update && sudo apt upgrade -y"
alias ll="ls -la"
alias gs="git status"

# WSL Specific Aliases
alias winhome="cd /mnt/c/Users/your_windows_username"
alias explorer="explorer.exe"
```

## 🪟 2. Tmux (Terminal Multiplexer)

Tmux allows you to create multiple windows and panes within a single terminal window, and keeps sessions running in the background.

### Installation

```bash
sudo apt install tmux -y
```

### Core Concepts
- **Server**: Runs in the background, holds all sessions.
- **Session**: A collection of windows. You can detach from a session and re-attach later.
- **Window**: Like a tab in a web browser.
- **Pane**: A split within a window.

### 📄 Example `.tmux.conf` Configuration

Create or edit `~/.tmux.conf` for a massively improved experience:

```tmux
# Change prefix from 'Ctrl+B' to 'Ctrl+A' (Optional, many find it easier)
unbind C-b
set-option -g prefix C-a
bind-key C-a send-prefix

# Enable mouse mode (clickable windows, panes, resizable panes)
set -g mouse on

# Split panes using | and - for easier memory
bind | split-window -h
bind - split-window -v
unbind '"'
unbind %

# Switch panes using Alt-arrow without prefix
bind -n M-Left select-pane -L
bind -n M-Right select-pane -R
bind -n M-Up select-pane -U
bind -n M-Down select-pane -D

# Start window and pane numbering at 1 (default is 0)
set -g base-index 1
set -g pane-base-index 1
set-window-option -g pane-base-index 1
set-option -g renumber-windows on

# Reload config file
bind r source-file ~/.tmux.conf \; display "Config Reloaded!"

# Design changes (Status bar styling)
set -g status-bg black
set -g status-fg white
```

Apply the configuration:
```bash
tmux source-file ~/.tmux.conf
```

## ⚡ 3. The Ultimate WSL2 Workflow

1. **Start WSL** and automatically land in your preferred `Zsh`.
2. **Start a Tmux session**: `tmux new -s dev`
3. **Split your screen**: 
   - Code in Vim/Neovim on the left pane.
   - Run server/compile on the right pane.
4. **Detach**: Close your Windows Terminal window (the session keeps running!).
5. **Reattach**: Open WSL again and run `tmux a -t dev` to pick up exactly where you left off.
