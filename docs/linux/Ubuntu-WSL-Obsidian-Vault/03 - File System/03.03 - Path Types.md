## 📍 Absolute Paths

An **absolute path** starts from the root (`/`) and specifies the complete location.

```bash
/home/yourname/documents/file.txt
/etc/passwd
/usr/bin/python3
/var/log/syslog
```

**Characteristics:**
- Always starts with `/`
- Works from any directory
- Unambiguous
- Longer to type

---

## 📍 Relative Paths

A **relative path** starts from the current directory.

```bash
documents/file.txt      # In current directory
../config/settings.ini  # Parent directory
./script.sh             # Current directory (explicit)
images/logo.png         # Subdirectory
```

**Characteristics:**
- Does NOT start with `/`
- Depends on current directory
- Shorter to type
- Can be ambiguous

---

## 🔗 Special Path References

| Symbol | Meaning | Example |
|--------|---------|---------|
| `.` | Current directory | `cd ./subdir` |
| `..` | Parent directory | `cd ../..` |
| `~` | Home directory | `cd ~/projects` |
| `~username` | User's home | `cd ~root` |
| `-` | Previous directory | `cd -` |
| `/` | Root directory | `cd /` |

### Examples

```bash
# Current directory (rarely needed, but explicit)
cp file.txt ./backup/

# Parent directory
cd ..

# Two levels up
cd ../../..

# Home directory
cd ~
cd ~/documents

# Another user's home (if accessible)
cd ~otheruser

# Previous directory
cd -
```

## 🃏 Wildcards (Globbing)

| Pattern | Matches | Example |
|---------|---------|---------|
| `*` | Any characters (including none) | `*.txt` matches all .txt files |
| `?` | Single character | `file?.txt` matches file1.txt, fileA.txt |
| `[abc]` | Any character in brackets | `file[123].txt` |
| `[a-z]` | Range of characters | `file[a-z].txt` |
| `[!abc]` | Any character NOT in brackets | `file[!0-9].txt` |
| `{a,b,c}` | Any of the options | `file.{txt,md,json}` |
| `**` | Recursive match (bash 4+) | `**/*.txt` |

### Examples

```bash
# All text files
ls *.txt

# Files starting with 'a'
ls a*

# Single character files
ls file?.txt

# Numbered files
ls file[0-9].txt

# Multiple extensions
ls file.{txt,md,json}

# Recursive find (bash 4+)
shopt -s globstar
ls **/*.py
```

### Globbing vs Regex

| Feature | Globbing | Regex |
|---------|----------|-------|
| Used by | Shell (bash) | grep, sed, awk |
| `*` | Any characters | Zero or more of previous |
| `?` | Single character | Zero or one of previous |
| `.` | Literal dot | Any character |
| Context | Filename matching | Text matching |

## 🎯 Path Best Practices

### 1. Use Absolute Paths in Scripts

```bash
# Good: Script works from anywhere
#!/bin/bash
LOG_FILE="/var/log/myapp/app.log"

# Bad: Depends on where script is run from
LOG_FILE="../logs/app.log"
```

### 2. Use Variables for Paths

```bash
# Good: Easy to change
BASE_DIR="/opt/myapp"
LOG_DIR="$BASE_DIR/logs"
CONFIG_DIR="$BASE_DIR/config"

# Create directories
mkdir -p "$LOG_DIR" "$CONFIG_DIR"
```

### 3. Quote Paths with Spaces

```bash
# Good: Handles spaces
mkdir -p "/path/with spaces/directory"

# Bad: Breaks on spaces
mkdir -p /path/with spaces/directory
```

### 4. Use `realpath` for Absolute Paths

```bash
# Get absolute path
realpath ./relative/path

# Get absolute path with symlink resolution
realpath -e ./symlink
```

## 🧪 Practice

```bash
# 1. Create test structure
mkdir -p ~/path-test/{dir1,dir2,dir3}
touch ~/path-test/{file1.txt,file2.md,file3.log}
touch ~/path-test/dir1/{a.txt,b.txt,c.py}

# 2. Practice relative navigation
cd ~/path-test
cd dir1/../dir2
cd ../../..
pwd

# 3. Use wildcards
ls ~/path-test/*.txt
ls ~/path-test/file?.txt
ls ~/path-test/*.{txt,md}

# 4. Get absolute path
cd ~/path-test/dir1
realpath .
realpath ../file1.txt

# 5. Clean up
cd ~
rm -rf ~/path-test
```
