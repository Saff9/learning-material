## 🏗️ WSL2 Network Architecture

WSL2 runs in a lightweight VM with its own virtual network:

```
Windows Host
    |
    +-- WSL2 Virtual Switch
          |
          +-- eth0 (WSL2)
                |
                +-- Ubuntu
```

---

## 🔄 Accessing Windows from WSL

```bash
# Windows host IP
cat /etc/resolv.conf | grep nameserver

# Or use special hostname
ping host.docker.internal

# Access Windows localhost services
curl http://host.docker.internal:8080

# Access Windows files
/mnt/c/Users/YourName/
```

---

## 🔄 Accessing WSL from Windows

```bash
# WSL IP address
ip addr show eth0 | grep "inet "

# Or
hostname -I
```

From Windows:
```powershell
# SSH to WSL
ssh username@wsl-ip

# Access WSL web server
curl http://wsl-ip:3000
```

---

## 🔀 Port Forwarding

From PowerShell (admin):
```powershell
# Forward Windows port to WSL
netsh interface portproxy add v4tov4 listenport=8080 connectport=8080 connectaddress=<WSL-IP>

# View forwards
netsh interface portproxy show all

# Delete forward
netsh interface portproxy delete v4tov4 listenport=8080
```

## 🛠️ .wslconfig

Create `%UserProfile%\.wslconfig`:

```ini
[wsl2]
memory=8GB
processors=4
localhostForwarding=true
dnsTunneling=true
firewall=true
autoProxy=true
```
