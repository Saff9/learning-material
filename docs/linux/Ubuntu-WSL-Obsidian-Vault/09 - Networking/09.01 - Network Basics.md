## 🌐 IP Addresses

### IPv4
```bash
# Check your IP
ip addr
# or
hostname -I
```

Format: `192.168.1.100` (4 octets, 0-255)

### IPv6
```bash
# Check IPv6
ip -6 addr
```

Format: `2001:0db8:85a3::8a2e:0370:7334`

|------|---------|
| 22 | SSH |


## 📡 Protocols

| Protocol | Purpose |
|----------|---------|
| TCP | Reliable, connection-oriented |
| UDP | Fast, connectionless |
| HTTP | Web traffic |
| HTTPS | Encrypted web |
| SSH | Secure shell |
| FTP | File transfer |
| DNS | Domain name resolution |

## 🪟 WSL Networking

WSL2 uses a virtual network adapter:

```bash
# WSL2 IP address
ip addr show eth0

# Windows host IP (from WSL)
cat /etc/resolv.conf | grep nameserver

# Access Windows localhost from WSL
curl http://host.docker.internal:8080
```
