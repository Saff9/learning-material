---

## 🔑 Basic Connection

```bash
# Connect to server
ssh username@hostname

# Connect with port
ssh -p 2222 username@hostname

# Connect with key
ssh -i ~/.ssh/private_key username@hostname
```

---

## 🔐 SSH Keys

```bash
# Generate key pair
ssh-keygen -t ed25519 -C "your_email@example.com"

# Generate RSA key (older systems)
ssh-keygen -t rsa -b 4096

# Copy public key to server
ssh-copy-id username@hostname

# Or manually copy
cat ~/.ssh/id_ed25519.pub | ssh user@host "mkdir -p ~/.ssh && cat >> ~/.ssh/authorized_keys"
```

---

## ⚙️ SSH Config

```bash
# Edit config
nano ~/.ssh/config
```

Example:
```
Host myserver
    HostName 192.168.1.100
    User myuser
    Port 2222
    IdentityFile ~/.ssh/myserver_key
    ServerAliveInterval 60

Host github
    HostName github.com
    User git
    IdentityFile ~/.ssh/github_key
```

Usage:
```bash
ssh myserver
# Instead of: ssh -p 2222 -i ~/.ssh/myserver_key myuser@192.168.1.100
```

## 🔒 SSH Agent

```bash
# Start agent
eval "$(ssh-agent -s)"

# Add key
ssh-add ~/.ssh/id_ed25519

# List keys
ssh-add -l

# Remove all keys
ssh-add -D
```

## 🧪 Practice

```bash
# 1. Generate key
ssh-keygen -t ed25519 -f ~/.ssh/test_key

# 2. View public key
cat ~/.ssh/test_key.pub

# 3. Add to SSH agent
eval "$(ssh-agent -s)"
ssh-add ~/.ssh/test_key

# 4. Clean up
rm ~/.ssh/test_key ~/.ssh/test_key.pub
```
