## 📋 Script Template

```bash
#!/bin/bash
set -euo pipefail

# Strict mode:
# -e: Exit on error
# -u: Exit on undefined variable
# -o pipefail: Exit if any command in pipe fails

# Variables
readonly SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
readonly LOG_FILE="/var/log/myapp.log"

# Functions
log() {
    echo "[$(date '+%Y-%m-%d %H:%M:%S')] $*" | tee -a "$LOG_FILE"
}

cleanup() {
    log "Cleaning up..."
    # cleanup code
}

# Trap signals
trap cleanup EXIT

# Main logic
main() {
    log "Starting script..."
    # Your code here
    log "Script completed successfully"
}

# Run main
main "$@"
```

## 🔢 Exit Codes

| Code | Meaning |
|------|---------|
| 0 | Success |
| 1 | General error |
| 2 | Misuse of command |
| 126 | Command not executable |
| 127 | Command not found |
| 128+N | Fatal signal N |
| 130 | Ctrl+C (SIGINT) |
| 137 | SIGKILL |
| 143 | SIGTERM |

```bash
# Check exit code of last command
echo $?

# Set exit code
exit 0
exit 1
```

## 🛡️ Error Handling

```bash
#!/bin/bash
set -euo pipefail

# Check command success
if command -v git >/dev/null 2>&1; then
    echo "Git is installed"
else
    echo "Git not found" >&2
    exit 1
fi

# Or with && and ||
git --version || { echo "Git not found"; exit 1; }

# Catch errors in functions
my_function() {
    local file=$1
    if [ ! -f "$file" ]; then
        echo "Error: File not found: $file" >&2
        return 1
    fi
    cat "$file"
}
```

## ✅ Best Practices

1. **Always use `#!/bin/bash`**
2. **Use `set -euo pipefail`**
3. **Quote all variables**: `"$var"` not `$var`
4. **Use `readonly` for constants**
5. **Use `local` in functions**
6. **Check for required commands**
7. **Provide meaningful error messages**
8. **Use `trap` for cleanup**
9. **Log actions**
10. **Validate inputs**
