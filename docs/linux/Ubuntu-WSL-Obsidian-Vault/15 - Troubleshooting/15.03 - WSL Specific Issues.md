## 🎯 What You'll Learn

---

## 🔄 WSL Won't Start

```powershell
# Restart WSL
wsl --shutdown
wsl

# If still broken, restart LxssManager
# In PowerShell (Admin):
Restart-Service LxssManager

# Or restart computer
```

---

## 💾 Out of Disk Space

```bash
# Check WSL disk usage
du -sh / 2>/dev/null

# Compact WSL disk (Windows side)
# In PowerShell:
wsl --shutdown
# Then use diskpart or optimize-vhd
```

---

## 🐢 Slow Performance

```bash
# Check if accessing Windows files
cd /mnt/c && ls  # Slow
cd ~ && ls       # Fast

# Solution: Move projects to WSL filesystem
mv /mnt/c/Projects ~/projects
```

---

## 🔄 Reset WSL

```powershell
# Export first (backup)
wsl --export Ubuntu C:\backup\ubuntu.tar

# Unregister (deletes everything!)
wsl --unregister Ubuntu

# Reinstall
wsl --install -d Ubuntu

# Or import backup
wsl --import Ubuntu C:\WSL\Ubuntu C:\backup\ubuntu.tar
```
