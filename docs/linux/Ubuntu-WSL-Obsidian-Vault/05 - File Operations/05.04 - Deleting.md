# Deleting Files and Directories

## 🎯 What You'll Learn
- Remove files with rm
- Remove directories with rmdir and rm -r
- Securely delete with shred
- Understand the dangers and safety measures

---

## ⚠️ DANGER: Deletion is Permanent

> **In Linux, deleted files are gone.** There's no Recycle Bin for rm.
> Always double-check before deleting!

---

## 🗑️ rm — Remove Files

```bash
# Remove single file
rm file.txt

# Remove multiple files
rm file1.txt file2.txt file3.txt

# Remove with confirmation
rm -i file.txt

# Remove without confirmation (default)
rm -f file.txt

# Remove with verbose output
rm -v file.txt

# Remove files matching pattern
rm *.txt
rm file?.log
```

### rm Options

| Option | Meaning |
|--------|---------|
| `-i` | Interactive (prompt before each removal) |
| `-f` | Force (ignore non-existent files, never prompt) |
| `-v` | Verbose |
| `-r` or `-R` | Recursive (remove directories) |
| `-d` | Remove empty directories |

---

## 📁 rmdir — Remove Empty Directories

```bash
# Remove empty directory
rmdir empty_dir/

# Remove nested empty directories
rmdir -p parent/child/grandchild/

# Verbose
rmdir -v empty_dir/
```

> rmdir only removes **empty** directories. Use `rm -r` for non-empty ones.

---

## 🔥 rm -r — Remove Directories and Contents

```bash
# Remove directory and all contents
rm -r directory/

# Force remove (no prompts)
rm -rf directory/

# Interactive recursive remove
rm -ri directory/

# Verbose recursive remove
rm -rv directory/
```

### The Infamous rm -rf /

```bash
# NEVER RUN THIS:
rm -rf /

# This deletes EVERYTHING on your system!
# Some systems have protections, but don't rely on it.
```

**Safer alternatives in scripts:**
```bash
# Use trash-cli instead
sudo apt install trash-cli
trash-put file.txt

# Or move to a trash directory
mv file.txt ~/.local/share/Trash/files/
```

---

## 🔒 shred — Securely Delete

```bash
# Overwrite and delete file
shred -u file.txt

# Overwrite 10 times (default is 3)
shred -n 10 -u file.txt

# Overwrite with zeros after shredding
shred -uz file.txt

# Overwrite but don't delete
shred file.txt
# File still exists but data is overwritten
```

> **Note:** shred doesn't work well on modern SSDs due to wear-leveling. Use full disk encryption for true security.

## 🛡️ Safety Measures

### 1. Use Aliases

```bash
# Add to ~/.bashrc
alias rm='rm -i'
alias cp='cp -i'
alias mv='mv -i'
```

### 2. Use trash-cli

```bash
sudo apt install trash-cli

# Put in trash instead of deleting
trash-put file.txt

# List trashed files
trash-list

# Restore file
restore-trash

# Empty trash
trash-empty
```

### 3. Test with echo first

```bash
# See what would be deleted
echo rm *.txt

# If it looks right, run without echo
rm *.txt
```

### 4. Use find with -delete carefully

```bash
# Find and delete (be very careful!)
find . -name "*.tmp" -delete

# Better: preview first
find . -name "*.tmp"
# Then if correct:
find . -name "*.tmp" -delete
```

## 🧪 Practice

```bash
# 1. Create test files and directories
mkdir -p ~/delete-test/{keep,remove}
touch ~/delete-test/remove/{a,b,c}.txt
touch ~/delete-test/keep/important.txt

# 2. Remove a single file
rm ~/delete-test/remove/a.txt

# 3. Try to remove non-empty directory with rmdir
rmdir ~/delete-test/remove
# Fails: Directory not empty

# 4. Remove directory and contents
rm -r ~/delete-test/remove

# 5. Try rm -i
rm -i ~/delete-test/keep/important.txt
# Type 'n' to keep it

# 6. Clean up
rm -rf ~/delete-test
```
