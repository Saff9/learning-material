---

## 📊 diff — Line by Line Comparison

```bash
# Basic comparison
diff file1.txt file2.txt

# Side by side
sdiff file1.txt file2.txt

# Unified format (most common)
diff -u file1.txt file2.txt

# Context format
diff -c file1.txt file2.txt

# Ignore case
diff -i file1.txt file2.txt

# Ignore whitespace
diff -w file1.txt file2.txt

# Ignore blank lines
diff -B file1.txt file2.txt

# Show only differences (no context)
diff -q file1.txt file2.txt

# Compare directories
diff -r dir1/ dir2/

# Show differences with color
diff --color=auto file1.txt file2.txt
```

### Understanding diff Output

```bash
# Normal format
3c3
< old line
---
> new line

# Unified format (-u)
@@ -3,3 +3,3 @@
 context
-old line
+new line
 context
```

| Symbol | Meaning |
|--------|---------|
| `<` | Line from first file |
| `>` | Line from second file |
| `---` | Separator |
| `-` | Line removed (unified) |
| `+` | Line added (unified) |

## 🔢 cmp — Byte by Byte Comparison

```bash
# Compare two files
cmp file1.bin file2.bin

# Show differing bytes
cmp -l file1.bin file2.bin

# Show first difference only
cmp file1.txt file2.txt

# Skip first N bytes
cmp -i 100 file1.bin file2.bin

# Compare limited bytes
cmp -n 1000 file1.bin file2.bin
```

> cmp is useful for binary files where diff doesn't work well.

## 📋 comm — Compare Sorted Files

```bash
# Compare two sorted files
comm file1.txt file2.txt

# Show only lines in file1
comm -23 file1.txt file2.txt

# Show only lines in file2
comm -13 file1.txt file2.txt

# Show only common lines
comm -12 file1.txt file2.txt
```

**Output columns:**
- Column 1: Lines only in file1
- Column 2: Lines only in file2
- Column 3: Lines in both files

| Option | Suppresses |
|--------|-----------|
| `-1` | Column 1 |
| `-2` | Column 2 |
| `-3` | Column 3 |

## 🩹 patch — Apply diffs

```bash
# Create a patch
diff -u original.txt modified.txt > fix.patch

# Apply a patch
patch original.txt < fix.patch

# Apply patch to directory
cd /project
diff -ruN original/ modified/ > changes.patch
patch -p1 < changes.patch

# Reverse a patch
patch -R original.txt < fix.patch

# Dry run
patch --dry-run original.txt < fix.patch
```

## 🧪 Practice

```bash
# 1. Create test files
cat > file1.txt << 'EOF'
Line 1
Line 2
Line 3
Line 4
EOF

cat > file2.txt << 'EOF'
Line 1
Line 2 modified
Line 3
Line 5
EOF

# 2. Compare with diff
diff file1.txt file2.txt

# 3. Unified format
diff -u file1.txt file2.txt

# 4. Create and apply patch
diff -u file1.txt file2.txt > changes.patch
cp file1.txt file1_backup.txt
patch file1.txt < changes.patch
cat file1.txt

# 5. Compare sorted files
cat > sorted1.txt << 'EOF'
apple
banana
cherry
EOF

cat > sorted2.txt << 'EOF'
apple
banana
date
EOF

comm sorted1.txt sorted2.txt

# 6. Clean up
rm file1.txt file2.txt file1_backup.txt changes.patch sorted1.txt sorted2.txt
```
