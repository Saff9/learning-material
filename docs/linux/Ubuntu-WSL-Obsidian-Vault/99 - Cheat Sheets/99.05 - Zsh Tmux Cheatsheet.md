# Zsh & Tmux Master Cheatsheet

## 🚀 Zsh Shortcuts & Commands

### Navigation & Editing
| Shortcut | Action |
|----------|--------|
| `Ctrl + A` | Move cursor to beginning of line |
| `Ctrl + E` | Move cursor to end of line |
| `Ctrl + U` | Clear line before cursor |
| `Ctrl + K` | Clear line after cursor |
| `Ctrl + W` | Delete previous word |
| `Alt + F` | Move cursor forward one word |
| `Alt + B` | Move cursor backward one word |

### History & Search
| Shortcut | Action |
|----------|--------|
| `Ctrl + R` | Search command history backwards |
| `!!` | Execute the last command |
| `!$` | Last argument of the previous command |
| `sudo !!` | Run the previous command with sudo |

*(With `zsh-autosuggestions` installed: Press `→` (Right Arrow) to accept the suggestion!)*

## 🪟 Tmux Master Cheatsheet

*(Assuming default prefix `Ctrl+B`, or `Ctrl+A` if you modified `.tmux.conf` as per the guide)*

### Sessions
| Command | Action |
|---------|--------|
| `tmux` | Start a new session |
| `tmux new -s name` | Start a new session with a specific name |
| `tmux a` | Attach to the last session |
| `tmux a -t name` | Attach to session "name" |
| `tmux ls` | List all running sessions |
| `tmux kill-session -t name` | Kill session "name" |
| `Prefix + d` | Detach from the current session |
| `Prefix + $` | Rename current session |

### Windows (Tabs)
| Shortcut | Action |
|----------|--------|
| `Prefix + c` | Create a new window |
| `Prefix + ,` | Rename current window |
| `Prefix + n` | Next window |
| `Prefix + p` | Previous window |
| `Prefix + 0-9` | Select window by number |
| `Prefix + w` | List windows (interactive selection) |
| `Prefix + &` | Kill current window |

### Panes (Splits)
| Shortcut | Action |
|----------|--------|
| `Prefix + %` | Split pane vertically (Left/Right) |
| `Prefix + "` | Split pane horizontally (Top/Bottom) |
| *(Custom: `\|`)* | *Split vertically (if in .tmux.conf)* |
| *(Custom: `-`)* | *Split horizontally (if in .tmux.conf)* |
| `Prefix + Arrow keys` | Move between panes |
| `Prefix + x` | Kill current pane |
| `Prefix + z` | Toggle pane zoom (Full screen) |
| `Prefix + {` | Swap pane left |
| `Prefix + }` | Swap pane right |

### Resizing Panes
| Shortcut | Action |
|----------|--------|
| `Prefix + Ctrl + Arrow` | Resize pane by 1 cell |
| `Prefix + Alt + Arrow` | Resize pane by 5 cells |

## 💡 Pro Tips for WSL2
- Run `explorer.exe .` in Zsh to open the current Linux directory in Windows File Explorer.
- Copy text in Tmux by holding `Shift` and highlighting with your mouse, then `Right Click` to copy (if mouse mode is off, otherwise standard copy works).
- Combine both tools for the ultimate setup: A Tmux session running in a powerful Zsh environment ensures you never lose your workspace even if Windows Terminal crashes.
