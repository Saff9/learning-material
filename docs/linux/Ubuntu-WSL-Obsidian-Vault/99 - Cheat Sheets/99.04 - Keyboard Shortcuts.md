# Keyboard Shortcuts

> Essential terminal and bash shortcuts for speed

---

## ⌨️ Bash Line Editing

| Shortcut | Action |
|----------|--------|
| `Ctrl + A` | Beginning of line |
| `Ctrl + E` | End of line |
| `Ctrl + B` | Back one character |
| `Ctrl + F` | Forward one character |
| `Alt + B` | Back one word |
| `Alt + F` | Forward one word |
| `Ctrl + U` | Delete to beginning |
| `Ctrl + K` | Delete to end |
| `Ctrl + W` | Delete word before cursor |
| `Ctrl + D` | Delete character under cursor |
| `Ctrl + H` | Delete character before cursor |
| `Ctrl + Y` | Paste (yank) |
| `Ctrl + T` | Swap characters |
| `Alt + T` | Swap words |
| `Ctrl + _` | Undo |
| `Ctrl + L` | Clear screen |
| `Ctrl + C` | Cancel command |
| `Ctrl + D` | Exit/logout |
| `Ctrl + Z` | Suspend process |
| `Ctrl + S` | Stop output |
| `Ctrl + Q` | Resume output |

## 📜 History

| Shortcut | Action |
|----------|--------|
| `Up` | Previous command |
| `Down` | Next command |
| `Ctrl + R` | Search history backward |
| `Ctrl + S` | Search history forward |
| `Ctrl + G` | Cancel search |
| `Ctrl + P` | Previous command |
| `Ctrl + N` | Next command |
| `!!` | Last command |
| `!n` | Command n |
| `!-n` | nth previous |
| `!string` | Last starting with string |
| `!$` | Last argument |
| `!*` | All arguments |

---

## 🔍 Tab Completion

| Shortcut | Action |
|----------|--------|
| `Tab` | Complete current |
| `Tab Tab` | Show all options |
| `Alt + ?` | List completions |
| `Alt + *` | Insert all completions |
| `Alt + /` | Complete filename |
| `Alt + ~` | Complete username |
| `Alt + $` | Complete variable |
| `Alt + @` | Complete hostname |
| `Alt + !` | Complete command |
