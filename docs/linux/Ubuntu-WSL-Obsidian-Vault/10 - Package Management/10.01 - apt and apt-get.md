---

## 🆚 apt vs apt-get

| Feature | apt | apt-get |
|---------|-----|---------|
| Modern | Yes | Legacy |
| Progress bar | Yes | No |
| User-friendly | Yes | Script-friendly |
| Recommended | For interactive | For scripts |

---

## 📦 Basic Commands

```bash
# Update package lists
sudo apt update

# Upgrade installed packages
sudo apt upgrade
sudo apt full-upgrade  # Also removes unnecessary packages

# Install package
sudo apt install package_name

# Install multiple packages
sudo apt install package1 package2 package3

# Remove package
sudo apt remove package_name

# Remove package and config
sudo apt purge package_name

# Search for package
apt search keyword

# Show package info
apt show package_name

# List installed packages
apt list --installed

# Check if package is installed
dpkg -l | grep package_name
```

---

## 🧹 Cleanup

```bash
# Remove unused dependencies
sudo apt autoremove

# Clean downloaded packages
sudo apt clean

# Clean old packages
sudo apt autoclean

# Fix broken dependencies
sudo apt --fix-broken install
sudo apt -f install
```

## 🧪 Practice

```bash
# 1. Update lists
sudo apt update

# 2. Search for htop
apt search htop

# 3. Install
sudo apt install htop

# 4. Show info
apt show htop

# 5. Remove
sudo apt remove htop

# 6. Clean up
sudo apt autoremove
```
