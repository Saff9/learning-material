## 💀 kill — Terminate Processes

```bash
# Default: SIGTERM (graceful)
kill 1234

# Force kill
kill -9 1234
kill -SIGKILL 1234

# Graceful restart
kill -HUP 1234

# Kill by name
killall firefox
pkill firefox

# List signals
kill -l
```

### Common Signals

| Signal | Number | Meaning |
|--------|--------|---------|
| SIGTERM | 15 | Graceful termination (default) |
| SIGKILL | 9 | Force kill (cannot be caught) |
| SIGHUP | 1 | Hang up (often reloads config) |
| SIGINT | 2 | Interrupt (Ctrl+C) |
| SIGSTOP | 19 | Stop (pause) |
| SIGCONT | 18 | Continue |

## ⚡ nice and renice — Priority

```bash
# Start with low priority (nice value 10)
nice -n 10 command

# Start with high priority (requires root)
sudo nice -n -10 command

# Change priority of running process
sudo renice -n 5 -p 1234

# View nice values
ps -eo pid,ni,cmd | grep firefox
```

**Nice values:** -20 (highest priority) to 19 (lowest)

## 🏃 nohup — Immune to Hangups

```bash
# Run even after logout
nohup long-running-command &

# Output goes to nohup.out by default
nohup python script.py > output.log 2>&1 &
```

## 📋 jobs — Job Control

```bash
# List jobs
jobs

# Bring to foreground
fg %1

# Send to background
bg %1

# Kill job
kill %1
```

---

## 🧪 Practice

```bash
# 1. Start a background process
sleep 100 &

# 2. List jobs
jobs

# 3. Bring to foreground
fg %1
# Then Ctrl+Z to suspend

# 4. Send back to background
bg %1

# 5. Kill it
kill %1
```
