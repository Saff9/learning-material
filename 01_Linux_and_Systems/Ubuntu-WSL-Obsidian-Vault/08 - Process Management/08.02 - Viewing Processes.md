# Viewing Processes

## 🎯 What You'll Learn
- Use ps to view processes
- Monitor with top and htop
- Find processes with pgrep and pidof

---

## 📊 ps — Process Status

```bash
# Basic
ps

# All processes
ps aux

# Full format
ps -ef

# Specific user
ps -u username

# Specific process
ps -p 1234

# Tree view
ps auxf

# Custom format
ps -eo pid,ppid,cmd,%mem,%cpu --sort=-%mem | head
```

### ps Columns

| Column | Meaning |
|--------|---------|
| PID | Process ID |
| PPID | Parent PID |
| USER | Owner |
| %CPU | CPU usage |
| %MEM | Memory usage |
| VSZ | Virtual memory size |
| RSS | Resident set size |
| TTY | Terminal |
| STAT | State |
| START | Start time |
| TIME | CPU time |
| CMD | Command |

---

## 📈 top — Dynamic View

```bash
# Run top
top

# Sort by memory: Shift+M
# Sort by CPU: Shift+P
# Kill process: k
# Quit: q
```

**Interactive commands:**
- `h` — Help
- `k` — Kill process
- `r` — Renice
- `M` — Sort by memory
- `P` — Sort by CPU
- `T` — Sort by time
- `1` — Show all CPUs
- `q` — Quit

---

## 🌈 htop — Enhanced top

```bash
# Install
sudo apt install htop

# Run
htop
```

**Features:**
- Colorful interface
- Mouse support
- Tree view
- Search
- Filter

---

## 🔍 pgrep and pidof

```bash
# Find PID by name
pgrep firefox

# Full command match
pgrep -f "python script.py"

# List with command
pgrep -a firefox

# Find PID
pidof nginx

# Find all PIDs
pidof -x script.sh
```

## 🧪 Practice

```bash
# 1. View your processes
ps aux | grep $USER

# 2. Top 10 memory users
ps aux --sort=-%mem | head -11

# 3. Find bash PID
pgrep bash

# 4. Run htop
htop
```
