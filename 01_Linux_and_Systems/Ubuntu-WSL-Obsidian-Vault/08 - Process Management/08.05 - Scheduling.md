## ⏰ cron — Recurring Tasks

```bash
# Edit crontab
crontab -e

# List crontab
crontab -l

# Remove crontab
crontab -r

# View system crontab
cat /etc/crontab

# View cron directories
ls /etc/cron.*/
```

### Cron Syntax

```
* * * * * command
| | | | |
| | | | +-- Day of week (0-7, 0=Sunday)
| | | +---- Month (1-12)
| | +------ Day of month (1-31)
| +-------- Hour (0-23)
+---------- Minute (0-59)
```

### Examples

```bash
# Every minute
* * * * * /path/to/script.sh

# Every hour
0 * * * * /path/to/script.sh

# Every day at 3 AM
0 3 * * * /path/to/script.sh

# Every Monday at 8 AM
0 8 * * 1 /path/to/script.sh

# Every 5 minutes
*/5 * * * * /path/to/script.sh

# First day of month at midnight
0 0 1 * * /path/to/script.sh
```

## ⏱️ at — One-time Tasks

```bash
# Install
sudo apt install at

# Schedule task
echo "backup.sh" | at midnight

# Schedule with time
at 3:00 PM tomorrow
at now + 1 hour
at 14:00 07/20/2024

# List scheduled tasks
atq

# Remove task
atrm 1

# View task details
at -c 1
```

## 🕐 systemd Timers

```bash
# List timers
systemctl list-timers

# View timer file
cat /etc/systemd/system/mytimer.timer

# Enable timer
sudo systemctl enable mytimer.timer
sudo systemctl start mytimer.timer
```

## 🧪 Practice

```bash
# 1. Edit crontab
crontab -e

# 2. Add a test entry (runs every minute, logs to file)
* * * * * echo "Cron test $(date)" >> ~/cron-test.log

# 3. Wait a few minutes, then check
cat ~/cron-test.log

# 4. Remove test entry
crontab -e
# Delete the line

# 5. Clean up
rm ~/cron-test.log
```
