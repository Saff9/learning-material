## 📦 Snap Commands

```bash
# Search for snap
snap find keyword

# Install snap
sudo snap install package_name

# Remove snap
sudo snap remove package_name

# List installed snaps
snap list

# Update snaps
sudo snap refresh

# Update specific snap
sudo snap refresh package_name

# Check snap info
snap info package_name

# View snap changes
snap changes
```

---

## 🆚 Snap vs Apt

| Feature | Snap | Apt |
|---------|------|-----|
| Sandboxed | Yes | No |
| Auto-updates | Yes | No |
| Size | Larger | Smaller |
| Startup | Slower | Faster |
| Latest versions | Yes | No (stable) |
