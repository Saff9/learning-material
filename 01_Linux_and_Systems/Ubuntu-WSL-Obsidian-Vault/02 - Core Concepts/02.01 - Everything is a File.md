## 📖 The Philosophy

In Linux, **everything is a file**. This isn't just a saying — it's a fundamental design principle that makes the system elegant and consistent.

> "In Unix, everything is a file. This is a lie, but a useful one." — Unknown

### What "Everything is a File" Means

| Thing | File Path | What It Represents |
|-------|-----------|-------------------|
| Hard drive | `/dev/sda` | Block device |
| Keyboard | `/dev/input/event0` | Character device |
| Process info | `/proc/1234/` | Process directory |
| Network socket | `/proc/net/tcp` | Network state |
| Random data | `/dev/urandom` | Random number generator |
| Null device | `/dev/null` | Discard output |
| Terminal | `/dev/pts/0` | Pseudo-terminal |

## 📂 File Types

Linux recognizes these file types:

### 1. Regular Files (`-`)

```bash
-rw-r--r-- 1 user group 1234 Jul 15 10:00 document.txt
```

Normal files: text, images, binaries, etc.

### 2. Directories (`d`)

```bash
drwxr-xr-x 2 user group 4096 Jul 15 10:00 myfolder
```

Special files that contain lists of other files.

### 3. Symbolic Links (`l`)

```bash
lrwxrwxrwx 1 user group 9 Jul 15 10:00 link -> target.txt
```

Pointers to other files (like shortcuts).

```bash
# Create a symbolic link
ln -s /path/to/original /path/to/link

# Create a hard link
ln /path/to/original /path/to/hardlink
```

**Symbolic Link vs Hard Link:**

| Feature | Symbolic Link | Hard Link |
|---------|--------------|-----------|
| Points to | File path | Inode (data) |
| Works across filesystems | Yes | No |
| Survives original deletion | No (broken link) | Yes (data remains) |
| Can link directories | Yes | No |

### 4. Character Devices (`c`)

```bash
crw-rw-rw- 1 root root 1, 3 Jul 15 10:00 /dev/null
```

Devices that handle data character by character (keyboards, serial ports).

### 5. Block Devices (`b`)

```bash
brw-rw---- 1 root disk 8, 0 Jul 15 10:00 /dev/sda
```

Devices that handle data in blocks (hard drives, SSDs, USB drives).

### 6. Named Pipes (`p`)

```bash
prw-r--r-- 1 user group 0 Jul 15 10:00 mypipe
```

Allow processes to communicate (inter-process communication).

```bash
# Create a named pipe
mkfifo mypipe

# Terminal 1: Write to pipe
echo "Hello" > mypipe

# Terminal 2: Read from pipe
cat mypipe
# Output: Hello
```

### 7. Sockets (`s`)

```bash
srwxrwxr-x 1 user group 0 Jul 15 10:00 /tmp/mysocket
```

Allow processes to communicate over a network or locally.

## 🔍 Identifying File Types

```bash
# Method 1: ls -l (first character)
ls -l /dev/null
# crw-rw-rw- ... /dev/null  (c = character device)

# Method 2: file command
file /dev/null
# /dev/null: character special (1/3)

file /bin/ls
# /bin/ls: ELF 64-bit LSB pie executable

file /etc/passwd
# /etc/passwd: ASCII text

# Method 3: stat command
stat /dev/null

# Method 4: test command
[ -f /etc/passwd ] && echo "Regular file"
[ -d /home ] && echo "Directory"
[ -L /bin/sh ] && echo "Symbolic link"
[ -b /dev/sda ] && echo "Block device"
[ -c /dev/null ] && echo "Character device"
[ -p /tmp/mypipe ] && echo "Named pipe"
[ -S /tmp/mysocket ] && echo "Socket"
```

## 🌊 Special Device Files

### /dev/null — The Black Hole

```bash
# Discard output
cat bigfile.txt > /dev/null

# Discard errors
command 2> /dev/null

# Discard everything
command > /dev/null 2>&1
```

### /dev/zero — Infinite Zeros

```bash
# Create a 1GB file filled with zeros
dd if=/dev/zero of=bigfile bs=1M count=1024
```

### /dev/random and /dev/urandom — Random Data

```bash
# Get random bytes (blocking, cryptographically secure)
head -c 32 /dev/random | base64

# Get random bytes (non-blocking)
head -c 32 /dev/urandom | base64
```

### /dev/full — Always Full

```bash
# Simulates a full disk (useful for testing)
echo "test" > /dev/full
# bash: echo: write error: No space left on device
```

### /dev/stdin, /dev/stdout, /dev/stderr

```bash
# These are symlinks to file descriptors
cat /dev/stdin
# Same as: cat -
# Same as: just running cat
```

## 🧠 Why "Everything is a File" is Powerful

### 1. Unified Interface

```bash
# Read from a file
cat document.txt

# Read from a device
cat /dev/input/event0

# Read from a process
cat /proc/1/cmdline

# Same command, different targets — consistent interface!
```

### 2. Composability

```bash
# Combine any sources and destinations
cat /dev/urandom | head -c 100 | base64 > random_password.txt
```

### 3. Easy Inspection

```bash
# See what a process is doing
cat /proc/1234/status

# See network connections
cat /proc/net/tcp

# See memory info
cat /proc/meminfo
```

### 4. Everything is Scriptable

```bash
# Check if a process is running
if [ -d /proc/1234 ]; then
    echo "Process 1234 is running"
fi

# Monitor a process
watch -n 1 cat /proc/1234/status
```

## 🧪 Practice

```bash
# 1. Check the type of various files
file /bin/bash
file /dev/sda
file /proc/1
file /etc/localtime

# 2. Create and use a named pipe
mkfifo /tmp/testpipe
# In one terminal: echo "Hello Pipe" > /tmp/testpipe
# In another: cat /tmp/testpipe

# 3. Explore /proc for your shell
ls /proc/$$
cat /proc/$$/cmdline
cat /proc/$$/status

# 4. Generate a random password
cat /dev/urandom | tr -dc 'a-zA-Z0-9' | head -c 16; echo

# 5. Create a 100MB test file
dd if=/dev/zero of=testfile bs=1M count=100
```
