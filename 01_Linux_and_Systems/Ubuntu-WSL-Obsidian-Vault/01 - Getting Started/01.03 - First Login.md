## 🖥️ The Shell Prompt

When you open Ubuntu, you see something like:

```bash
yourname@COMPUTERNAME:~$ 
```

Let's break it down:

```
yourname    @    COMPUTERNAME    :    ~    $
   |              |                |    |
   |              |                |    +--- You are a normal user (# = root)
   |              |                +-------- Current directory (~ = home)
   |              +------------------------- Hostname (your computer name)
   +---------------------------------------- Your username
```

**Prompt variations:**
- `$` = Normal user (safe mode)
- `#` = Root user (dangerous — you can break anything)

## 🧭 Your First Commands

### Where Am I? (pwd)

```bash
# Print Working Directory
pwd
# Output: /home/yourname
```

This shows your **absolute path** — your exact location in the file system.

### What's Here? (ls)

```bash
# List files
ls

# List with details
ls -l

# List all files (including hidden)
ls -la

# List with human-readable sizes
ls -lh

# List sorted by time (newest first)
ls -lt
```

**Understanding `ls -l` output:**

```bash
drwxr-xr-x 2 yourname yourname 4096 Jul 15 10:30 Documents
-rw-r--r-- 1 yourname yourname  220 Jul 15 10:30 .bash_logout
```

| Column         | Meaning                                           |
| -------------- | ------------------------------------------------- |
| `drwxr-xr-x`   | Permissions (d=directory, rwx=read/write/execute) |
| `2`            | Number of hard links                              |
| `yourname`     | Owner                                             |
| `yourname`     | Group                                             |
| `4096`         | Size in bytes                                     |
| `Jul 15 10:30` | Last modified date                                |
| `Documents`    | Name                                              |

### Moving Around (cd)

```bash
# Go to home directory
cd ~
# or just
cd

# Go up one level
cd ..

# Go to specific directory
cd /var/log

# Go to previous directory
cd -

# Go to absolute path
cd /usr/bin
```

### Creating Directories (mkdir)

```bash
# Create a single directory
mkdir projects

# Create nested directories
mkdir -p projects/linux-learning/week1

# Create multiple directories
mkdir dir1 dir2 dir3
```

### Creating Files (touch)

```bash
# Create empty file
touch notes.txt

# Create multiple files
touch file1.txt file2.txt file3.txt

# Update timestamp of existing file
touch notes.txt
```

## ✏️ Editing Files

### Using nano (Beginner-Friendly)

```bash
# Open or create a file
nano notes.txt
```

**Nano controls:**
- `Ctrl + O` -> Save (Write Out)
- `Ctrl + X` -> Exit
- `Ctrl + K` -> Cut line
- `Ctrl + U` -> Paste
- `Ctrl + W` -> Search
- `Ctrl + G` -> Help

> The `^` symbol means `Ctrl`. So `^O` = `Ctrl+O`.

### Using echo

```bash
# Write text to file (overwrite)
echo "Hello, Linux!" > hello.txt

# Append text to file
echo "Another line" >> hello.txt

# View the file
cat hello.txt
```

## ⌨️ Essential Keyboard Shortcuts

### Terminal Navigation

| Shortcut | Action |
|----------|--------|
| `Ctrl + A` | Go to beginning of line |
| `Ctrl + E` | Go to end of line |
| `Ctrl + U` | Clear line (before cursor) |
| `Ctrl + K` | Clear line (after cursor) |
| `Ctrl + W` | Delete word before cursor |
| `Ctrl + L` | Clear screen |
| `Ctrl + C` | Cancel current command |
| `Ctrl + D` | Exit/logout (or delete char) |
| `Ctrl + Z` | Suspend process (background) |
| `Tab` | Auto-complete |
| `Tab Tab` | Show all completions |
| `Up` / `Down` | Previous/next command in history |
| `Ctrl + R` | Search command history |

### Copy/Paste in Terminal

- **WSL/Terminal:** `Ctrl + Shift + C` (copy), `Ctrl + Shift + V` (paste)
- **Right-click** also works for paste
- **Note:** Regular `Ctrl+C` cancels commands, not copies!

## 🧪 Practice Exercise

Complete this exercise to reinforce what you learned:

```bash
# 1. Check where you are
pwd

# 2. Create a learning directory structure
mkdir -p ~/linux-practice/{week1,week2,week3}

# 3. Navigate into week1
cd ~/linux-practice/week1

# 4. Create a file with today's date
touch $(date +%Y-%m-%d)-notes.txt

# 5. Write something in it
echo "My Linux journey begins today!" > $(date +%Y-%m-%d)-notes.txt

# 6. View the file
cat $(date +%Y-%m-%d)-notes.txt

# 7. List all files with details
ls -la

# 8. Go back to home
cd ~

# 9. View the directory tree
tree linux-practice
```
