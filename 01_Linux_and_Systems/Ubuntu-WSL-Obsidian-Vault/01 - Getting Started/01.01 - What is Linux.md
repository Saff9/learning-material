## 📖 The Story

### Linux is a Kernel
**Linux** is the **kernel** — the core component that talks to your hardware. It was created by **Linus Torvalds** in 1991.

> "I'm doing a (free) operating system (just a hobby, won't be big and professional like gnu)" — Linus Torvalds, 1991

### GNU + Linux = Operating System
The tools you use (ls, cp, bash, gcc) come from the **GNU Project** (started by Richard Stallman in 1983). Together they form a complete OS, often called **GNU/Linux**.

```
+-------------------------------------+
|         User Applications           |  <- Your apps: Chrome, VS Code, etc.
+-------------------------------------+
|         Shell (bash, zsh)           |  <- Command interpreter
+-------------------------------------+
|    GNU Utilities (coreutils)        |  <- ls, cp, mv, grep, etc.
+-------------------------------------+
|         Linux Kernel                |  <- Hardware interface
+-------------------------------------+
|           Hardware                  |  <- CPU, RAM, Disk, Network
+-------------------------------------+
```

## 🐧 Linux Distributions (Distros)

A **distribution** packages the Linux kernel + GNU tools + package manager + desktop environment + default configs.

| Distro | Based On | Best For | Package Manager |
|--------|----------|----------|-----------------|
| **Ubuntu** | Debian | Beginners, servers, WSL | `apt` |
| Debian | — | Stability, servers | `apt` |
| Fedora | Red Hat | Bleeding edge, developers | `dnf` |
| Arch | — | Customization, learning | `pacman` |
| CentOS/RHEL | Red Hat | Enterprise servers | `yum/dnf` |
| Alpine | — | Containers, minimal | `apk` |

> **Why Ubuntu for WSL?** It's the most supported, has the largest community, and Microsoft optimizes WSL for Ubuntu first.

## 🌍 Why Learn Linux?

### 1. Servers Run Linux
- 96.3% of the world's top 1 million servers run Linux
- Every major cloud provider (AWS, Azure, GCP) is Linux underneath

### 2. Development Standard
- Docker containers run Linux
- CI/CD pipelines run on Linux
- Most deployment targets are Linux

### 3. Power and Control
- No hidden processes
- Everything is configurable
- Automation through scripting

### 4. Free and Open Source
- Zero licensing costs
- Full source code available
- Community-driven improvements

## 🧠 Key Concepts

### The Unix Philosophy
1. **Do one thing well** — Each program should have a single purpose
2. **Compose programs** — Small tools connect via pipes
3. **Text is universal** — Everything is text (or can be treated as text)
4. **Configuration in files** — No hidden registry; config is readable

### Everything is a File
In Linux, **everything** is represented as a file:
- Regular files (`/home/user/doc.txt`)
- Directories (`/home/user/`)
- Devices (`/dev/sda` — your hard drive)
- Processes (`/proc/1234/`)
- Network sockets (`/proc/net/`)
