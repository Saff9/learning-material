## 🐚 What is a Shell?

A **shell** is a command-line interpreter. It takes your text commands and translates them into instructions for the computer.

```
You type: ls -la

Shell translates -> System calls -> Kernel executes -> Output displayed
```

### Common Shells

| Shell | Description | Default On |
|-------|-------------|------------|
| **bash** | Bourne Again SHell | Ubuntu, most distros |
| **zsh** | Z SHell | macOS (since Catalina) |
| **fish** | Friendly Interactive SHell | User choice |
| **sh** | Original Bourne SHell | Minimal systems |

> Ubuntu uses **bash** by default. You can check with: `echo $SHELL`

## 📁 Bash Configuration Files

Bash reads configuration files in a specific order:

### Login Shell (SSH, console login)
```
/etc/profile
    |
~/.bash_profile  (if exists)
    |
~/.bash_login    (if .bash_profile doesn't exist)
    |
~/.profile       (if neither exists)
```

### Interactive Non-Login Shell (opening terminal)
```
/etc/bash.bashrc
    |
~/.bashrc
```

### Important Files

| File | Purpose |
|------|---------|
| `~/.bashrc` | **Most important** — aliases, functions, prompt, per-session settings |
| `~/.bash_profile` | Login settings, often sources `.bashrc` |
| `~/.profile` | Fallback login config |
| `~/.bash_logout` | Commands run on logout |
| `~/.bash_history` | Command history |

> **WSL Tip:** WSL opens as a non-login interactive shell, so `~/.bashrc` is your main file.

## ⚙️ Customizing ~/.bashrc

```bash
# Open your bash configuration
nano ~/.bashrc
```

### Useful Additions

```bash
# ========== ALIASES ==========

# Navigation
alias ..='cd ..'
alias ...='cd ../..'
alias ....='cd ../../..'
alias ~='cd ~'

# Listing
alias ls='ls --color=auto'
alias ll='ls -alF'
alias la='ls -A'
alias l='ls -CF'
alias lt='ls -lt'           # Sort by time
alias lh='ls -lh'           # Human-readable sizes
alias lsize='ls -lhS'       # Sort by size

# Safety
alias rm='rm -i'            # Confirm before delete
alias cp='cp -i'            # Confirm before overwrite
alias mv='mv -i'            # Confirm before overwrite

# Git shortcuts
alias gs='git status'
alias ga='git add'
alias gc='git commit'
alias gp='git push'
alias gl='git log --oneline'

# ========== FUNCTIONS ==========

# Create directory and cd into it
mkcd() {
    mkdir -p "$1" && cd "$1"
}

# Extract any archive
extract() {
    if [ -f "$1" ]; then
        case "$1" in
            *.tar.bz2)   tar xjf "$1" ;;
            *.tar.gz)    tar xzf "$1" ;;
            *.tar.xz)    tar xJf "$1" ;;
            *.bz2)       bunzip2 "$1" ;;
            *.rar)       unrar x "$1" ;;
            *.gz)        gunzip "$1" ;;
            *.tar)       tar xf "$1" ;;
            *.tbz2)      tar xjf "$1" ;;
            *.tgz)       tar xzf "$1" ;;
            *.zip)       unzip "$1" ;;
            *.Z)         uncompress "$1" ;;
            *.7z)        7z x "$1" ;;
            *)           echo "Cannot extract '$1'" ;;
        esac
    else
        echo "'$1' is not a valid file"
    fi
}

# ========== PROMPT ==========

# Color definitions
RED='\[\e[31m\]'
GREEN='\[\e[32m\]'
YELLOW='\[\e[33m\]'
BLUE='\[\e[34m\]'
MAGENTA='\[\e[35m\]'
CYAN='\[\e[36m\]'
RESET='\[\e[0m\]'

# Custom prompt: user@host:directory (git_branch)$
# Shows git branch if in a git repository
parse_git_branch() {
    git branch 2>/dev/null | sed -e '/^[^*]/d' -e 's/* \(.*\)/ (\1)/'
}
export PS1="${GREEN}\u${RESET}@${YELLOW}\h${RESET}:${BLUE}\w${RESET}${MAGENTA}\$(parse_git_branch)${RESET}\$ "

# ========== HISTORY ==========

# Don't put duplicate lines in history
export HISTCONTROL=ignoredups:erasedups

# Append to history, don't overwrite
shopt -s histappend

# Larger history
export HISTSIZE=10000
export HISTFILESIZE=20000

# Save history after every command
export PROMPT_COMMAND="history -a; history -c; history -r; $PROMPT_COMMAND"

# ========== MISC ==========

# Case-insensitive tab completion
bind 'set completion-ignore-case on'

# Show all completions on first Tab
bind 'set show-all-if-ambiguous on'

# Enable colored grep output
export GREP_OPTIONS='--color=auto'

# Default editor
export EDITOR='nano'
export VISUAL='nano'

# Better less behavior
export LESS='--quit-if-one-screen --ignore-case --status-column --LONG-PROMPT --RAW-CONTROL-CHARS --HILITE-UNREAD --tabs=4 --no-init'
```

Apply changes:
```bash
source ~/.bashrc
```

## 🌐 Environment Variables

Environment variables are key-value pairs that configure your system.

```bash
# View all environment variables
env

# View specific variable
echo $HOME
echo $PATH
echo $USER

# Set variable (current session only)
export MY_VAR="hello"

# Set variable permanently (add to ~/.bashrc)
echo 'export MY_VAR="hello"' >> ~/.bashrc

# Important environment variables
```

| Variable  | Purpose                                |
| --------- | -------------------------------------- |
| `$HOME`   | Your home directory (`/home/username`) |
| `$PATH`   | Directories to search for commands     |
| `$USER`   | Your username                          |
| `$SHELL`  | Path to your shell                     |
| `$PWD`    | Current directory                      |
| `$OLDPWD` | Previous directory                     |
| `$EDITOR` | Default text editor                    |
| `$LANG`   | System language/locale                 |
|           |                                        |

### Understanding $PATH

```bash
echo $PATH
# /usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin
```

When you type a command, bash searches these directories **in order**:

```
/usr/local/sbin -> /usr/local/bin -> /usr/sbin -> /usr/bin -> /sbin -> /bin
```

```bash
# See where a command is located
which ls
# /usr/bin/ls

# Add directory to PATH
export PATH="$PATH:/new/directory"

# Add to PATH permanently
# Add to ~/.bashrc:
export PATH="$HOME/.local/bin:$PATH"
```

## 🎯 Command Line Editing (Emacs Mode)

Bash uses Emacs-style editing by default:

| Key | Action |
|-----|--------|
| `Ctrl + A` | Beginning of line |
| `Ctrl + E` | End of line |
| `Ctrl + B` / `Left` | Back one character |
| `Ctrl + F` / `Right` | Forward one character |
| `Alt + B` | Back one word |
| `Alt + F` | Forward one word |
| `Ctrl + D` | Delete character under cursor |
| `Ctrl + H` / `Backspace` | Delete character before cursor |
| `Ctrl + W` | Delete word before cursor |
| `Ctrl + U` | Delete entire line |
| `Ctrl + K` | Delete from cursor to end |
| `Ctrl + Y` | Paste (yank) |
| `Ctrl + T` | Swap current and previous character |
| `Alt + T` | Swap current and previous word |
| `Ctrl + _` | Undo |
