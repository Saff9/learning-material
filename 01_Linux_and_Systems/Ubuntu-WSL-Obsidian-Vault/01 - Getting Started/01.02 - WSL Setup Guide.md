# WSL Setup Guide

## 🎯 What You'll Learn
- Install and configure WSL2 on Windows
- Set up Ubuntu as your Linux distribution
- Configure WSL for optimal development

## 📋 Prerequisites

- **Windows 10** version 2004+ (Build 19041+) OR **Windows 11**
- Administrator access
- ~1GB free disk space

> Check your version: Press `Win + R`, type `winver`, press Enter

## 🚀 Installation Methods

### Method 1: Automatic Install (Recommended)

Open **PowerShell as Administrator** and run:

```powershell
# Install WSL with Ubuntu (default distro)
wsl --install

# This installs:
# - WSL2 (the latest version)
# - Ubuntu (the default distribution)
# - Sets WSL2 as default
```

**Restart your computer** when prompted.

After restart, Ubuntu will automatically launch and ask you to create a username and password.

### Method 2: Manual Install

If automatic fails or you want more control:

```powershell
# Step 1: Enable WSL
wsl --install --no-distribution

# Step 2: Set WSL2 as default
wsl --set-default-version 2

# Step 3: Install Ubuntu from Microsoft Store
# Or via command line:
wsl --install -d Ubuntu

# List available distributions
wsl --list --online

# Install a specific version
wsl --install -d Ubuntu-22.04
```

### Method 3: If WSL Commands Don't Work (Older Windows)

```powershell
# Enable WSL feature (Windows 10 older builds)
dism.exe /online /enable-feature /featurename:Microsoft-Windows-Subsystem-Linux /all /norestart

# Enable Virtual Machine Platform
dism.exe /online /enable-feature /featurename:VirtualMachinePlatform /all /norestart

# Download and install WSL2 kernel update
# https://aka.ms/wsl2kernel

# Set WSL2 as default
wsl --set-default-version 2
```

## ⚙️ Post-Installation Configuration

### First Launch

When Ubuntu opens for the first time:

```bash
# You'll be prompted to create a UNIX username
Enter new UNIX username: yourname

# Create a password (you won't see characters as you type — this is normal!)
New password: ********
Retype new password: ********

# Success! You're now in your Ubuntu home directory
yourname@COMPUTERNAME:~$ 
```

> **Important:** This password is for `sudo` (admin) commands. Remember it!

### Update Your System

```bash
# Update package lists
sudo apt update

# Upgrade installed packages
sudo apt upgrade -y

# Install essential tools
sudo apt install -y \
    build-essential \
    curl \
    wget \
    git \
    vim \
    htop \
    tree \
    unzip \
    software-properties-common \
    apt-transport-https \
    ca-certificates
```

### Configure Git

```bash
# Set your identity
git config --global user.name "Your Name"
git config --global user.email "your.email@example.com"

# Set default editor
git config --global core.editor "nano"

# Check configuration
git config --list
```

## 🔄 WSL1 vs WSL2

| Feature | WSL1 | WSL2 |
|---------|------|------|
| **Architecture** | Translation layer | Lightweight VM |
| **Kernel** | Windows translation | Real Linux kernel |
| **Performance** | Faster file access (Windows files) | Faster Linux operations |
| **Compatibility** | Some apps don't work | Full Linux compatibility |
| **Boot time** | Instant | ~1 second |
| **Memory** | Shared with Windows | Dynamic allocation |
| **Docker** | Via Docker Desktop | Native (best) |

> **Recommendation:** Use WSL2. It's the default and significantly better.

### Check Your WSL Version

```powershell
# In PowerShell
wsl --list --verbose
# or
wsl -l -v

# Output example:
#   NAME      STATE       VERSION
# * Ubuntu    Running     2
```

### Convert WSL1 to WSL2

```powershell
# Convert a specific distro
wsl --set-version Ubuntu 2

# Set WSL2 as default for new distros
wsl --set-default-version 2
```

## 🔧 Essential WSL Commands

```powershell
# List all distributions
wsl --list --verbose

# Launch default distribution
wsl

# Launch specific distribution
wsl -d Ubuntu

# Terminate a distribution
wsl --terminate Ubuntu

# Shutdown all WSL
wsl --shutdown

# Unregister (delete) a distribution ⚠️ DESTRUCTIVE
wsl --unregister Ubuntu

# Export a distribution (backup)
wsl --export Ubuntu C:\backups\ubuntu.tar

# Import a distribution
wsl --import Ubuntu C:\WSL\Ubuntu C:\backups\ubuntu.tar
```

## 🖥️ Accessing Your Files

### From Windows → WSL

```powershell
# Open WSL current directory in File Explorer
explorer.exe .

# Or navigate directly
\\wsl$\Ubuntu\home\yourname
```

### From WSL → Windows

```bash
# Windows C: drive is mounted at /mnt/c
cd /mnt/c/Users/YourWindowsUsername/Desktop
ls

# Access Windows files
notepad.exe /mnt/c/Users/YourName/file.txt
```

> **⚠️ Warning:** Always use Linux file paths (`/home/user/...`) for Linux tools. Using `/mnt/c/...` paths with Linux tools is slow in WSL2.

## 🎨 Terminal Customization

### Install Windows Terminal (Recommended)

Download from Microsoft Store for the best experience:
- Tabs
- Multiple panes
- Custom themes
- GPU acceleration

### Basic .bashrc Customization

```bash
# Open your bash configuration
nano ~/.bashrc

# Add these lines at the bottom:

# Better prompt with colors
export PS1='\[\e[32m\]\u\[\e[m\]@\[\e[33m\]\h\[\e[m\]:\[\e[34m\]\w\[\e[m\]\$ '

# Aliases for common commands
alias ll='ls -alF'
alias la='ls -A'
alias l='ls -CF'
alias ..='cd ..'
alias ...='cd ../..'

# Enable color in ls
export LS_COLORS='di=1;34:ln=1;36:so=1;35:pi=1;33:ex=1;32'

# Apply changes
source ~/.bashrc
```
