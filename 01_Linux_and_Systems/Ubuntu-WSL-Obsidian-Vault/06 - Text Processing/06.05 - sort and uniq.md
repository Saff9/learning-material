# sort and uniq

## 🎯 What You'll Learn
- Sort lines with sort
- Remove duplicates with uniq
- Combine for powerful data processing

---

## 🔃 sort — Sort Lines

```bash
# Basic sort
sort file.txt

# Reverse sort
sort -r file.txt

# Numeric sort
sort -n numbers.txt

# Human-readable sizes
sort -h sizes.txt

# Sort by month
sort -M dates.txt

# Sort by specific field
sort -k2 file.txt

# Sort by field with delimiter
sort -t: -k3n /etc/passwd

# Sort and remove duplicates
sort -u file.txt

# Stable sort
sort -s file.txt

# Check if sorted
sort -c file.txt
```

### sort Options

| Option | Meaning |
|--------|---------|
| `-r` | Reverse |
| `-n` | Numeric |
| `-h` | Human-readable |
| `-M` | Month names |
| `-k` | Key/field |
| `-t` | Delimiter |
| `-u` | Unique |
| `-s` | Stable |
| `-c` | Check |

---

## 🎯 uniq — Remove Duplicates

```bash
# Remove adjacent duplicates
uniq file.txt

# Count occurrences
uniq -c file.txt

# Show only duplicates
uniq -d file.txt

# Show only unique lines
uniq -u file.txt

# Skip first N fields
uniq -f 2 file.txt

# Skip first N characters
uniq -s 5 file.txt

# Compare first N characters
uniq -w 10 file.txt
```

> **Note:** uniq only removes ADJACENT duplicates. Use `sort | uniq` for all duplicates.

---

## 🔗 Common Combinations

```bash
# Sort and remove all duplicates
sort file.txt | uniq

# Count unique occurrences
sort file.txt | uniq -c | sort -nr

# Find duplicates
sort file.txt | uniq -d

# Find unique lines only
sort file.txt | uniq -u
```
