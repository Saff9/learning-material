# xargs — Building Command Lines

## 🎯 What You'll Learn
- Build commands from stdin
- Handle special characters
- Parallel execution
- Practical examples

---

## 📝 Basic Usage

```bash
# Pass arguments to command
cat files.txt | xargs rm

# Equivalent to:
rm file1 file2 file3

# With find
find . -name "*.log" | xargs rm

# Limit arguments per command
find . -name "*.txt" | xargs -n 1 cat

# Prompt before execution
find . -name "*.tmp" | xargs -p rm

# Show command before executing
find . -name "*.txt" | xargs -t cat
```

---

## 🔧 Handling Special Characters

```bash
# Handle filenames with spaces
find . -name "*.txt" -print0 | xargs -0 rm

# Or use -d for custom delimiter
echo "file1,file2,file3" | xargs -d',' cat
```

---

## ⚡ Parallel Execution

```bash
# Run 4 processes in parallel
find . -name "*.jpg" -print0 | xargs -0 -P 4 -I {} convert {} {}.png

# With progress
find . -name "*.txt" | xargs -n 1 -P 4 gzip
```

---

## 🎯 Placeholder

```bash
# Use {} as placeholder
find . -name "*.txt" | xargs -I {} cp {} /backup/{}

# Multiple uses
find . -name "*.txt" | xargs -I {} sh -c 'echo {}; wc -l {}'
```

---

## 🧪 Practice

```bash
# 1. Remove all .tmp files
find . -name "*.tmp" | xargs rm

# 2. Count lines in all .py files
find . -name "*.py" | xargs wc -l

# 3. Copy files with spaces safely
find . -name "*.txt" -print0 | xargs -0 cp -t /backup/

# 4. Parallel compression
find . -name "*.log" | xargs -P 4 gzip
```
