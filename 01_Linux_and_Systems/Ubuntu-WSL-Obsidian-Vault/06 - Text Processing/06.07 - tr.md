# tr — Character Translation

## 🎯 What You'll Learn
- Translate characters
- Delete characters
- Squeeze repeats

---

## 🔄 Basic Translation

```bash
# Uppercase to lowercase
cat file.txt | tr 'A-Z' 'a-z'

# Lowercase to uppercase
cat file.txt | tr 'a-z' 'A-Z'

# Replace specific characters
echo "hello" | tr 'aeiou' '12345'

# Delete characters
cat file.txt | tr -d '0-9'

# Squeeze repeats
cat file.txt | tr -s ' '

# Delete non-printing characters
cat file.txt | tr -dc '[:print:]'
```

---

## 📋 Character Classes

```bash
# Use predefined classes
tr '[:lower:]' '[:upper:]'
tr -d '[:digit:]'
tr -d '[:space:]'
tr -cd '[:alnum:]'
```

| Class | Meaning |
|-------|---------|
| `[:alnum:]` | Letters and digits |
| `[:alpha:]` | Letters |
| `[:digit:]` | Digits |
| `[:lower:]` | Lowercase |
| `[:upper:]` | Uppercase |
| `[:space:]` | Whitespace |
| `[:punct:]` | Punctuation |
| `[:print:]` | Printable |

## 🧪 Practice

```bash
# 1. Convert to uppercase
echo "hello" | tr 'a-z' 'A-Z'

# 2. Remove digits
cat file.txt | tr -d '0-9'

# 3. Squeeze multiple spaces
cat file.txt | tr -s ' '

# 4. Replace newlines with spaces
cat file.txt | tr '\n' ' '

# 5. Generate random password
cat /dev/urandom | tr -dc 'a-zA-Z0-9' | head -c 16; echo
```
