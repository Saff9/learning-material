# cut and paste

## 🎯 What You'll Learn
- Extract columns with cut
- Merge files with paste
- Complement awk for simple tasks

---

## ✂️ cut — Extract Columns

```bash
# Extract field by delimiter
cut -d: -f1 /etc/passwd

# Extract multiple fields
cut -d: -f1,3 /etc/passwd

# Extract range of fields
cut -d: -f1-3 /etc/passwd

# Extract by character position
cut -c1-10 file.txt

# Extract specific characters
cut -c1,5,10 file.txt

# Complement (extract everything except)
cut --complement -d: -f2 /etc/passwd
```

### cut Options

| Option | Meaning |
|--------|---------|
| `-d` | Delimiter |
| `-f` | Fields to extract |
| `-c` | Character positions |
| `--complement` | Invert selection |

---

## 📋 paste — Merge Files

```bash
# Merge side by side
paste file1.txt file2.txt

# Merge with delimiter
paste -d',' file1.txt file2.txt

# Merge with tab delimiter
paste -d'\t' file1.txt file2.txt

# Merge single file into multiple columns
paste - - - < file.txt

# Merge with serial mode
paste -s file1.txt file2.txt
```

## 🧪 Practice

```bash
# 1. Extract usernames
cut -d: -f1 /etc/passwd

# 2. Extract first 3 fields
cut -d: -f1-3 /etc/passwd

# 3. Merge two files side by side
paste names.txt ages.txt

# 4. Create CSV from two files
paste -d',' names.txt ages.txt > people.csv
```
