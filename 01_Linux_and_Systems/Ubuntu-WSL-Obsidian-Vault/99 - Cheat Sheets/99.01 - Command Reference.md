# Command Reference

> Quick lookup for the most common Linux commands

---

## 📁 File Operations

| Command | Description | Example |
|---------|-------------|---------|
| `ls` | List files | `ls -la` |
| `cd` | Change directory | `cd /home` |
| `pwd` | Print working directory | `pwd` |
| `mkdir` | Make directory | `mkdir -p dir/subdir` |
| `rm` | Remove file | `rm -i file.txt` |
| `rm -r` | Remove directory | `rm -rf dir/` |
| `cp` | Copy | `cp -r src/ dest/` |
| `mv` | Move/rename | `mv old new` |
| `touch` | Create empty file | `touch file.txt` |
| `cat` | Display file | `cat file.txt` |
| `less` | Page through file | `less file.txt` |
| `head` | First lines | `head -n 5 file.txt` |
| `tail` | Last lines | `tail -f log.txt` |
| `find` | Find files | `find . -name "*.txt"` |
| `grep` | Search text | `grep -r "pattern" dir/` |
| `chmod` | Change permissions | `chmod 755 file` |
| `chown` | Change owner | `chown user:group file` |
| `tar` | Archive | `tar czvf archive.tar.gz dir/` |
| `tar` | Extract | `tar xzvf archive.tar.gz` |
