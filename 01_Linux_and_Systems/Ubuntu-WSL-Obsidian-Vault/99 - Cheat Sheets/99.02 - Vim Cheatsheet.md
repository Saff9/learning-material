# Vim Cheatsheet

> Essential Vim commands for survival and productivity

---

## 🚀 Getting Started

```bash
vim filename        # Open file
vim +10 filename    # Open at line 10
vim filename1 filename2  # Open multiple files
```

---

## 🔄 Modes

| Mode | Enter | Purpose |
|------|-------|---------|
| **Normal** | `Esc` | Navigation, commands |
| **Insert** | `i` | Typing text |
| **Visual** | `v` | Selecting text |
| **Command** | `:` | Ex commands |

## 🔍 Search and Replace

```vim
/pattern            # Search forward
?pattern            # Search backward
n                   # Next result
N                   # Previous result

:%s/old/new/g       # Replace all in file
:%s/old/new/gc      # Replace with confirmation
:5,10s/old/new/g    # Replace in lines 5-10
```

---

## 💾 Saving and Quitting

```vim
:w                  # Save
:q                  # Quit
:wq                 # Save and quit
:x                  # Save and quit
ZZ                  # Save and quit (shortcut)
:q!                 # Quit without saving
:w !sudo tee %      # Save with sudo
```

## 📑 Working with Multiple Files

```vim
:e filename         # Edit file
:bn                 # Next buffer
:bp                 # Previous buffer
:bd                 # Close buffer
:ls                 # List buffers
:sp filename        # Split horizontally
:vs filename        # Split vertically
Ctrl+w w            # Switch windows
Ctrl+w q            # Close window
Ctrl+w =            # Equal size windows
```

## ⚙️ Settings

```vim
:set number         # Show line numbers
:set nonumber       # Hide line numbers
:set relativenumber # Relative line numbers
:set hlsearch       # Highlight search
:set nohlsearch     # No highlight
:set ignorecase     # Case insensitive search
:set smartcase      # Smart case search
:set tabstop=4      # Tab width
:set shiftwidth=4   # Indent width
:set expandtab      # Use spaces for tabs
:set wrap           # Wrap lines
:set nowrap         # Don't wrap
:syntax on          # Syntax highlighting
```

---

## 🎯 Vim Survival Guide

1. **Open file:** `vim file.txt`
2. **Enter insert mode:** `i`
3. **Type your text**
4. **Exit insert mode:** `Esc`
5. **Save and quit:** `:wq` + `Enter`

**Emergency exit:** `Esc` then `:q!` + `Enter`

---

> **Learn Vim progressively:** Start with basic navigation, then add commands as needed. Use `vimtutor` for interactive lessons.
