## 🗺️ The Big Picture

```
/
├── bin/          Essential user binaries
├── boot/         Boot loader files
├── dev/          Device files
├── etc/          System configuration
├── home/         User home directories
├── lib/          Essential shared libraries
├── media/        Removable media mount points
├── mnt/          Temporary mount points
├── opt/          Optional software
├── proc/         Process information (virtual)
├── root/         Root user's home
├── run/          Runtime variable data
├── sbin/         Essential system binaries
├── srv/          Service data
├── sys/          System information (virtual)
├── tmp/          Temporary files
├── usr/          User programs and data
│   ├── bin/      Non-essential binaries
│   ├── lib/      Non-essential libraries
│   ├── local/    Local software
│   └── share/    Shared data
├── var/          Variable data
│   ├── log/      Log files
│   ├── mail/     User mailboxes
│   ├── spool/    Spooled data
│   └── tmp/      Temporary files (preserved)
└── mnt/          Mount points (WSL: Windows drives)
```

## 📂 Key Directories Explained

### / — The Root

The top of the filesystem. Everything starts here.

```bash
cd /
ls
```

### /bin — Essential Binaries

Programs needed for the system to boot and run in single-user mode.

```bash
ls /bin
# cat, cp, ls, mv, rm, mkdir, bash, echo, pwd...
```

> These must be available even if /usr is not mounted.

### /sbin — System Binaries

Programs for system administration.

```bash
ls /sbin
# fdisk, fsck, ifconfig, reboot, shutdown...
```

### /usr — User Programs

Secondary hierarchy for read-only user data.

```bash
ls /usr
# bin/    - Non-essential commands
# sbin/   - Non-essential admin commands
# lib/    - Libraries for /usr/bin and /usr/sbin
# local/  - Locally installed software
# share/  - Architecture-independent data
# include/- Header files
```

> **Modern systems:** /bin and /usr/bin are often the same (symlinked).

### /etc — Configuration

System-wide configuration files.

```bash
ls /etc
# passwd      - User accounts
# group       - Group definitions
# hosts       - Hostname to IP mappings
# fstab       - Filesystem table
# crontab     - Cron jobs
# apt/        - Package manager config
# ssh/        - SSH configuration
# systemd/    - Systemd configuration
```

### /home — User Homes

Each user gets a directory here.

```bash
ls /home
# yourname/  - Your home directory
```

> **In WSL:** This is where your Linux files live. Windows files are at /mnt/c/.

### /var — Variable Data

Files that change during normal operation.

```bash
ls /var
# log/    - System logs
# mail/   - User mail
# spool/  - Print queues, cron jobs
# cache/  - Cached data
# tmp/    - Temporary files (survives reboot)
```

### /tmp — Temporary Files

Files that can be deleted on reboot.

```bash
# Create temp file
mktemp
# /tmp/tmp.abc123

# Create temp directory
mktemp -d
# /tmp/tmp.def456
```

### /dev — Device Files

Hardware and virtual devices.

```bash
ls /dev
# null      - Discard output
# zero      - Infinite zeros
# random    - Random data
# urandom   - Non-blocking random
# sda       - First hard drive
# tty       - Terminal
# pts/      - Pseudo-terminals
```

### /proc — Process Information

Virtual filesystem showing process and kernel info.

```bash
ls /proc
# 1/        - PID 1 (init/systemd)
# 1234/     - Process 1234
# cpuinfo   - CPU information
# meminfo   - Memory information
# mounts    - Mounted filesystems
# net/      - Network info
# sys/      - Kernel parameters
```

### /sys — System Information

Virtual filesystem for kernel objects.

```bash
ls /sys
# block/    - Block devices
# bus/      - Buses
# class/    - Device classes
# devices/  - Device tree
# module/   - Kernel modules
```

## 🪟 WSL-Specific Paths

### Windows Integration

```bash
# Windows C: drive
cd /mnt/c
ls
# 'Program Files'   'Program Files (x86)'   Users   Windows

# Your Windows home
cd /mnt/c/Users/YourWindowsName

# Windows path in WSL
# C:\Users\Name -> /mnt/c/Users/Name
```

### WSL Filesystem Locations

```bash
# WSL configuration (per-distro)
/etc/wsl.conf

# WSL global configuration (Windows side)
# %UserProfile%\.wslconfig

# WSL executable
# /mnt/c/Windows/System32/wsl.exe
```

### Performance Considerations

```bash
# FAST: Linux files in WSL
/home/yourname/projects       # Fast
/var/www/html                # Fast

# SLOW: Windows files accessed from WSL
/mnt/c/Users/you/projects    # Slow for Linux tools
/mnt/d/data                  # Slow for Linux tools

# Rule: Keep project files in WSL filesystem
# Access Windows files only when needed
```

## 🧪 Practice

```bash
# 1. Explore the root directory
ls /

# 2. See what's in /bin
ls /bin | wc -l

# 3. Check your CPU info
cat /proc/cpuinfo | grep "model name" | head -1

# 4. Check memory
cat /proc/meminfo | head -5

# 5. See mounted filesystems
cat /proc/mounts | head -10

# 6. Find all config files in /etc
find /etc -maxdepth 1 -type f | sort

# 7. Check disk usage by directory
du -sh /var/* 2>/dev/null | sort -h

# 8. Create and use a temp file
tempfile=$(mktemp)
echo "Hello" > $tempfile
cat $tempfile
rm $tempfile
```
