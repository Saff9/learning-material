## 📍 pwd — Print Working Directory

```bash
# Show current location
pwd
# /home/yourname/projects

# Show physical path (resolves symlinks)
pwd -P

# Show logical path (with symlinks)
pwd -L
```

## 📋 ls — List Directory Contents

### Basic Usage

```bash
ls                    # Simple list
ls -l                 # Long format
ls -la                # All files (including hidden)
ls -lh                # Human-readable sizes
ls -lt                # Sort by time (newest first)
ls -ltr               # Sort by time (oldest first)
ls -lS                # Sort by size (largest first)
ls -lSr               # Sort by size (smallest first)
ls -R                 # Recursive listing
ls -d */              # List only directories
```

### Understanding ls -l Output

```bash
-rw-r--r-- 1 user group 1234 Jul 15 10:30 file.txt
```

| Position | Meaning |
|----------|---------|
| `-` | File type (-=file, d=directory, l=link) |
| `rw-r--r--` | Permissions |
| `1` | Hard link count |
| `user` | Owner |
| `group` | Group |
| `1234` | Size in bytes |
| `Jul 15 10:30` | Modification date |
| `file.txt` | Filename |

### Advanced ls Options

```bash
# Colorized output
ls --color=auto

# Show file sizes in human-readable format
ls -lh

# Sort by extension
ls -lX

# Show inode numbers
ls -li

# Show SELinux context
ls -lZ

# Time formats
ls -lt                  # Modification time (default)
ls -ltc                 # Change time
ls -ltu                 # Access time
ls -lt --time=birth     # Creation time (if supported)

# List with full timestamps
ls -l --time-style=full-iso

# Custom format
ls -l --time-style="+%Y-%m-%d %H:%M:%S"
```

## 🧭 cd — Change Directory

```bash
cd /home/user/projects    # Absolute path
cd projects               # Relative path
cd ..                     # Parent directory
cd ../..                  # Two levels up
cd ~                      # Home directory
cd ~username              # Another user's home
cd -                      # Previous directory
cd                        # Home directory (shortcut)
cd /                      # Root directory
```

### cd Shortcuts

| Command | Goes To |
|---------|---------|
| `cd` or `cd ~` | Home directory |
| `cd -` | Previous directory |
| `cd ..` | Parent directory |
| `cd /` | Root directory |

## 🌳 tree — Directory Tree

```bash
# Install if not available
sudo apt install tree

# Basic tree
tree

# Show only directories
tree -d

# Limit depth
tree -L 2

# Show hidden files
tree -a

# Show file sizes
tree -h

# Show permissions
tree -p

# Show full path prefix
tree -f

# Pattern filtering
tree -P "*.txt"         # Only .txt files
tree -I "node_modules"  # Exclude node_modules

# Save tree to file
tree -L 2 > directory_structure.txt
```

## 🎯 Efficient Navigation

### Tab Completion

```bash
# Press Tab to complete
# Single match: completes immediately
cd /usr/l<Tab>    # -> cd /usr/local/

# Multiple matches: press Tab twice
cd /usr/s<Tab><Tab>
# sbin/  share/  src/

# Case insensitive (if configured)
```

### Pushd and Popd (Directory Stack)

```bash
# Save current directory and change
cd /var/log
pushd /etc
pushd /usr/bin

# See directory stack
dirs -v
# 0  /usr/bin
# 1  /etc
# 2  /var/log

# Go back
cd ~2    # Go to /var/log
popd     # Go to /etc
popd     # Go to /var/log
```

### FZF (Fuzzy Finder) — Advanced

```bash
# Install
sudo apt install fzf

# Fuzzy cd
cd $(find . -type d | fzf)

# Fuzzy file open
nano $(fzf)

# Fuzzy history search
history | fzf
```

## 🧪 Practice

```bash
# 1. Navigate to /var/log and check contents
cd /var/log
ls -lt | head -10

# 2. Go back home and list with details
cd
ls -lah

# 3. Use pushd to navigate between directories
pushd /etc
pushd /usr/share
dirs -v
popd

# 4. Create a directory tree and visualize it
mkdir -p test/{a,b,c}/{1,2,3}
tree test
rm -rf test

# 5. List files sorted by size
ls -lhS /usr/bin | head -10

# 6. Find the oldest file in /var/log
ls -ltr /var/log | head -5
```
