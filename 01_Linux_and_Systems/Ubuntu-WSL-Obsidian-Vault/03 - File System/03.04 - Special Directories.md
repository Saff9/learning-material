## 🔴 Dotfiles (Hidden Files)

Files and directories starting with `.` are hidden.

```bash
# List all files (including hidden)
ls -la

# Common hidden files in home directory
ls -la ~
# .bashrc
# .bash_history
# .bash_logout
# .profile
# .ssh/
# .config/
# .cache/
# .local/
```

### Why Hide Files?

- Keep home directory clean
- Store configuration without clutter
- Follow Unix convention

## 📁 Common Dotfiles

### Shell Configuration

| File | Purpose |
|------|---------|
| `.bashrc` | Interactive shell settings |
| `.bash_profile` | Login shell settings |
| `.bash_history` | Command history |
| `.bash_logout` | Commands on logout |
| `.profile` | Fallback login config |
| `.inputrc` | Readline (line editing) config |

### Application Config

| File/Dir | Purpose |
|----------|---------|
| `.ssh/` | SSH keys and config |
| `.gitconfig` | Git global config |
| `.vimrc` / `.vim/` | Vim config |
| `.config/` | XDG config directory |
| `.cache/` | Application cache |
| `.local/` | User local data |

## 📂 XDG Base Directory Specification

Modern applications store data in standardized locations:

```
~/.config/    -> Configuration files
~/.cache/     -> Non-essential cached data
~/.local/     -> User-specific data
    share/    -> Data files
    bin/      -> User-installed binaries
    lib/      -> User libraries
```

```bash
# Check XDG variables
echo $XDG_CONFIG_HOME   # Usually ~/.config
echo $XDG_CACHE_HOME    # Usually ~/.cache
echo $XDG_DATA_HOME     # Usually ~/.local/share
```

## 🪟 WSL-Specific Directories

### Windows Mount Points

```bash
# Windows drives
ls /mnt/
# c/   d/   e/   wsl/

# C: drive
cd /mnt/c
ls
# 'Program Files'   Users   Windows

# Your Windows home
cd /mnt/c/Users/YourName
```

### WSL Filesystem

```bash
# WSL root filesystem (Linux files)
ls /

# WSL interop
ls /usr/lib/wsl/

# WSL shared memory
ls /mnt/wsl/
```

### Important: File Location Performance

```bash
# FAST (WSL filesystem)
/home/yourname/
/var/
/tmp/

# SLOW (Windows filesystem accessed from WSL)
/mnt/c/Users/you/
/mnt/d/data/

# Best practice:
# - Keep projects in WSL: /home/you/projects
# - Access Windows files only when needed
# - Use /mnt/c/ for reading Windows files
```

## 🧪 Practice

```bash
# 1. List all dotfiles in home
ls -la ~ | grep "^\."

# 2. Check your .bashrc size
ls -lh ~/.bashrc

# 3. Explore .config directory
ls -la ~/.config/

# 4. Find all hidden files recursively (top 20)
find ~ -maxdepth 2 -name ".*" -type f | head -20

# 5. Check disk usage of dotfiles
du -sh ~/.[^.]* 2>/dev/null | sort -h

# 6. Create a proper XDG structure
mkdir -p ~/.local/bin
mkdir -p ~/.config/myapp
mkdir -p ~/.cache/myapp
```
