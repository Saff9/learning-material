## 👤 Understanding Users

### Types of Users

| Type | UID | Purpose |
|------|-----|---------|
| root | 0 | Superuser |
| system | 1-999 | System services |
| regular | 1000+ | Human users |

### Viewing User Info

```bash
# Who am I?
whoami
id

# Detailed info
id username

# Current user
echo $USER
echo $UID
```

---

## 📁 /etc/passwd

```bash
cat /etc/passwd
```

Format: `username:password:UID:GID:GECOS:home:shell`

Example:
```
john:x:1000:1000:John Doe:/home/john:/bin/bash
```

| Field | Meaning |
|-------|---------|
| username | Login name |
| password | x (stored in /etc/shadow) |
| UID | User ID |
| GID | Primary group ID |
| GECOS | Full name, phone, etc. |
| home | Home directory |
| shell | Default shell |

## 📁 /etc/shadow

```bash
sudo cat /etc/shadow
```

Stores encrypted passwords.

## 👥 /etc/group

```bash
cat /etc/group
```

Format: `groupname:password:GID:member_list`

---

## 🔧 User Management Commands

```bash
# Add user
sudo adduser username

# Add user (low-level)
sudo useradd -m -s /bin/bash username

# Set password
sudo passwd username

# Delete user
sudo deluser username

# Delete user and home directory
sudo deluser --remove-home username

# Modify user
sudo usermod -aG groupname username

# List user groups
groups username

# Switch user
su - username

# Switch to root
sudo -i
sudo su -
```

---

## 🔧 Group Management

```bash
# Add group
sudo addgroup groupname

# Delete group
sudo delgroup groupname

# Add user to group
sudo usermod -aG groupname username

# Remove user from group
sudo gpasswd -d username groupname

# List group members
getent group groupname
```

## 🧪 Practice

```bash
# 1. Check your ID
id

# 2. View /etc/passwd
cat /etc/passwd | head -5

# 3. Check your groups
groups

# 4. Create a test group
sudo addgroup testgroup

# 5. Add yourself to it
sudo usermod -aG testgroup $USER

# 6. Verify
groups

# 7. Clean up
sudo delgroup testgroup
```
