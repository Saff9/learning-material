## 📂 Accessing Windows Files from WSL

```bash
# Windows drives mounted at /mnt/
cd /mnt/c
ls

# Your Windows home
cd /mnt/c/Users/YourName

# Access Desktop
cd /mnt/c/Users/YourName/Desktop

# Access Documents
cd /mnt/c/Users/YourName/Documents
```

> **Performance:** Use Linux paths for Linux tools. Use /mnt/c only when needed.

---

## 📂 Accessing WSL Files from Windows

```powershell
# Via File Explorer
\\wsl$\Ubuntu\home\yourname

# Via command line
cd \\wsl$\Ubuntu\home\yourname

# Via explorer
explorer.exe .
```

## 🖥️ Running Windows Apps from WSL

```bash
# Open current directory in File Explorer
explorer.exe .

# Open file with default app
notepad.exe file.txt
code .

# Run PowerShell command
powershell.exe -Command "Get-Date"

# Run Windows command
cmd.exe /c dir

# Open browser
explorer.exe https://google.com
```

## 🔗 Interop Features

```bash
# Windows PATH appended to Linux PATH
echo $PATH

# Access Windows environment variables
powershell.exe -Command "Write-Host \$env:USERNAME"

# Share environment variables
# In .wslconfig:
# [wsl2]
# localhostForwarding=true
```

## 🧪 Practice

