## 📄 touch — Create Empty Files

```bash
# Create a single file
touch newfile.txt

# Create multiple files
touch file1.txt file2.txt file3.txt

# Create file with spaces (quote it!)
touch "my file.txt"

# Update timestamp of existing file
touch existingfile.txt
```

### Touch Options

```bash
# Set specific time
touch -t 202401011200 file.txt  # Jan 1, 2024, 12:00

# Use reference file's timestamp
touch -r reference.txt target.txt

# Don't create file if doesn't exist
touch -c nonexistent.txt

# Access time only
touch -a file.txt

# Modification time only
touch -m file.txt
```

## 📁 mkdir — Create Directories

```bash
# Create single directory
mkdir mydir

# Create nested directories
mkdir -p projects/linux/basics

# Create multiple directories
mkdir dir1 dir2 dir3

# Create with specific permissions
mkdir -m 755 secure_dir

# Show what's being created
mkdir -v new_directory
```

### mkdir Options

| Option | Meaning |
|--------|---------|
| `-p` | Create parent directories as needed |
| `-v` | Verbose (show each creation) |
| `-m` | Set permissions on creation |

## ✏️ nano — Simple Editor

```bash
# Open or create file
nano filename.txt

# Open with line number
nano +10 filename.txt

# Open multiple files
nano file1.txt file2.txt
```

### Nano Controls

| Key | Action |
|-----|--------|
| `Ctrl + O` | Save (Write Out) |
| `Ctrl + X` | Exit |
| `Ctrl + K` | Cut line |
| `Ctrl + U` | Paste |
| `Ctrl + W` | Search |
| `Ctrl + G` | Help |
| `Ctrl + C` | Cursor position |
| `Alt + U` | Undo |
| `Alt + E` | Redo |

> `^` means `Ctrl`. `M-` means `Alt`.

## 📝 vim — Powerful Editor

```bash
# Open or create file
vim filename.txt

# Open with cursor at line 10
vim +10 filename.txt

# Open multiple files
vim file1.txt file2.txt
```

### Vim Modes

| Mode | Purpose | How to Enter |
|------|---------|-------------|
| **Normal** | Navigation, commands | Default, or press `Esc` |
| **Insert** | Typing text | Press `i`, `a`, `o` |
| **Visual** | Selecting text | Press `v`, `V`, `Ctrl+v` |
| **Command** | Ex commands | Press `:` |

### Basic Vim Commands

**Normal Mode:**

| Command | Action |
|---------|--------|
| `i` | Insert before cursor |
| `a` | Append after cursor |
| `o` | Open new line below |
| `O` | Open new line above |
| `x` | Delete character |
| `dd` | Delete line |
| `yy` | Yank (copy) line |
| `p` | Paste after |
| `P` | Paste before |
| `u` | Undo |
| `Ctrl+r` | Redo |
| `gg` | Go to top |
| `G` | Go to bottom |
| `:w` | Save |
| `:q` | Quit |
| `:wq` or `ZZ` | Save and quit |
| `:q!` | Quit without saving |

**For a full reference, see [[99 - Cheat Sheets/99.02 - Vim Cheatsheet]]**

## 🔄 Other Ways to Create Files

### Redirection

```bash
# Create file with content
echo "Hello World" > file.txt

# Create empty file
> emptyfile.txt

# Create from command output
date > timestamp.txt
whoami > user.txt
```

### Here Document

```bash
cat > config.txt << EOF
name=John
email=john@example.com
EOF
```

### From Another Command

```bash
# Copy and modify
cat /etc/passwd > mypasswd.txt

# From URL
curl -o file.html https://example.com
wget -O file.html https://example.com
```

## 🧪 Practice

```bash
# 1. Create files
touch practice1.txt practice2.txt

# 2. Create directory structure
mkdir -p ~/linux-practice/{week1,week2}/{notes,exercises}

# 3. Edit with nano
nano ~/linux-practice/week1/notes/day1.txt
# Type something, save with Ctrl+O, exit with Ctrl+X

# 4. Create file with echo
echo "My first Linux file" > ~/linux-practice/README.md

# 5. Create file with here document
cat > ~/linux-practice/.gitignore << 'EOF'
*.tmp
*.log
EOF

# 6. Check timestamps
ls -lt ~/linux-practice/
```
