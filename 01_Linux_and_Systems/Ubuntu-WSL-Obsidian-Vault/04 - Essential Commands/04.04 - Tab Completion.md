# Tab Completion

## 🎯 What You'll Learn
- Use basic and advanced tab completion
- Configure bash completion
- Programmable completion
- Completion shortcuts

---

## 🔤 Basic Completion

### Single Tab

```bash
# If only one match: completes immediately
cd /usr/l<Tab>     # -> cd /usr/local/
```

### Double Tab

```bash
# If multiple matches: shows options
cd /usr/s<Tab><Tab>
# sbin/  share/  src/
```

### What Can Be Completed?

| Type | Example |
|------|---------|
| Commands | `git <Tab>` |
| Files | `cat file<Tab>` |
| Directories | `cd /usr/<Tab>` |
| Variables | `echo $HO<Tab>` |
| Users | `cd ~ro<Tab>` |
| Hosts | `ssh ser<Tab>` |

---

## ⚙️ Configuring Completion

Add to `~/.bashrc`:

```bash
# Case-insensitive completion
bind 'set completion-ignore-case on'

# Show all options on first Tab
bind 'set show-all-if-ambiguous on'

# Show all options if partially typed
bind 'set show-all-if-unmodified on'

# Menu completion (cycle through options)
bind 'TAB: menu-complete'
```

## 🧩 Programmable Completion

Many commands have custom completion:

```bash
# Git completion
git che<Tab>        # -> git checkout
git checkout ma<Tab> # -> git checkout main

# SSH completion
ssh ser<Tab>        # Completes from ~/.ssh/config

# apt completion
sudo apt ins<Tab>   # -> sudo apt install
sudo apt install vi<Tab> # -> sudo apt install vim
```

### Install bash-completion

```bash
sudo apt install bash-completion

# Then add to ~/.bashrc:
if [ -f /usr/share/bash-completion/bash_completion ]; then
    . /usr/share/bash-completion/bash_completion
fi
```

## ⌨️ Completion Shortcuts

| Shortcut | Action |
|----------|--------|
| `Tab` | Complete current |
| `Tab Tab` | Show all options |
| `Alt + ?` | List possible completions |
| `Alt + *` | Insert all completions |
| `Alt + /` | Complete filename |
| `Alt + ~` | Complete username |
| `Alt + $` | Complete variable |
| `Alt + @` | Complete hostname |
| `Alt + !` | Complete command |
