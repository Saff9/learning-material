## 📖 man — Manual Pages

The primary documentation system for Linux commands.

```bash
man ls          # Manual for ls command
man bash        # Bash shell manual
man 5 passwd    # Section 5 (file format) of passwd
```

### Man Page Sections

| Section | Content |
|---------|---------|
| 1 | User commands |
| 2 | System calls |
| 3 | Library functions |
| 4 | Special files |
| 5 | File formats |
| 6 | Games |
| 7 | Miscellaneous |
| 8 | System administration |

### Navigating Man Pages

| Key | Action |
|-----|--------|
| `Space` or `Page Down` | Next page |
| `Page Up` | Previous page |
| `Home` | Beginning |
| `End` | End |
| `/pattern` | Search forward |
| `?pattern` | Search backward |
| `n` | Next search result |
| `N` | Previous search result |
| `q` | Quit |

### Man Page Structure

```
NAME           - Command name and brief description
SYNOPSIS       - Command syntax
DESCRIPTION    - Detailed explanation
OPTIONS        - Available options
EXAMPLES       - Usage examples
SEE ALSO       - Related commands
FILES          - Related files
AUTHOR         - Who wrote it
```

## ❓ --help

Quick help for most commands.

```bash
ls --help
grep --help
git --help
```

**Pros:**
- Fast
- Shows common options
- No pager needed

**Cons:**
- Less detailed than man
- No examples sometimes

---

## 🔍 apropos — Search Man Pages

```bash
# Search for commands related to "copy"
apropos copy

# Search for commands related to "network"
apropos network

# Search with keyword
apropos "list directory"
```

---

## ℹ️ info — GNU Info Pages

More detailed than man for GNU tools.

```bash
info ls
info bash
info coreutils
```

**Navigation:**
- `n` — Next node
- `p` — Previous node
- `u` — Up
- `Space` — Next page
- `q` — Quit

## 🌐 Online Resources

```bash
# TLDR pages (simplified man pages)
# Install: sudo apt install tldr
tldr tar

# Cheat (interactive cheat sheets)
# Install: sudo apt install cheat
cheat tar

# Built-in help for shell commands
help cd
help echo
help test
```

## 🧪 Practice

```bash
# 1. Read man page for ls
man ls
# Search for "time" inside: /time

# 2. Get quick help
ls --help | head -20

# 3. Find commands related to "compress"
apropos compress

# 4. Check bash built-in help
help cd
help test

# 5. Try tldr
tldr tar

# 6. What section is passwd in?
man -f passwd
# passwd (1)     - change user password
# passwd (5)     - the password file
```
