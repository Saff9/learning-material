# 🖥️ Complete Terminal Mastery Course

Welcome to the **Complete Terminal Mastery Course**! This course is designed for beginners (especially if you're around 18 and just starting out) to go from zero to terminal hero. 🚀

## Course Structure

This course is organized into 12 modules, each building on the previous one:

### 📚 Modules

| Module | Topic | Description |
|--------|-------|-------------|
| [01 - Getting Started](01-getting-started/) | Introduction to the terminal | What is a terminal, opening it, first commands |
| [02 - Navigation](02-navigation/) | File system navigation | `pwd`, `ls`, `cd`, directory structure |
| [03 - File Management](03-file-management/) | Working with files | `touch`, `cat`, `cp`, `mv`, `rm`, wildcards |
| [04 - Text Editing](04-text-editing/) | Terminal text editors | `nano` and `vim` basics |
| [05 - Permissions](05-permissions/) | File permissions | `chmod`, `chown`, permission strings |
| [06 - Processes](06-processes/) | Process management | `ps`, `top`, `kill`, background jobs |
| [07 - Pipes & Redirection](07-pipes-redirection/) | Data flow | `>`, `>>`, `|`, command chaining |
| [08 - Searching](08-searching/) | Finding things | `find`, `grep`, `locate`, `awk`, `sed` |
| [09 - Networking](09-networking/) | Network commands | `ping`, `curl`, `ssh`, `ss` |
| [10 - Scripting](10-scripting/) | Shell scripting | Variables, loops, functions, scripts |
| [11 - Advanced Topics](11-advanced/) | Power user skills | Aliases, dotfiles, `tmux`, package management |
| [12 - Projects](12-projects/) | Real-world projects | System dashboard, backup, file organizer, and more |

## How to Use This Course

1. **Start from Module 1** and work through sequentially
2. **Read each module** carefully — don't skip!
3. **Do the exercises** at the end of each module
4. **Practice daily** — even 15 minutes helps
5. **Keep the cheatsheets handy** for quick reference
6. **Build the projects** in Module 12 to solidify your skills

## Prerequisites

- A computer running Linux, macOS, or Windows with WSL
- Curiosity and patience!
- No prior terminal experience required

## Tips for Success

- 💡 **Use Tab completion** constantly — it's your best friend
- 💡 **Make mistakes** — that's how you learn
- 💡 **Keep a notebook** of commands you find useful
- 💡 **Set up your environment** — customize your terminal to make it yours
- 💡 **Join communities** — Reddit's r/linux, Stack Overflow, Discord servers

## Learning Path

```
Week 1-2:   Modules 1-4  (Basics + Navigation + Files + Editing)
Week 3-4:   Modules 5-7  (Permissions + Processes + Pipes)
Week 5-6:   Modules 8-9  (Searching + Networking)
Week 7-8:   Modules 10-11 (Scripting + Advanced)
Week 9+:    Module 12    (Projects + Practice)
```

## Final Words

The terminal is one of the most powerful tools you'll ever learn. It might feel intimidating at first, but stick with it. Every expert was once a beginner. You've got this! 💪
