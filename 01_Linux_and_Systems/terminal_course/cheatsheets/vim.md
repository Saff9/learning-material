# Vim Cheatsheet

## Modes

| Key | Action |
|-----|--------|
| `i` | Insert mode (before cursor) |
| `a` | Insert mode (after cursor) |
| `o` | Insert mode (new line below) |
| `O` | Insert mode (new line above) |
| `Esc` | Normal mode |
| `v` | Visual mode |
| `:` | Command mode |

## Navigation (Normal Mode)

| Key | Action |
|-----|--------|
| `h` | Left |
| `j` | Down |
| `k` | Up |
| `l` | Right |
| `w` | Next word |
| `b` | Previous word |
| `0` | Start of line |
| `$` | End of line |
| `gg` | Top of file |
| `G` | Bottom of file |
| `:5` | Go to line 5 |

## Editing (Normal Mode)

| Key | Action |
|-----|--------|
| `x` | Delete character |
| `dd` | Delete line |
| `yy` | Copy (yank) line |
| `p` | Paste after |
| `P` | Paste before |
| `u` | Undo |
| `Ctrl + r` | Redo |
| `r` | Replace character |
| `cw` | Change word |
| `cc` | Change line |

## Saving & Quitting

| Command | Action |
|---------|--------|
| `:w` | Save |
| `:q` | Quit |
| `:wq` or `ZZ` | Save and quit |
| `:q!` | Quit without saving |
| `:wqa` | Save all and quit |

## Searching

| Command | Action |
|---------|--------|
| `/word` | Search forward |
| `?word` | Search backward |
| `n` | Next result |
| `N` | Previous result |
