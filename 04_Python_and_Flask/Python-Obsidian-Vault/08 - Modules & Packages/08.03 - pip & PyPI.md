## What is pip?

`pip` is the standard package installer for Python. It fetches and installs packages from **PyPI** (Python Package Index), resolving dependencies automatically.

## Basic Commands

```bash
# Install a package (always use virtual environments first!)
pip install requests

# Install specific version (exact match)
pip install requests==2.31.0

# Install minimum version
pip install "requests>=2.31"

# Install latest compatible version (Semantic Versioning)
pip install "requests~=2.31.0"

# Upgrade a package to the latest version
pip install --upgrade requests

# Uninstall a package
pip uninstall requests
```

## Listing Packages

```bash
# List installed packages
pip list

# List outdated packages
pip list --outdated

# Show detailed package metadata
pip show requests
```

## Virtual Environment Best Practice

Never install packages into the global system Python environment. Doing so can break system tools.

```bash
# Always use virtual environments!
python -m venv myenv
source myenv/bin/activate  # Linux/Mac
myenv\Scripts\activate     # Windows

# Now it is safe to install
pip install requests numpy pandas
```

## 🧪 Practice: Interacting with Packages in Code

### Exercise 1: Modern Package Version Checking (Python 3.12+)
*Note: `pkg_resources` is deprecated. Use `importlib.metadata` instead.*

```python
import importlib.metadata
from typing import Dict

def check_required_packages(required: dict[str, str]) -> None:
    """Checks if required packages are installed and reports their versions."""
    
    # Get all installed packages mapping name to version
    installed: dict[str, str] = {
        dist.metadata['Name']: dist.version 
        for dist in importlib.metadata.distributions()
    }
    
    for package, min_version in required.items():
        if package in installed:
            print(f"{package}: {installed[package]} (required: >={min_version})")
        else:
            print(f"{package}: NOT INSTALLED")

if __name__ == "__main__":
    requirements: dict[str, str] = {
        "requests": "2.31.0",
        "numpy": "1.26.0"
    }
    check_required_packages(requirements)
```

### Exercise 2: Asynchronous Package Installation Script
Sometimes in automation scripts, you might want to dynamically install missing dependencies asynchronously.

```python
import asyncio
import sys
from typing import Any

async def install_package_async(package: str) -> bool:
    """Asynchronously installs a Python package using pip."""
    print(f"Installing {package} asynchronously...")
    process = await asyncio.create_subprocess_exec(
        sys.executable, "-m", "pip", "install", package,
        stdout=asyncio.subprocess.PIPE,
        stderr=asyncio.subprocess.PIPE
    )
    
    stdout, stderr = await process.communicate()
    
    if process.returncode == 0:
        print(f"Successfully installed {package}.")
        return True
    else:
        print(f"Failed to install {package}:\n{stderr.decode().strip()}")
        return False

async def main_async() -> None:
    """Check and install packages concurrently."""
    packages_to_check: list[str] = ["requests", "colorama"]
    install_tasks: list[asyncio.Task[bool]] = []
    
    for package in packages_to_check:
        try:
            __import__(package)
            print(f"{package} is already installed.")
        except ImportError:
            # Schedule installation
            task = asyncio.create_task(install_package_async(package))
            install_tasks.append(task)
            
    # Wait for all scheduled installations to finish
    if install_tasks:
        results: list[bool] = await asyncio.gather(*install_tasks)
        print("All installations completed.")

if __name__ == "__main__":
    asyncio.run(main_async())
```
