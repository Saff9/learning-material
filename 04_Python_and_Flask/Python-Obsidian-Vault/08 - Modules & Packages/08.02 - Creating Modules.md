## Creating a Module

A module is simply a `.py` file. Create `mymath.py`:

```python
# mymath.py
"""A math utility module demonstrating strict typing in Python 3.12+."""
from typing import Any

# Define what is public when users do `from mymath import *`
__all__: list[str] = ["add", "multiply", "Calculator"]

# Internal constant not included in __all__
PI: float = 3.14159

def add(a: float, b: float) -> float:
    """Adds two numbers and returns the result."""
    return a + b

def multiply(a: float, b: float) -> float:
    """Multiplies two numbers and returns the result."""
    return a * b

class Calculator:
    """A simple calculator class that keeps a history of operations."""

    def __init__(self) -> None:
        self.history: list[str] = []

    def calculate(self, a: float, b: float, operation: str) -> float:
        """Performs a calculation based on the operation string."""
        if operation == "add":
            result: float = add(a, b)
        elif operation == "multiply":
            result = multiply(a, b)
        else:
            raise ValueError(f"Unknown operation: {operation}")

        self.history.append(f"{a} {operation} {b} = {result}")
        return result

# This code only runs when the file is executed directly
if __name__ == "__main__":
    print("Running mymath module directly")
    calc = Calculator()
    print(calc.calculate(5.0, 3.0, "add"))
```

## Using the Module

```python
# main.py
import mymath
from typing import Any

def main() -> None:
    """Main execution function."""
    print(mymath.PI)                       # 3.14159
    print(mymath.add(2.0, 3.0))            # 5.0
    
    calc: mymath.Calculator = mymath.Calculator()
    print(calc.calculate(4.0, 5.0, "multiply"))  # 20.0

if __name__ == "__main__":
    main()
```

## Module Attributes

Every loaded module has special dunder (double underscore) attributes you can inspect.

```python
import mymath

def inspect_module() -> None:
    print(mymath.__name__)      # Module name, e.g., 'mymath'
    print(mymath.__file__)      # Absolute path to the .py file
    print(mymath.__doc__)       # Module-level docstring
    print(dir(mymath))          # List of all names in the module's namespace
```

## Advanced Module Reloading and Profiling

Sometimes during development, you might want to reload a module after modifying it without restarting the Python interpreter. We can also profile the memory usage using `tracemalloc`.

```python
import importlib
import tracemalloc
import mymath
from contextlib import contextmanager
from typing import Generator, Any

@contextmanager
def profile_memory() -> Generator[None, None, None]:
    """Context manager to profile memory usage of a block of code."""
    tracemalloc.start()
    try:
        yield
    finally:
        current, peak = tracemalloc.get_traced_memory()
        print(f"Memory -> Current: {current / 10**6:.4f}MB; Peak: {peak / 10**6:.4f}MB")
        tracemalloc.stop()

def reload_example() -> None:
    """Demonstrates safe module reloading inside a memory profile."""
    with profile_memory():
        # Suppose mymath.py was modified externally...
        importlib.reload(mymath)
        print("Module successfully reloaded.")
```

### Exercise 1: Create a String Utilities Module
```python
# string_utils.py
"""String utility functions with full type annotations."""

def reverse(s: str) -> str:
    """Reverses a given string."""
    return s[::-1]

def count_vowels(s: str) -> int:
    """Counts the number of vowels in a string."""
    return sum(1 for c in s.lower() if c in "aeiou")

def is_palindrome(s: str) -> bool:
    """Checks if a string is a palindrome, ignoring non-alphanumeric chars."""
    cleaned: str = ''.join(c.lower() for c in s if c.isalnum())
    return cleaned == cleaned[::-1]

if __name__ == "__main__":
    print(reverse("hello"))
    print(count_vowels("hello"))
    print(is_palindrome("A man a plan a canal Panama"))
```

### Exercise 2: Date Utilities with `async` and Context Managers
```python
# date_utils.py
import asyncio
from datetime import datetime, timedelta
from typing import Optional

async def days_until_async(date_string: str) -> int:
    """Asynchronously calculate days until a given date."""
    # Simulate a delay (e.g. fetching external holiday API)
    await asyncio.sleep(0.1)
    target: datetime = datetime.strptime(date_string, "%Y-%m-%d")
    return (target - datetime.now()).days

def is_weekend(date: Optional[datetime] = None) -> bool:
    """Checks if a given date (or today) is a weekend."""
    if date is None:
        date = datetime.now()
    return date.weekday() >= 5

async def main_async() -> None:
    """Run async date utilities."""
    days: int = await days_until_async("2030-01-01")
    print(f"Days until 2030: {days}")

if __name__ == "__main__":
    asyncio.run(main_async())
```

## ✅ Check Your Understanding

1. **What makes a Python file a module?**
   - Any `.py` file containing Python code can be imported and treated as a module.
2. **What does `if __name__ == "__main__":` do?**
   - It acts as an entry point, ensuring the code block inside only runs if the file is executed directly (not when imported).
3. **What is `__all__` used for?**
   - It explicitly defines the public API of a module, controlling which names are exported when a user does `from module import *`.
4. **How do you reload a module dynamically?**
   - Use `importlib.reload(module)`.
5. **How can you profile a module's memory footprint?**
   - Use the built-in `tracemalloc` library inside a custom `@contextmanager`.
