## Basic Import

When you import a module, Python executes all the top-level code in the module.

```python
"""Basic import demonstrations with type annotations."""
import math
from typing import Any

def demonstrate_basic_imports() -> None:
    """Shows basic import usage."""
    # Import entire module
    print(math.pi)
    print(math.sqrt(16.0))

# Import specific items
from math import pi, sqrt

def use_specific_imports() -> float:
    """Uses specific imported items."""
    return sqrt(pi)

# Import with alias
import math as m

def use_aliased_imports() -> float:
    """Uses aliased module imports."""
    return m.pi

from math import pi as PI

def use_aliased_item() -> float:
    """Uses an aliased specific item."""
    return PI

if __name__ == "__main__":
    demonstrate_basic_imports()
```

## Import Patterns

```python
"""Good and bad import patterns."""
from typing import Any, Optional
from datetime import datetime, timedelta
from collections import Counter, defaultdict, OrderedDict, deque
import os
import sys
import json

# Good: Import module with alias (standard community conventions)
import numpy as np
import pandas as pd

# Avoid: Import everything (pollutes namespace and confuses tooling)
# from math import *  # Don't do this!

def type_annotated_function(data: list[int]) -> dict[str, int]:
    """Uses grouped imports from collections."""
    return dict(Counter(data))
```

## How Imports Work (sys.path & sys.modules)

Python maintains a cache of imported modules in `sys.modules`. 

```python
import sys
from typing import Any

def inspect_imports() -> list[str]:
    """
    Returns the first few paths where Python looks for modules.
    Python searches in this order:
    1. sys.modules (cache of already loaded modules)
    2. Built-in modules
    3. sys.path directories:
       - Current directory
       - PYTHONPATH
       - Installation-dependent defaults
    """
    return sys.path[:5]

def check_if_loaded(module_name: str) -> bool:
    """Checks if a module is already loaded in the cache."""
    return module_name in sys.modules
```

## Advanced & Dynamic Imports

Python provides the `importlib` module to programmatically import modules at runtime.

```python
"""Advanced import strategies using importlib."""
import importlib
from types import ModuleType
from typing import Optional

def safe_dynamic_import(module_name: str) -> Optional[ModuleType]:
    """
    Safely imports a module dynamically using importlib.
    
    Args:
        module_name: The string name of the module to import.
        
    Returns:
        The imported module object, or None if it fails.
    """
    try:
        module: ModuleType = importlib.import_module(module_name)
        print(f"Successfully imported {module_name}")
        return module
    except ImportError as e:
        print(f"Failed to import {module_name}: {e}")
        return None

if __name__ == "__main__":
    json_mod = safe_dynamic_import("json")
    non_existent = safe_dynamic_import("non_existent_module_123")
```

## Async Imports & Lazy Loading

In modern Python apps, you may want to avoid loading heavy modules until they are actually needed (lazy loading) to speed up application startup. While Python doesn't have true "async imports", we can simulate lazy loading or offload heavy imports using thread pools in async applications.

```python
import asyncio
import importlib
from types import ModuleType
from typing import Any

async def load_heavy_module_async(module_name: str) -> ModuleType:
    """
    Simulates importing a heavy module asynchronously by offloading
    the import blocking call to a thread pool.
    """
    loop = asyncio.get_running_loop()
    # importlib.import_module can be blocking (I/O reading files)
    module: ModuleType = await loop.run_in_executor(
        None, importlib.import_module, module_name
    )
    return module

async def main() -> None:
    """Main async execution."""
    print("Starting async import task...")
    sys_mod = await load_heavy_module_async("sys")
    print(f"Loaded module: {sys_mod.__name__}")

if __name__ == "__main__":
    asyncio.run(main())
```

## ✅ Check Your Understanding

1. **What is the difference between `import module` and `from module import item`?**
   - `import module` loads the module and keeps it in its own namespace. `from module import item` brings specific items directly into the current namespace.
2. **Why should you avoid `from module import *`?**
   - It pollutes the current namespace, increases the risk of naming collisions, and makes it impossible for static type checkers to know where a name came from.
3. **What is `sys.path` and `sys.modules`?**
   - `sys.path` is the list of directories Python searches to find a module. `sys.modules` is a dictionary caching all currently loaded modules.
4. **How do you import a module dynamically?**
   - Use the `importlib.import_module(module_name)` function.
