## Full Source Code

This modernized example uses asynchronous I/O to fetch data efficiently, strict type annotations, and a custom context manager for handling the HTTP client lifecycle.

```python
# weather_app.py
"""A modern asynchronous command-line weather application using OpenWeatherMap API."""

import asyncio
import os
import time
from dataclasses import dataclass
from datetime import datetime
from functools import lru_cache
from typing import Any, AsyncGenerator, Dict, Optional, Self

try:
    import httpx
except ImportError:
    print("Please install httpx: pip install httpx")
    exit(1)


@dataclass(frozen=True)
class WeatherData:
    """Dataclass representing the parsed weather data."""
    city: str
    country: str
    temp: float
    feels_like: float
    humidity: int
    description: str
    wind_speed: float
    
    @classmethod
    def from_api_response(cls, data: dict[str, Any]) -> Self:
        """Create a WeatherData instance from the raw JSON response."""
        return cls(
            city=data["name"],
            country=data["sys"]["country"],
            temp=data["main"]["temp"],
            feels_like=data["main"]["feels_like"],
            humidity=data["main"]["humidity"],
            description=data["weather"][0]["description"],
            wind_speed=data["wind"]["speed"]
        )


class RequestTimer:
    """A custom context manager to measure HTTP request latency."""
    def __init__(self) -> None:
        self.start_time: float = 0.0

    def __enter__(self) -> Self:
        self.start_time = time.perf_counter()
        return self

    def __exit__(self, exc_type: Any, exc_val: Any, exc_tb: Any) -> None:
        elapsed = time.perf_counter() - self.start_time
        print(f"[Timer] Request took {elapsed:.3f} seconds.")


class WeatherApp:
    """Asynchronous client for the OpenWeatherMap API."""
    def __init__(self, api_key: Optional[str] = None) -> None:
        self.api_key: str = api_key or os.getenv("OPENWEATHER_API_KEY", "")
        self.base_url: str = "https://api.openweathermap.org/data/2.5/weather"
        self._client: Optional[httpx.AsyncClient] = None

        if not self.api_key:
            raise ValueError("API key required. Set OPENWEATHER_API_KEY environment variable.")

    async def __aenter__(self) -> Self:
        """Asynchronous context manager entry."""
        self._client = httpx.AsyncClient(timeout=10.0)
        return self

    async def __aexit__(self, exc_type: Any, exc_val: Any, exc_tb: Any) -> None:
        """Asynchronous context manager exit."""
        if self._client:
            await self._client.aclose()

    @lru_cache(maxsize=128)
    def _build_params(self, city: str, units: str = "metric") -> tuple[tuple[str, str], ...]:
        """
        Helper method demonstrating functools.lru_cache.
        Note: lru_cache requires unhashable types to be converted to hashable types (like tuples).
        """
        return (("q", city), ("appid", self.api_key), ("units", units))

    async def get_weather(self, city: str, units: str = "metric") -> WeatherData | dict[str, str]:
        """Fetch weather data for a city asynchronously."""
        if not self._client:
            raise RuntimeError("Client not initialized. Use async with context manager.")
            
        params = dict(self._build_params(city, units))

        try:
            with RequestTimer():
                response = await self._client.get(self.base_url, params=params)
                response.raise_for_status()
            
            data = response.json()
            return WeatherData.from_api_response(data)
        except httpx.RequestError as e:
            return {"error": f"Request failed: {e}"}
        except httpx.HTTPStatusError as e:
            return {"error": f"HTTP status error: {e.response.status_code}"}
        except KeyError as e:
            return {"error": f"Unexpected response structure: missing {e}"}

    def display_weather(self, result: WeatherData | dict[str, str]) -> None:
        """Display weather information to the console."""
        if isinstance(result, dict) and "error" in result:
            print(f"Error: {result['error']}")
            return

        if isinstance(result, WeatherData):
            print(f"\n=== Weather in {result.city}, {result.country} ===")
            print(f"Temperature: {result.temp}°C")
            print(f"Feels like: {result.feels_like}°C")
            print(f"Condition: {result.description.capitalize()}")
            print(f"Humidity: {result.humidity}%")
            print(f"Wind speed: {result.wind_speed} m/s")
            print(f"Updated: {datetime.now().strftime('%Y-%m-%d %H:%M')}")


async def main() -> None:
    try:
        # Using async context manager to ensure graceful client shutdown
        async with WeatherApp() as app:
            while True:
                city = input("\nEnter city name (or 'q' to quit): ").strip()

                if city.lower() == 'q':
                    print("Goodbye!")
                    break

                if not city:
                    print("Please enter a city name.")
                    continue

                print("Fetching weather...")
                data = await app.get_weather(city)
                app.display_weather(data)

    except ValueError as e:
        print(f"Setup error: {e}")
        print("\nTo get an API key:")
        print("1. Visit https://openweathermap.org/api")
        print("2. Sign up for a free account")
        print("3. Set your API key: export OPENWEATHER_API_KEY=your_key")
        print("   (On Windows PowerShell: $env:OPENWEATHER_API_KEY=\"your_key\")")

if __name__ == "__main__":
    # Python 3.7+ high-level API to run async applications
    asyncio.run(main())
```

## Deep Dives & Modern Python Features

### 1. Async / Await & `httpx`
In a traditional synchronous app (using `requests`), your program halts execution while waiting for the network response. For a simple CLI, this is fine, but in web servers or desktop GUIs, blocking the main thread creates a frozen UI or bottlenecks. 
- Using `asyncio` and `httpx.AsyncClient`, the code yields execution back to the event loop while waiting for the network.
- Notice the `async with WeatherApp() as app:` block. We implemented an asynchronous context manager (`__aenter__` and `__aexit__`) to safely initialize and tear down the HTTP connection pool.

### 2. Custom Context Managers
We created `RequestTimer`, a custom synchronous context manager.
- `__enter__` starts a timer and returns control to the block.
- `__exit__` catches the end of the block (or an exception) and calculates the elapsed time. This pattern is ideal for releasing locks, timing events, or safely closing files.

### 3. Type Annotations & `dataclasses`
We utilized `typing` features like `Self`, `Optional`, and structural unions (`WeatherData | dict[str, str]`).
- The `WeatherData` dataclass makes it explicitly clear what attributes exist. Setting `frozen=True` makes it immutable, improving thread-safety and providing hashability.

### 4. `functools.lru_cache`
The `_build_params` method uses `@lru_cache(maxsize=128)` from `functools`. While building dictionaries is cheap, this pattern illustrates how to cache expensive computations or string manipulations based on arguments. Because dictionaries are unhashable, we return a tuple of tuples, which is hashable and can be memoized, then convert it back to a `dict` at call time.

### 5. `itertools` Considerations
For a 5-day forecast containing lists of dictionaries (e.g., 3-hour interval reports), `itertools.groupby` can be utilized to group responses by date to find daily highs and lows.

### 6. Global Interpreter Lock (PEP 703)
Python 3.13 introduces experimental support for removing the Global Interpreter Lock (GIL) via PEP 703. In a multi-threaded weather dashboard fetching hundreds of cities simultaneously, a GIL-less Python environment would allow true parallel execution using standard threads rather than having to rely strictly on `asyncio` or `multiprocessing`.

| Bug | Cause | Fix |
|-----|-------|-----|
| API key error | Missing or invalid key | Check environment variable |
