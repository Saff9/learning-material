## 🛠️ Modern Python 3.12+ Concepts

### 1. Advanced Concurrency and PEP 703 (No-GIL)
In web scraping, I/O bound concurrency is critical. We typically use `asyncio`. However, with **PEP 703 (Making the Global Interpreter Lock Optional in CPython)** (experimental in 3.13, discussed in 3.12+), true multithreaded web scrapers parsing CPU-heavy DOM trees in parallel will see massive performance gains.
- Use `asyncio` for network I/O bounds (fetching).
- Use `concurrent.futures.ThreadPoolExecutor` or multiprocessing for CPU bounds (BeautifulSoup parsing) — this landscape evolves significantly with No-GIL.

### 2. Functional Tools (`itertools` & `functools`)
When parsing hundreds of pages, functional programming concepts help process data streams elegantly:
- `itertools.chain.from_iterable()` to flatten lists of scraped articles.
- `itertools.batched()` (Python 3.12+) to cleanly chunk URLs into scraping batches.
- `functools.lru_cache` to cache `robots.txt` lookups for domains.

### 3. Custom Context Managers
We use custom async context managers (with `__aenter__` and `__aexit__`) to encapsulate our HTTP sessions, ensuring graceful resource cleanup even if exceptions occur.

## 💻 Full Source Code: Modern Async Web Scraper

```python
# web_scraper.py
"""
A modern, asynchronous web scraper utilizing Python 3.12+ features,
strict type annotations, and custom context managers.

Requirements:
    pip install aiohttp beautifulsoup4
"""

import asyncio
import csv
import urllib.robotparser
from functools import lru_cache
from itertools import batched
from typing import Any, Optional
from urllib.parse import urlparse

import aiohttp
from bs4 import BeautifulSoup


class ScraperContext:
    """A custom asynchronous context manager for handling aiohttp sessions."""
    
    def __init__(self, headers: dict[str, str] | None = None) -> None:
        self.headers: dict[str, str] = headers or {"User-Agent": "ModernAsyncScraper/1.0"}
        self.session: Optional[aiohttp.ClientSession] = None

    async def __aenter__(self) -> aiohttp.ClientSession:
        """Initialize and return the session."""
        self.session = aiohttp.ClientSession(headers=self.headers)
        return self.session

    async def __aexit__(self, exc_type: Any, exc_val: Any, exc_tb: Any) -> None:
        """Ensure the session is properly closed on exit."""
        if self.session:
            await self.session.close()


@lru_cache(maxsize=128)
def get_robot_parser(domain: str) -> urllib.robotparser.RobotFileParser:
    """
    Caches the robots.txt parser for each domain to avoid redundant network calls.
    """
    rp = urllib.robotparser.RobotFileParser()
    rp.set_url(f"{domain}/robots.txt")
    try:
        rp.read()
    except Exception as e:
        print(f"Failed to read robots.txt for {domain}: {e}")
    return rp


def can_fetch(url: str, user_agent: str = "*") -> bool:
    """Check if the URL is allowed by the domain's robots.txt."""
    parsed_url = urlparse(url)
    domain = f"{parsed_url.scheme}://{parsed_url.netloc}"
    rp = get_robot_parser(domain)
    # If robots.txt couldn't be fetched, assume allowed to proceed
    return rp.can_fetch(user_agent, url) if rp.mtime() != 0 else True


async def fetch_html(session: aiohttp.ClientSession, url: str, delay: float = 1.0) -> str | None:
    """Fetch HTML content asynchronously with a polite delay."""
    if not can_fetch(url):
        print(f"Scraping disallowed for {url}")
        return None

    await asyncio.sleep(delay)
    try:
        async with session.get(url, timeout=10) as response:
            response.raise_for_status()
            return await response.text()
    except aiohttp.ClientError as e:
        print(f"Error fetching {url}: {e}")
        return None


def parse_articles(html: str, selector: str) -> list[dict[str, str]]:
    """Parse HTML and extract articles using BeautifulSoup."""
    soup = BeautifulSoup(html, "html.parser")
    articles: list[dict[str, str]] = []

    for item in soup.select(selector):
        title = item.get_text(strip=True)
        link_val = item.get("href", "")
        
        # Handle cases where link might be a list
        link = link_val[0] if isinstance(link_val, list) else link_val
            
        articles.append({"title": title, "link": str(link)})

    return articles


async def scrape_urls(urls: list[str], selector: str, batch_size: int = 5) -> list[dict[str, str]]:
    """Scrape a list of URLs concurrently in batches using itertools.batched (Python 3.12+)."""
    all_articles: list[dict[str, str]] = []
    
    async with ScraperContext() as session:
        # Using Python 3.12+ batched to group URLs
        for batch in batched(urls, batch_size):
            tasks = [fetch_html(session, url) for url in batch]
            html_results = await asyncio.gather(*tasks)
            
            for html in html_results:
                if html:
                    all_articles.extend(parse_articles(html, selector))
                    
    return all_articles


def save_to_csv(data: list[dict[str, str]], filename: str) -> None:
    """Save parsed data to a CSV file."""
    if not data:
        print("No data to save.")
        return

    fieldnames = list(data[0].keys())
    with open(filename, 'w', newline='', encoding='utf-8') as f:
        writer = csv.DictWriter(f, fieldnames=fieldnames)
        writer.writeheader()
        writer.writerows(data)
    print(f"Saved {len(data)} items to {filename}")


async def main() -> None:
    """Main execution entry point."""
    # Example urls for demonstration
    urls = [
        "https://example.com/page/1",
        "https://example.com/page/2"
    ]
    selector = "a"  # CSS selector for extracting links
    
    print("Starting async scraping...")
    articles = await scrape_urls(urls, selector, batch_size=2)
    
    if articles:
        save_to_csv(articles, "articles.csv")
        print("Sample of extracted articles:")
        for article in articles[:3]:
            print(f"- {article['title']}: {article['link']}")
            
if __name__ == "__main__":
    # Standard Python 3.7+ way to run top-level async code
    asyncio.run(main())
```

## 🧠 Deep Dives

### `async` / `await` & Concurrency
By utilizing `aiohttp` and `asyncio.gather()`, we issue multiple network requests concurrently without blocking the main execution thread. This dramatically reduces total execution time when waiting for slow server responses compared to standard synchronous `requests`.

### `itertools.batched`
Python 3.12 introduced `itertools.batched()`. Instead of slicing lists manually via list comprehensions (`urls[i:i+n]`), `batched` provides a clean, memory-efficient way to group our concurrent tasks into manageable chunks. This prevents us from overwhelming the target server with too many simultaneous requests.

### `functools.lru_cache`
We cache the `urllib.robotparser.RobotFileParser` instance based on the domain using `@lru_cache`. This ensures we only fetch, read, and parse a domain's `robots.txt` file once per process, saving network bandwidth and execution time.

### Custom Context Managers
`ScraperContext` is an asynchronous context manager (utilizing `__aenter__` and `__aexit__`). It properly encapsulates the lifecycle of an `aiohttp.ClientSession`, ensuring that background resources (like open TCP sockets) are closed safely, even if exceptions occur during the scraping loop.

## Common Bugs and Fixes

| Bug | Cause | Fix |
|-----|-------|-----|
| Empty results | Wrong CSS selector | Inspect HTML structure in browser DevTools |
| Blocked by site | Missing User-Agent | Use custom headers via `ScraperContext` |
| RuntimeError (Event Loop) | Missing `asyncio.run()` | Start the script with `asyncio.run(main())` |
| `AttributeError` on batched | Pre-Python 3.12 | Upgrade Python or implement a custom chunker generator |
