## Complex Types & Generics (Python 3.12+ PEP 695)

Python 3.12 introduced a new, cleaner syntax for type aliases and generic functions/classes using the `type` statement and type parameter syntax.

```python
# Modern type alias syntax (Python 3.12+)
type Number = int | float
type UserMap = dict[str, int]

# Generic function (Python 3.12+)
def first_element[T](items: list[T]) -> T | None:
    """Returns the first element of a list, or None if empty."""
    return items[0] if items else None

# Optional and Union modern syntax (using `|`)
def find_user(user_id: int) -> str | None:
    if user_id == 1:
        return "Alice"
    return None

def process_identifier(value: str | int) -> str:
    return str(value)
```

## `TypedDict` and `Protocol`

Structural duck typing via `Protocol`, and typed dictionaries for JSON-like data.

```python
from typing import TypedDict, Protocol, override

class UserDict(TypedDict):
    id: int
    username: str
    active: bool

user_data: UserDict = {"id": 1, "username": "alice123", "active": True}

# Structural Subtyping (Duck Typing)
class Logger(Protocol):
    def log(self, message: str) -> None:
        ...

class ConsoleLogger:
    def log(self, message: str) -> None:
        print(f"[LOG]: {message}")

def do_work(logger: Logger) -> None:
    logger.log("Work started")

# ConsoleLogger structurally matches Logger; no inheritance needed.
do_work(ConsoleLogger())
```

## Advanced Function Type Hints

```python
from collections.abc import Callable
from typing import Any

# Function taking a Callable as parameter
def apply_operation(a: int, b: int, operation: Callable[[int, int], int]) -> int:
    return operation(a, b)

# Variable and Keyword arguments
def sum_all(*numbers: int) -> int:
    return sum(numbers)

def create_user(**kwargs: str) -> dict[str, str]:
    return kwargs
```

## Object-Oriented Type Hints

Using `@override` (Python 3.12+) to guarantee method overrides.

```python
from typing import override

class Person:
    def __init__(self, name: str, age: int) -> None:
        self.name: str = name
        self.age: int = age

    def greet(self) -> str:
        return f"Hello, I am {self.name}"

class Employee(Person):
    def __init__(self, name: str, age: int, role: str) -> None:
        super().__init__(name, age)
        self.role: str = role

    @override
    def greet(self) -> str:
        return f"{super().greet()} and I am a {self.role}."

class Team:
    def __init__(self, name: str) -> None:
        self.name: str = name
        self.members: list[Person] = []

    def add_member(self, person: Person) -> None:
        self.members.append(person)
```

### Exercise 2: Typed API Response Parser
```python
from typing import TypedDict, Any

class APIResponse(TypedDict):
    status: int
    data: list[dict[str, Any]]
    message: str | None

def parse_response(response: APIResponse) -> list[str]:
    """Extracts names from an API response."""
    if response["status"] != 200:
        return []
    
    names: list[str] = []
    for item in response["data"]:
        if "name" in item and isinstance(item["name"], str):
            names.append(item["name"])
    return names

resp: APIResponse = {
    "status": 200, 
    "data": [{"name": "Alice"}, {"name": "Bob"}], 
    "message": "Success"
}
print(parse_response(resp))
```
