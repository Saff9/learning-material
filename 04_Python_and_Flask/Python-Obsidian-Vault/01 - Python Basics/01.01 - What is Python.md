## What is Python?

Python is a **high-level, interpreted, general-purpose programming language** created by Guido van Rossum and first released in 1991. It emphasizes code readability and simplicity, making it an excellent choice for beginners and experienced developers alike.

### Key Characteristics & Modern Evolution

| Feature | Description |
|---------|-------------|
| **Interpreted** | Code runs line-by-line without compilation (though compiled to bytecode internally). |
| **Dynamically Typed** | Variable types are determined at runtime, but modern Python heavily leverages **static type hints**. |
| **Object-Oriented** | Everything in Python is an object. |
| **High-Level** | Abstracts away low-level machine details. |
| **The GIL & PEP 703** | Historically constrained by the Global Interpreter Lock (GIL). Python 3.13+ introduces experimental free-threading (PEP 703) to run threads in parallel without the GIL. |

### Advanced Python Features (3.12+ Standard)

Python has evolved significantly. Modern Python development relies on async/await, robust type hinting, context managers, and high-performance collections.

#### 1. Async/Await Deep Dive
Modern asynchronous programming allows I/O-bound tasks to run concurrently using an event loop.

```python
import asyncio
from typing import Any

async def fetch_data(url: str, delay: int | float = 1.0) -> dict[str, Any]:
    """
    Simulates fetching data from a web API asynchronously.
    """
    print(f"Fetching {url}...")
    await asyncio.sleep(delay)
    return {"url": url, "status": 200, "data": "Success"}

async def async_deep_dive() -> None:
    """
    Demonstrates asyncio.gather and modern task execution.
    """
    urls: list[str] = [
        "https://api.example.com/users",
        "https://api.example.com/posts"
    ]
    
    # Run tasks concurrently using asyncio.gather
    print("Starting concurrent fetches...")
    results: list[dict[str, Any]] = await asyncio.gather(
        *(fetch_data(url) for url in urls)
    )
    
    for result in results:
        print(f"Received: {result}")

if __name__ == "__main__":
    asyncio.run(async_deep_dive())
```

#### 2. Custom Context Managers
Context managers (`with` statements) ensure resources are properly acquired and released.

```python
from typing import Any
from collections.abc import Generator
from contextlib import contextmanager
import time

# Approach 1: Class-based context manager
class Timer:
    """
    A custom context manager to measure execution time.
    """
    def __init__(self, name: str) -> None:
        self.name: str = name
        self.start_time: float | None = None

    def __enter__(self) -> 'Timer':
        self.start_time = time.perf_counter()
        print(f"[{self.name}] Timer started.")
        return self
        
    def __exit__(self, exc_type: type[BaseException] | None, exc_val: BaseException | None, exc_tb: Any | None) -> None:
        if self.start_time is not None:
            elapsed = time.perf_counter() - self.start_time
            print(f"[{self.name}] Timer stopped. Elapsed time: {elapsed:.4f} seconds.")

# Approach 2: Generator-based context manager
@contextmanager
def file_handler_mock(filename: str) -> Generator[str, None, None]:
    """
    Mock file handler demonstrating @contextmanager.
    """
    print(f"Opening {filename}...")
    try:
        yield f"<File content of {filename}>"
    finally:
        print(f"Closing {filename}...")

def run_context_managers() -> None:
    """Demonstrates context manager usage."""
    with Timer("MyTask"):
        time.sleep(0.1)
        
    with file_handler_mock("test.txt") as content:
        print(f"Read: {content}")

if __name__ == "__main__":
    run_context_managers()
```

#### 3. Advanced Collections, itertools, and Profiling
Python provides robust built-ins for data processing and profiling (e.g., `tracemalloc`).

```python
import itertools
import collections
import tracemalloc
from collections.abc import Iterator

def data_processing_demo() -> None:
    """
    Demonstrates itertools, collections, and memory profiling.
    """
    # Start tracing memory allocations
    tracemalloc.start()
    
    # 1. Collections: Counter
    words: list[str] = ["apple", "banana", "apple", "cherry", "banana", "apple"]
    word_counts: collections.Counter[str] = collections.Counter(words)
    print("Word Counts:", word_counts)
    
    # 2. itertools: combination and chaining
    letters: list[str] = ['A', 'B']
    numbers: list[int] = [1, 2]
    chained: Iterator[str | int] = itertools.chain(letters, numbers)
    print("Chained:", list(chained))
    
    combinations: list[tuple[str, str]] = list(itertools.combinations(letters + ['C'], 2))
    print("Combinations:", combinations)
    
    # Display memory usage
    current, peak = tracemalloc.get_traced_memory()
    print(f"Memory Usage - Current: {current / 1024:.2f} KB | Peak: {peak / 1024:.2f} KB")
    tracemalloc.stop()

if __name__ == "__main__":
    data_processing_demo()
```
