## Basic Lambda and Callable Types

Lambdas are single-expression, anonymous functions. We annotate them using `collections.abc.Callable` or `typing.Callable`.

```python
from collections.abc import Callable

# Regular function
def add_func(x: int, y: int) -> int:
    """Adds two integers."""
    return x + y

# Equivalent lambda
add_lambda: Callable[[int, int], int] = lambda x, y: x + y

print(add_lambda(3, 5))  # 8
```

## Common Uses with Iterables

```python
# With sorted
words: list[str] = ["banana", "pie", "Washington"]
sorted_by_length: list[str] = sorted(words, key=lambda x: len(x))

# With map
numbers: list[int] = [1, 2, 3, 4]
squares: list[int] = list(map(lambda x: x**2, numbers))

# With filter
evens: list[int] = list(filter(lambda x: x % 2 == 0, numbers))
```

## 🚀 Advanced: Functools, Itertools, and Collections

Functional programming in Python relies heavily on these standard library modules.

### `functools`

```python
from functools import reduce, partial, lru_cache
from typing import Any

# reduce: repeatedly applies a function to sequence elements
product: int = reduce(lambda x, y: x * y, numbers)

# partial: freezes some arguments of a function
multiply: Callable[[int, int], int] = lambda a, b: a * b
double: Callable[[int], int] = partial(multiply, 2)
print(double(4))  # 8

# lru_cache: memoizes results for expensive function calls
@lru_cache(maxsize=128)
def fibonacci(n: int) -> int:
    """Calculates Fibonacci with memoization."""
    if n < 2: return n
    return fibonacci(n-1) + fibonacci(n-2)
```

### `itertools`

```python
import itertools

# Infinite iterators, chaining, combinations
counter = itertools.count(10, 2)  # 10, 12, 14...
chained = itertools.chain([1, 2], ["A", "B"])
perms = list(itertools.permutations([1, 2, 3], 2))
```

### `collections` Module Primitives

```python
from collections import Counter, defaultdict, deque

# Counter: dict subclass for counting hashable objects
tally = Counter(["apple", "banana", "apple"])
print(tally["apple"])  # 2

# defaultdict: assigns default values for missing keys
dd: dict[str, int] = defaultdict(int)
dd["missing_key"] += 1

# deque: Double-ended queue, O(1) appends and pops from both ends
queue: deque[int] = deque([1, 2, 3])
queue.appendleft(0)
```

## 🧠 Advanced: Memory Profiling (tracemalloc)

When working with heavy functional pipelines or generators vs lists, memory consumption matters. Use `tracemalloc` to track allocations.

```python
import tracemalloc

def memory_profiled_task() -> None:
    """Profiles memory usage of list comprehension vs map/generator."""
    tracemalloc.start()
    
    # Large memory allocation (List Comprehension)
    large_list: list[int] = [x**2 for x in range(1000000)]
    
    current, peak = tracemalloc.get_traced_memory()
    print(f"Current memory usage is {current / 10**6:.2f}MB; Peak was {peak / 10**6:.2f}MB")
    tracemalloc.stop()

# memory_profiled_task()
```
