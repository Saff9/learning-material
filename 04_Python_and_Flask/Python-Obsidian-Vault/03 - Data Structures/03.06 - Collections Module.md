## 📦 The `collections` Module

### `Counter` (Multisets)
`Counter` tracks frequencies of hashable objects.

```python
from collections import Counter
from typing import Iterable, Any

def analyze_frequencies[T](items: Iterable[T]) -> Counter[T]:
    """Returns a frequency map of items."""
    counts: Counter[T] = Counter(items)
    return counts

colors: list[str] = ["red", "blue", "red", "green", "blue", "blue"]
color_counts: Counter[str] = analyze_frequencies(colors)

print(color_counts.most_common(2))  # [('blue', 3), ('red', 2)]

# Math operations on Counters
c1: Counter[str] = Counter(a=3, b=1)
c2: Counter[str] = Counter(a=1, b=2)
print(c1 + c2)  # Counter({'a': 4, 'b': 3})
print(c1 - c2)  # Counter({'a': 2})
```

### `defaultdict`
Provides a default value for missing keys, eliminating `KeyError`.

```python
from collections import defaultdict

def group_by_first_letter(words: list[str]) -> defaultdict[str, list[str]]:
    """Groups words by their starting letter."""
    groups: defaultdict[str, list[str]] = defaultdict(list)
    for word in words:
        if word:
            groups[word[0]].append(word)
    return groups

words: list[str] = ["apple", "apricot", "banana", "blueberry", "cherry"]
print(dict(group_by_first_letter(words)))
```

### `deque` (Double-Ended Queue)
Thread-safe, O(1) appends and pops from both ends.

```python
from collections import deque
from typing import Generator, Iterable

def sliding_window[T](items: Iterable[T], size: int) -> Generator[list[T], None, None]:
    """Yields a sliding window of size `size` over the items."""
    window: deque[T] = deque(maxlen=size)
    for item in items:
        window.append(item)
        if len(window) == size:
            yield list(window)

print(list(sliding_window(range(5), 3)))  # [[0, 1, 2], [1, 2, 3], [2, 3, 4]]
```

### `OrderedDict` vs `dict`
While standard `dict` maintains insertion order since Python 3.7, `OrderedDict` provides order-specific operations like `move_to_end()` and equality checks that respect order.

```python
from collections import OrderedDict

class SimpleLRU[K, V]:
    """A basic Least Recently Used (LRU) Cache."""
    def __init__(self, capacity: int) -> None:
        self.cache: OrderedDict[K, V] = OrderedDict()
        self.capacity: int = capacity

    def get(self, key: K) -> V | None:
        """Retrieves a value and marks it as recently used."""
        if key not in self.cache:
            return None
        self.cache.move_to_end(key)
        return self.cache[key]

    def put(self, key: K, value: V) -> None:
        """Inserts a key-value pair and evicts the oldest if capacity is reached."""
        if key in self.cache:
            self.cache.move_to_end(key)
        self.cache[key] = value
        if len(self.cache) > self.capacity:
            self.cache.popitem(last=False)
```

## 🛠️ Itertools and Functools

### `itertools`: Lazy Iteration
`itertools` provides memory-efficient loop abstractions.

```python
import itertools

def demo_itertools() -> None:
    """Demonstrates itertools functionality."""
    # Chain multiple iterables lazily
    combined = itertools.chain([1, 2], [3, 4])
    
    # Group consecutive identical items
    data: list[tuple[str, int]] = [("A", 1), ("A", 2), ("B", 3)]
    grouped = {k: list(g) for k, g in itertools.groupby(data, key=lambda x: x[0])}
    
    # Running totals
    totals = list(itertools.accumulate([1, 2, 3, 4])) # [1, 3, 6, 10]
```

### `functools`: Higher-Order Functions
Tools for manipulating callable objects.

```python
from functools import lru_cache, partial, reduce

@lru_cache(maxsize=128)
def fibonacci(n: int) -> int:
    """Memoized Fibonacci function."""
    if n < 2:
        return n
    return fibonacci(n-1) + fibonacci(n-2)

# Partial application
def multiply(a: int, b: int) -> int:
    return a * b

double = partial(multiply, 2)
print(double(5))  # 10
```

## ⚡ Async Deep Dive & Context Managers

Using collections and files in an asynchronous context with custom context managers.

```python
import asyncio
from typing import AsyncGenerator, Any

class AsyncMetricsContext:
    """An asynchronous context manager for measuring execution time."""
    def __init__(self, name: str) -> None:
        self.name: str = name
        self.start_time: float = 0.0

    async def __aenter__(self) -> 'AsyncMetricsContext':
        self.start_time = asyncio.get_event_loop().time()
        print(f"Starting async task: {self.name}")
        return self

    async def __aexit__(self, exc_type: type[BaseException] | None, exc_val: BaseException | None, traceback: Any) -> None:
        elapsed = asyncio.get_event_loop().time() - self.start_time
        print(f"Finished {self.name} in {elapsed:.4f}s")

async def process_data_stream() -> AsyncGenerator[int, None]:
    """Simulates an async data stream."""
    for i in range(3):
        await asyncio.sleep(0.1)
        yield i

async def main() -> None:
    async with AsyncMetricsContext("StreamProcessing"):
        async for data in process_data_stream():
            print(f"Processed: {data}")

# asyncio.run(main())
```

## 🧠 Memory Profiling & Architecture

### Memory Footprint Analysis
Using `sys.getsizeof` and `tracemalloc` to understand memory overhead.

```python
import sys
import tracemalloc

def analyze_memory() -> None:
    tracemalloc.start()
    
    # Compare memory footprints
    l: list[int] = [1, 2, 3]
    t: tuple[int, ...] = (1, 2, 3)
    
    print(f"List size: {sys.getsizeof(l)} bytes")
    print(f"Tuple size: {sys.getsizeof(t)} bytes")
    
    current, peak = tracemalloc.get_traced_memory()
    print(f"Current memory usage is {current / 1024:.2f}KB; Peak was {peak / 1024:.2f}KB")
    tracemalloc.stop()
```

### PEP 703: The GIL Evolution & Free-Threading
Historically, CPython uses the **Global Interpreter Lock (GIL)**, preventing multiple native threads from executing Python bytecodes at once.

**PEP 703 (Python 3.13+)** introduces a build option to disable the GIL (Free-Threading).
- **Impact**: Pure Python code using multithreading will genuinely run in parallel across CPU cores.
- **Thread Safety**: Built-in collections (like `list`, `dict`) are being updated to use finer-grained locking internally to remain thread-safe without the GIL.
- **`deque`**: Always thread-safe for atomic appends/pops, making it ideal for message queues between threads regardless of the GIL.
