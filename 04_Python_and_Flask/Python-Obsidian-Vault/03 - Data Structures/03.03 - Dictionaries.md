## Creating Dictionaries

Dictionaries in Python map hashable keys to values. Modern Python relies heavily on type hints.

```python
from typing import Dict, Any, Mapping

# Empty dictionary with explicit type
empty_dict: dict[str, int] = {}

# With values
person: dict[str, Any] = {"name": "Alice", "age": 25, "city": "NYC"}

# Using dict()
person2: dict[str, Any] = dict(name="Bob", age=30)

# From pairs
pairs: list[tuple[str, int]] = [("a", 1), ("b", 2)]
d: dict[str, int] = dict(pairs)

# Dictionary comprehension
squares: dict[int, int] = {x: x**2 for x in range(5)}
```

## Accessing and Modifying

```python
from typing import Any

person: dict[str, Any] = {"name": "Alice", "age": 25}

# Safe access
salary: int = person.get("salary", 0)  # 0 (default)

# Python 3.9+ dictionary union operator
new_info: dict[str, Any] = {"email": "alice@example.com", "age": 26}
updated_person: dict[str, Any] = person | new_info  # Merge dictionaries

# In-place update
person |= {"phone": "555-1234", "city": "LA"}
```

## `collections` Deep Dive

The `collections` module provides specialized dictionary variants.

```python
from collections import defaultdict, Counter, ChainMap
from typing import DefaultDict

# 1. defaultdict: Automates handling missing keys
by_length: DefaultDict[int, list[str]] = defaultdict(list)
words: list[str] = ["apple", "bat", "car", "dolphin", "elephant"]

for word in words:
    by_length[len(word)].append(word)

# 2. Counter: Specialized for counting hashable objects
text: str = "hello world hello python"
word_counts: Counter[str] = Counter(text.split())
print(word_counts.most_common(2))  # [('hello', 2), ('world', 1)]

# 3. ChainMap: Groups multiple dicts into a single view (O(1) creation)
defaults: dict[str, str] = {"theme": "light", "show_index": "yes"}
user_prefs: dict[str, str] = {"theme": "dark"}

config: ChainMap[str, str] = ChainMap(user_prefs, defaults)
print(config["theme"])  # 'dark' (from user_prefs)
print(config["show_index"])  # 'yes' (from defaults)
```

## Advanced Iteration & Comprehensions

Using `itertools` and `functools` for dictionary operations.

```python
import itertools
import functools
from typing import Iterable

data: list[dict[str, str | int]] = [
    {"group": "A", "val": 10},
    {"group": "B", "val": 20},
    {"group": "A", "val": 30},
]

# Sort before grouping (required for itertools.groupby)
data.sort(key=lambda x: x["group"])

# Grouping dictionaries by a key
grouped: dict[str, list[dict[str, str | int]]] = {
    k: list(g) for k, g in itertools.groupby(data, key=lambda x: x["group"])
}

# Functools to reduce dictionaries (merge a list of dicts)
dicts: list[dict[str, int]] = [{"a": 1}, {"b": 2}, {"c": 3}]
merged: dict[str, int] = functools.reduce(lambda d1, d2: d1 | d2, dicts)
```

## Async Operations and Dictionaries

In modern concurrent Python (using `asyncio`), you might fetch data asynchronously and construct dictionaries using async comprehensions.

```python
import asyncio
from typing import Dict

async def fetch_user_data(user_id: int) -> str:
    """Simulates an I/O bound network fetch."""
    await asyncio.sleep(0.1)
    return f"User_{user_id}"

async def build_user_dict(user_ids: list[int]) -> dict[int, str]:
    """Builds a dictionary asynchronously using async comprehensions."""
    # Async comprehension (Python 3.6+)
    users: dict[int, str] = {
        uid: await fetch_user_data(uid)
        for uid in user_ids
    }
    return users

# To run:
# asyncio.run(build_user_dict([1, 2, 3]))
```

## Custom Context Managers for Dictionaries

Context managers can be used to manage dictionary states, e.g., temporarily modifying a configuration dictionary and restoring it later.

```python
from contextlib import contextmanager
from typing import Iterator, Any

@contextmanager
def temp_dict_update(d: dict[str, Any], **kwargs: Any) -> Iterator[None]:
    """Temporarily updates a dictionary and restores it afterwards."""
    original_state: dict[str, Any] = {k: d[k] for k in kwargs if k in d}
    added_keys: set[str] = set(kwargs.keys()) - set(d.keys())
    
    d.update(kwargs)
    try:
        yield
    finally:
        # Restore original values
        d.update(original_state)
        # Remove newly added keys
        for key in added_keys:
            del d[key]

# Usage:
config: dict[str, str] = {"env": "prod", "debug": "false"}

with temp_dict_update(config, debug="true", new_key="test"):
    print(f"Inside block: {config}")  # debug is true, new_key present

print(f"Outside block: {config}")  # Restored to original
```

## Memory Profiling and Free-Threading (PEP 703)

### Dictionary Memory Footprint
Python dictionaries are highly optimized via key-sharing and compact representations (since Python 3.6). To profile memory:

```python
import sys

d: dict[str, int] = {f"key_{i}": i for i in range(1000)}
print(f"Size of dict: {sys.getsizeof(d)} bytes")
```

### GIL and PEP 703 (Free-Threading)
Historically, the Global Interpreter Lock (GIL) ensured thread safety for built-in types like `dict` during concurrent access.
PEP 703 (No-GIL build, expected in Python 3.13+) fundamentally changes this:
- **Lock-free Reads**: Reading from dictionaries remains safe and concurrent.
- **Concurrent Mutations**: In free-threaded Python, if two threads mutate the same dictionary, race conditions could corrupt internal state or yield inconsistent results unless explicit locks (e.g., `threading.Lock`) are used.
- **Performance Trade-offs**: To enable free-threading without the GIL, dictionaries rely on per-object locking or atomic reference counting, which may introduce slight single-threaded overhead but enables massive multi-core scaling for dict-heavy parallel algorithms.

### Exercise: Robust Word Counter
Use `collections.Counter` to write an asynchronous file processor that counts words.

```python
import asyncio
from collections import Counter

async def count_words(text: str) -> Counter[str]:
    await asyncio.sleep(0.01) # Simulate async read
    return Counter(text.lower().split())

async def main() -> None:
    texts: list[str] = ["hello world", "python is great", "hello python"]
    
    counts: Counter[str] = Counter()
    for text in texts:
        counts += await count_words(text)
        
    print(counts)
```
