## Basic If Statement

```python
def check_adult(age: int) -> None:
    """Checks if the given age represents an adult."""
    if age >= 18:
        print("You are an adult!")

check_adult(18)
```

## If-Else

```python
def check_temperature(temperature: int | float) -> None:
    """Evaluates temperature and prints a corresponding message."""
    if temperature > 30:
        print("It is hot!")
    else:
        print("It is not too hot.")

check_temperature(25.5)
```

## If-Elif-Else

```python
def calculate_grade(score: int | float) -> str:
    """Calculates a letter grade based on a numerical score."""
    grade: str
    if score >= 90:
        grade = "A"
    elif score >= 80:
        grade = "B"
    elif score >= 70:
        grade = "C"
    elif score >= 60:
        grade = "D"
    else:
        grade = "F"
    return grade

print(f"Grade: {calculate_grade(85)}")
```

## Nested If Statements

```python
def calculate_discount(is_member: bool, purchase_amount: float) -> float:
    """Calculates discount based on membership and purchase amount."""
    discount: float = 0.0
    if is_member:
        if purchase_amount > 100.0:
            discount = 0.20
        else:
            discount = 0.10
    return discount

print(f"Discount: {calculate_discount(True, 150.0) * 100}%")
```

## Truthy and Falsy Values

```python
from typing import Any

def evaluate_truthiness(val: Any) -> None:
    """Evaluates and prints the truthiness of a value."""
    if not val:
        print(f"{repr(val)} is falsy")
    else:
        print(f"{repr(val)} is truthy")

evaluate_truthiness(None)
evaluate_truthiness("")
evaluate_truthiness([1, 2])
```

## Ternary Operator

```python
def get_status(age: int) -> str:
    """Returns status using a ternary operator."""
    return "adult" if age >= 18 else "minor"

print(get_status(20))
```

## 🚀 Advanced Topics

### Async/Await Deep Dive in Conditionals
When working with async IO, conditionals are often used to branch logic based on asynchronous results.

```python
import asyncio

async def fetch_data(condition: bool) -> dict[str, Any] | None:
    """Fetches data asynchronously based on a condition."""
    if condition:
        await asyncio.sleep(0.1)  # Simulate IO
        return {"status": "success", "data": [1, 2, 3]}
    return None

async def main() -> None:
    """Main event loop execution."""
    result: dict[str, Any] | None = await fetch_data(True)
    if result and result.get("status") == "success":
        print("Data fetched successfully!")

asyncio.run(main())
```

### Context Managers and Conditionals
Custom context managers can use conditionals to determine how setup and teardown should occur.

```python
from contextlib import contextmanager
from typing import Iterator

@contextmanager
def conditional_transaction(commit: bool) -> Iterator[None]:
    """A context manager that commits or rolls back based on a condition."""
    print("Starting transaction...")
    try:
        yield
    finally:
        if commit:
            print("Committing transaction...")
        else:
            print("Rolling back transaction...")

with conditional_transaction(commit=True):
    print("Executing operations...")
```

### Deep Dive: GIL (PEP 703) and Conditionals
With the evolution of Python and the introduction of PEP 703 (Making the Global Interpreter Lock Optional in CPython), condition checks on shared mutable state (like global flags) in multi-threaded environments might require explicit locking mechanisms if the GIL is disabled, whereas previously the GIL provided implicit atomic checks for certain bytecodes. Using `threading.Lock` inside conditionals is recommended for future-proofing free-threaded Python.

```python
import threading

lock = threading.Lock()
shared_counter: int = 0

def thread_safe_increment(condition: bool) -> None:
    """Increments a counter safely across threads."""
    global shared_counter
    if condition:
        with lock:
            shared_counter += 1
```

### Memory Profiling (`tracemalloc`)
Conditionals can control memory allocation paths. We can profile this:

```python
import tracemalloc

def profile_allocation(allocate: bool) -> list[int]:
    """Profiles memory allocation based on a conditional."""
    tracemalloc.start()
    data: list[int] = []
    if allocate:
        data = [i for i in range(100000)]
    
    current, peak = tracemalloc.get_traced_memory()
    print(f"Current memory: {current / 10**6}MB; Peak: {peak / 10**6}MB")
    tracemalloc.stop()
    return data
```
