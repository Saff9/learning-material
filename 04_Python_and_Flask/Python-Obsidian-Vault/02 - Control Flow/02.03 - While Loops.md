## Basic While Loop

```python
def countdown(count: int) -> None:
    """Counts down from a specified number to zero."""
    while count > 0:
        print(count)
        count -= 1

countdown(3)
```

## User Input Validation

```python
def get_valid_password(target: str) -> str:
    """Prompts until the correct password is provided."""
    # Note: In a real system, never use plain input like this for passwords
    password: str = ""
    while password != target:
        password = input("Enter password: ")
    return password
```

## While with Else

```python
def search_items(items: list[int], target: int) -> None:
    """Searches for a target, using the while-else construct."""
    index: int = 0
    while index < len(items):
        if items[index] == target:
            print(f"Found {target} at {index}")
            break
        index += 1
    else:
        print("Item not found!")

search_items([1, 2, 3], 5)
```

## 🚀 Advanced Topics

### Async While Loops and Event Loops
In asynchronous programming, `while` loops are frequently used to poll for conditions or consume streams.

```python
import asyncio

async def worker(task_name: str, duration: int) -> None:
    """An async task that loops until duration expires."""
    elapsed: int = 0
    while elapsed < duration:
        print(f"Task {task_name} running...")
        await asyncio.sleep(1)
        elapsed += 1

async def main() -> None:
    """Gathers multiple while-loop tasks concurrently."""
    await asyncio.gather(
        worker("A", 2),
        worker("B", 3)
    )

asyncio.run(main())
```

### Memory Profiling in Infinite Loops (`tracemalloc`)
Memory leaks in `while True` daemon loops are a common issue. You can use `tracemalloc` to detect them.

```python
import tracemalloc
import time

def monitor_memory_loop(iterations: int) -> None:
    """A loop that tracks memory allocation across iterations."""
    tracemalloc.start()
    storage: list[int] = []
    
    count: int = 0
    while count < iterations:
        storage.extend([i for i in range(1000)])
        current, peak = tracemalloc.get_traced_memory()
        print(f"Iter {count}: Current {current / 10**3}KB, Peak {peak / 10**3}KB")
        count += 1
        
    tracemalloc.stop()

monitor_memory_loop(3)
```

### Context Managers and While Loops
Using context managers to ensure resources are held during the loop lifecycle.

```python
from contextlib import contextmanager
from typing import Iterator

@contextmanager
def loop_session(name: str) -> Iterator[None]:
    """Manages a session for a long-running loop."""
    print(f"Starting session {name}")
    try:
        yield
    finally:
        print(f"Ending session {name}")

def run_session(limit: int) -> None:
    with loop_session("main_loop"):
        i: int = 0
        while i < limit:
            i += 1
```

### GIL and Multithreading in While Loops
Under the current GIL, CPU-bound `while` loops prevent other threads from running Python bytecodes, though IO-bound tasks release the GIL. With PEP 703 (free-threaded CPython), polling loops must safely synchronize shared state (e.g., using locks) since concurrent writes could corrupt data structures that used to rely on atomic bytecode operations.
