## Basic For Loop

```python
def print_fruits(fruits: list[str]) -> None:
    """Prints each fruit in a given list."""
    for fruit in fruits:
        print(fruit)

print_fruits(["apple", "banana", "cherry"])
```

## The `range()` Function

```python
def range_examples() -> None:
    """Demonstrates different usages of range."""
    # range(stop)
    for i in range(5):
        print(i)
    
    # range(start, stop, step)
    for i in range(0, 10, 2):
        print(i)
```

## Using `enumerate()`

```python
def print_enumerated_colors(colors: list[str]) -> None:
    """Prints colors with their index."""
    for index, color in enumerate(colors, start=1):
        print(f"{index}: {color}")

print_enumerated_colors(["red", "green", "blue"])
```

## Looping Over Dictionaries

```python
from typing import Any

def iterate_dict(person: dict[str, Any]) -> None:
    """Demonstrates dictionary iteration."""
    for key, value in person.items():
        print(f"{key}: {value}")

iterate_dict({"name": "Alice", "age": 25, "city": "NYC"})
```

## 🚀 Advanced Topics

### Async Iteration (`async for`)
Python provides async loops for consuming asynchronous generators or streams.

```python
import asyncio
from typing import AsyncIterator

async def async_generator() -> AsyncIterator[int]:
    """Yields integers asynchronously."""
    for i in range(3):
        await asyncio.sleep(0.1)
        yield i

async def consume() -> None:
    """Consumes an async generator."""
    async for num in async_generator():
        print(num)

asyncio.run(consume())
```

### Deep Dive: `itertools` and `functools`
For high-performance loops, standard libraries like `itertools` provide memory-efficient iterators.

```python
import itertools
from functools import reduce

def itertools_example() -> None:
    """Uses itertools for cartesian products and infinite iterators."""
    colors: list[str] = ["red", "blue"]
    sizes: list[str] = ["S", "M"]
    
    # Cartesian product
    for c, s in itertools.product(colors, sizes):
        print(f"{c} - {s}")
        
    # reduce example
    numbers: list[int] = [1, 2, 3, 4]
    total: int = reduce(lambda x, y: x + y, numbers)
    print(f"Total: {total}")

itertools_example()
```

### Context Managers inside Loops
Use context managers to safely handle resources per iteration.

```python
from contextlib import contextmanager
from typing import Iterator

@contextmanager
def file_processor(filename: str) -> Iterator[None]:
    """Context manager mock for processing a file."""
    print(f"Opening {filename}")
    try:
        yield
    finally:
        print(f"Closing {filename}")

def process_files(files: list[str]) -> None:
    for f in files:
        with file_processor(f):
            print(f"Processing content of {f}")

process_files(["file1.txt", "file2.txt"])
```

### Python GIL and Multithreaded Loops (PEP 703)
With the proposed removal of the GIL in PEP 703, multi-threaded CPU-bound for loops will see true parallelism. Currently, in standard CPython, heavily computational loops run on a single thread at a time unless using `multiprocessing` or native C extensions.
