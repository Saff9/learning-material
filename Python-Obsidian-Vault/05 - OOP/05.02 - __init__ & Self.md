## The `__init__` Method

`__init__` is the constructor method called automatically when a new object is created.

```python
class Person:
    def __init__(self, name, age):
        print(f"Creating person: {name}")
        self.name = name
        self.age = age

p = Person("Alice", 25)  # Prints: Creating person: Alice
```

## Understanding `self`

`self` is a reference to the current instance. It's passed automatically.

```python
class Counter:
    def __init__(self):
        self.count = 0  # self refers to the new instance

    def increment(self):
        self.count += 1  # Modify this instance's count
        return self.count

c1 = Counter()
c2 = Counter()

print(c1.increment())  # 1
print(c1.increment())  # 2
print(c2.increment())  # 1 (independent!)
```

## Default Parameters in __init__

```python
class Vehicle:
    def __init__(self, make, model, year=2024, color="black"):
        self.make = make
        self.model = model
        self.year = year
        self.color = color
        self.odometer = 0

car = Vehicle("Toyota", "Camry")
truck = Vehicle("Ford", "F-150", 2023, "red")
```

## Validation in __init__

```python
class Temperature:
    def __init__(self, celsius):
        if celsius < -273.15:
            raise ValueError("Below absolute zero!")
        self.celsius = celsius

    def to_fahrenheit(self):
        return (self.celsius * 9/5) + 32

temp = Temperature(25)
print(temp.to_fahrenheit())  # 77.0
```

## Class Methods as Alternative Constructors

```python
class Date:
    def __init__(self, year, month, day):
        self.year = year
        self.month = month
        self.day = day

    @classmethod
    def from_string(cls, date_string):
        year, month, day = map(int, date_string.split("-"))
        return cls(year, month, day)

    @classmethod
    def today(cls):
        import datetime
        now = datetime.datetime.now()
        return cls(now.year, now.month, now.day)

d1 = Date(2024, 1, 15)
d2 = Date.from_string("2024-03-20")
d3 = Date.today()
```

## 🧪 Practice

### Exercise 1: Rectangle with Validation
```python
class Rectangle:
    def __init__(self, width, height):
        if width <= 0 or height <= 0:
            raise ValueError("Dimensions must be positive")
        self.width = width
        self.height = height

    def area(self):
        return self.width * self.height

    def perimeter(self):
        return 2 * (self.width + self.height)

rect = Rectangle(5, 3)
print(f"Area: {rect.area()}, Perimeter: {rect.perimeter()}")
```

### Exercise 2: Employee with Class Method
```python
class Employee:
    def __init__(self, name, salary):
        self.name = name
        self.salary = salary

    @classmethod
    def from_dict(cls, data):
        return cls(data["name"], data["salary"])

    def info(self):
        return f"{self.name}: ${self.salary}"

emp = Employee.from_dict({"name": "Alice", "salary": 50000})
print(emp.info())
```
