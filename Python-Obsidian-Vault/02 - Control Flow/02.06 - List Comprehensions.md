## Basic List Comprehension

```python
# Traditional way
squares = []
for x in range(10):
    squares.append(x ** 2)

# List comprehension
squares = [x ** 2 for x in range(10)]
```

## With Condition (Filter)

```python
# Even numbers only
evens = [x for x in range(20) if x % 2 == 0]

# Numbers divisible by 3
multiples_of_3 = [x for x in range(30) if x % 3 == 0]
```

## With If-Else

```python
# Label numbers as even/odd
labels = ["even" if x % 2 == 0 else "odd" for x in range(10)]
```

## Nested Comprehensions

```python
# Flatten a matrix
matrix = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]
flat = [x for row in matrix for x in row]
# [1, 2, 3, 4, 5, 6, 7, 8, 9]

# Transpose
transpose = [[row[i] for row in matrix] for i in range(3)]
# [[1, 4, 7], [2, 5, 8], [3, 6, 9]]
```

## Dictionary Comprehension

```python
# Squares dictionary
squares_dict = {x: x**2 for x in range(6)}
# {0: 0, 1: 1, 2: 4, 3: 9, 4: 16, 5: 25}

# From two lists
keys = ["a", "b", "c"]
values = [1, 2, 3]
combined = {k: v for k, v in zip(keys, values)}
```

## Set Comprehension

```python
# Unique lengths
words = ["apple", "banana", "cherry", "date"]
lengths = {len(w) for w in words}
# {4, 5, 6}
```

## Generator Expression

```python
# Like list comprehension but lazy
sum_of_squares = sum(x**2 for x in range(1000000))
# No list created in memory!
```

## 🧪 Practice

### Exercise 1: Filter and Transform
```python
# Get lengths of words starting with 'a'
words = ["apple", "banana", "avocado", "cherry", "apricot"]
a_lengths = [len(w) for w in words if w.startswith("a")]
print(a_lengths)  # [5, 7, 7]
```

### Exercise 2: Number Categories
```python
numbers = range(20)
categories = ["small" if n < 5 else "medium" if n < 15 else "large" for n in numbers]
```

### Exercise 3: Cartesian Product
```python
colors = ["red", "green", "blue"]
sizes = ["S", "M", "L"]
products = [(c, s) for c in colors for s in sizes]
```

### Exercise 4: Character Frequency
```python
text = "hello world"
freq = {char: text.count(char) for char in set(text) if char != " "}
```
