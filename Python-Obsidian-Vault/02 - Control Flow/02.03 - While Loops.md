## Basic While Loop

```python
count = 0

while count < 5:
    print(count)
    count += 1
```

## User Input Validation

```python
password = ""

while password != "secret":
    password = input("Enter password: ")

print("Access granted!")
```

## Menu System

```python
while True:
    print("\n1. Play game")
    print("2. Settings")
    print("3. Quit")

    choice = input("Select: ")

    if choice == "1":
        print("Starting game...")
    elif choice == "2":
        print("Opening settings...")
    elif choice == "3":
        print("Goodbye!")
        break
    else:
        print("Invalid choice!")
```

## While with Else

```python
# else runs when loop completes normally (no break)
count = 0

while count < 3:
    print(count)
    count += 1
else:
    print("Loop completed!")

# With break, else does not run
while count < 5:
    if count == 10:  # Never true
        break
    count += 1
else:
    print("This will not print if break occurs")
```

## Counter-Controlled While Loop

```python
# Factorial calculation
n = 5
factorial = 1
counter = n

while counter > 0:
    factorial *= counter
    counter -= 1

print(f"{n}! = {factorial}")
```

## Sentinel-Controlled Loop

```python
# Keep adding numbers until user enters 0
total = 0

while True:
    num = int(input("Enter number (0 to quit): "))
    if num == 0:
        break
    total += num

print(f"Total: {total}")
```

## 🧪 Practice

### Exercise 1: Guess the Number
```python
import random

secret = random.randint(1, 100)
guesses = 0

while True:
    guess = int(input("Guess (1-100): "))
    guesses += 1

    if guess == secret:
        print(f"Correct! Took {guesses} guesses.")
        break
    elif guess < secret:
        print("Too low!")
    else:
        print("Too high!")
```

### Exercise 2: Password Attempts
```python
attempts = 3

while attempts > 0:
    password = input("Password: ")
    if password == "python123":
        print("Welcome!")
        break
    attempts -= 1
    print(f"{attempts} attempts remaining.")
else:
    print("Account locked!")
```

### Exercise 3: Number Reversal
```python
num = int(input("Enter a number: "))
reversed_num = 0

while num > 0:
    digit = num % 10
    reversed_num = reversed_num * 10 + digit
    num //= 10

print(f"Reversed: {reversed_num}")
```

### Exercise 4: Collatz Sequence
```python
n = int(input("Enter a positive integer: "))

while n != 1:
    print(n, end=" -> ")
    if n % 2 == 0:
        n //= 2
    else:
        n = n * 3 + 1

print(1)
```
