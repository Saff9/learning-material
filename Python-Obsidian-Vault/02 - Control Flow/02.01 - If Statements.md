---

## Basic If Statement

```python
age = 18

if age >= 18:
    print("You are an adult!")
```

## If-Else

```python
temperature = 25

if temperature > 30:
    print("It is hot!")
else:
    print("It is not too hot.")
```

## If-Elif-Else

```python
score = 85

if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
elif score >= 60:
    grade = "D"
else:
    grade = "F"

print(f"Grade: {grade}")
```

## Nested If Statements

```python
is_member = True
purchase_amount = 150

if is_member:
    if purchase_amount > 100:
        discount = 0.20
    else:
        discount = 0.10
else:
    discount = 0.0

print(f"Discount: {discount * 100}%")
```

## Truthy and Falsy Values

```python
# Falsy values
if not None: print("None is falsy")
if not 0: print("0 is falsy")
if not "": print("Empty string is falsy")
if not []: print("Empty list is falsy")
if not {}: print("Empty dict is falsy")

# Truthy values
if 42: print("Non-zero numbers are truthy")
if "hello": print("Non-empty strings are truthy")
if [1, 2]: print("Non-empty lists are truthy")
```

## Ternary Operator

```python
# One-line if-else
age = 20
status = "adult" if age >= 18 else "minor"
print(status)

# Equivalent to:
if age >= 18:
    status = "adult"
else:
    status = "minor"
```

## Logical Operators in Conditions

```python
username = "admin"
password = "secret123"

if username == "admin" and password == "secret123":
    print("Access granted!")
else:
    print("Access denied!")

# Using or
day = "Saturday"
if day == "Saturday" or day == "Sunday":
    print("It is the weekend!")
```

## ✅ Check Your Understanding

1. What is the difference between `if` and `elif`?
2. Can you have `elif` without `if`?
3. What values are considered "falsy" in Python?
4. How do you write a one-line if-else?
5. What is short-circuit evaluation?

**Answers:**
1. `if` starts a condition; `elif` checks another condition only if previous ones were false
2. No, `elif` must follow an `if`
3. None, 0, empty strings, empty collections, False
4. Using ternary: `value = a if condition else b`
5. `and`/`or` stop evaluating as soon as the result is determined
