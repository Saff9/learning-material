## Basic For Loop

```python
fruits = ["apple", "banana", "cherry"]

for fruit in fruits:
    print(fruit)
```

## The `range()` Function

```python
# range(stop)
for i in range(5):
    print(i)  # 0, 1, 2, 3, 4

# range(start, stop)
for i in range(2, 6):
    print(i)  # 2, 3, 4, 5

# range(start, stop, step)
for i in range(0, 10, 2):
    print(i)  # 0, 2, 4, 6, 8

# Negative step
for i in range(5, 0, -1):
    print(i)  # 5, 4, 3, 2, 1
```

## Looping Over Strings

```python
for char in "Python":
    print(char)
# P, y, t, h, o, n
```

## Using `enumerate()`

```python
colors = ["red", "green", "blue"]

for index, color in enumerate(colors):
    print(f"{index}: {color}")

# Start from 1
for index, color in enumerate(colors, start=1):
    print(f"{index}: {color}")
```

## Looping Over Dictionaries

```python
person = {"name": "Alice", "age": 25, "city": "NYC"}

# Keys
for key in person:
    print(key)

# Values
for value in person.values():
    print(value)

# Both
for key, value in person.items():
    print(f"{key}: {value}")
```

## Multiple Iterables with `zip()`

```python
names = ["Alice", "Bob", "Charlie"]
ages = [25, 30, 35]

for name, age in zip(names, ages):
    print(f"{name} is {age} years old")
```

## Nested For Loops

```python
# Multiplication table
for i in range(1, 4):
    for j in range(1, 4):
        print(f"{i} x {j} = {i*j}")
    print("---")
```

## 🧪 Practice

### Exercise 1: Sum of Numbers
```python
total = 0
for num in range(1, 101):
    total += num
print(f"Sum: {total}")  # 5050
```

### Exercise 2: Find Maximum
```python
numbers = [3, 7, 2, 9, 1, 5]
maximum = numbers[0]

for num in numbers:
    if num > maximum:
        maximum = num

print(f"Maximum: {maximum}")
```

### Exercise 3: Count Vowels
```python
text = "Hello, World!"
vowels = "aeiouAEIOU"
count = 0

for char in text:
    if char in vowels:
        count += 1

print(f"Vowels: {count}")
```

### Exercise 4: Pattern Printing
```python
n = 5
for i in range(1, n + 1):
    print("*" * i)
```
