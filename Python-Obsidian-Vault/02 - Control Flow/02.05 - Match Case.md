## Basic Match Case

```python
http_status = 200

match http_status:
    case 200:
        print("OK")
    case 404:
        print("Not Found")
    case 500:
        print("Server Error")
    case _:
        print("Unknown status")
```

## Matching with Or

```python
day = "Saturday"

match day:
    case "Saturday" | "Sunday":
        print("Weekend!")
    case "Monday" | "Tuesday" | "Wednesday" | "Thursday" | "Friday":
        print("Weekday")
    case _:
        print("Invalid day")
```

## Matching Variables

```python
point = (3, 4)

match point:
    case (0, 0):
        print("Origin")
    case (x, 0):
        print(f"On x-axis at {x}")
    case (0, y):
        print(f"On y-axis at {y}")
    case (x, y):
        print(f"Point at ({x}, {y})")
```

## Matching Lists/Sequences

```python
command = ["move", 10, 20]

match command:
    case ["quit"]:
        print("Quitting...")
    case ["move", x, y]:
        print(f"Moving to ({x}, {y})")
    case ["circle", radius]:
        print(f"Drawing circle with radius {radius}")
    case _:
        print("Unknown command")
```

## Matching Dictionaries

```python
user = {"name": "Alice", "role": "admin"}

match user:
    case {"name": str(name), "role": "admin"}:
        print(f"Admin: {name}")
    case {"name": str(name), "role": "user"}:
        print(f"User: {name}")
    case {"name": str(name)}:
        print(f"Guest: {name}")
```

## Guards (Conditions)

```python
age = 25

match age:
    case n if n < 0:
        print("Invalid age")
    case n if n < 13:
        print("Child")
    case n if n < 20:
        print("Teenager")
    case n if n < 65:
        print("Adult")
    case _:
        print("Senior")
```

## 🧪 Practice

### Exercise 1: Calculator with Match
```python
num1 = float(input("First number: "))
operator = input("Operator (+, -, *, /): ")
num2 = float(input("Second number: "))

match operator:
    case "+":
        result = num1 + num2
    case "-":
        result = num1 - num2
    case "*":
        result = num1 * num2
    case "/":
        result = num1 / num2 if num2 != 0 else "Error"
    case _:
        result = "Invalid operator"

print(f"Result: {result}")
```

### Exercise 2: Shape Area
```python
shape = input("Shape (circle, rectangle, triangle): ")

match shape:
    case "circle":
        radius = float(input("Radius: "))
        area = 3.14159 * radius ** 2
    case "rectangle":
        width = float(input("Width: "))
        height = float(input("Height: "))
        area = width * height
    case "triangle":
        base = float(input("Base: "))
        height = float(input("Height: "))
        area = 0.5 * base * height
    case _:
        area = "Unknown shape"

print(f"Area: {area}")
```

### Exercise 3: HTTP Method Handler
```python
method = "GET"
path = "/users"

match (method, path):
    case ("GET", "/users"):
        print("List all users")
    case ("GET", "/users/" + id):
        print(f"Get user {id}")
    case ("POST", "/users"):
        print("Create new user")
    case ("DELETE", "/users/" + id):
        print(f"Delete user {id}")
    case _:
        print("404 Not Found")
```
