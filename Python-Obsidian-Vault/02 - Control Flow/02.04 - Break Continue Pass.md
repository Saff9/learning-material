## The `break` Statement

Exits the loop immediately.

```python
# Find first even number
numbers = [1, 3, 5, 8, 9, 10]

for num in numbers:
    if num % 2 == 0:
        print(f"Found even number: {num}")
        break
```

```python
# Search in list
fruits = ["apple", "banana", "cherry", "date"]

for fruit in fruits:
    if fruit == "cherry":
        print("Found cherry!")
        break
else:
    print("Cherry not found")  # Runs if no break
```

## The `continue` Statement

Skips the rest of the current iteration.

```python
# Print only odd numbers
for num in range(10):
    if num % 2 == 0:
        continue
    print(num)  # 1, 3, 5, 7, 9
```

```python
# Skip empty strings
names = ["Alice", "", "Bob", "", "Charlie"]

for name in names:
    if not name:
        continue
    print(f"Hello, {name}!")
```

## The `pass` Statement

Does nothing - used as a placeholder.

```python
# Placeholder for future code
def function_not_implemented():
    pass  # TODO: implement this

class FutureFeature:
    pass

# Empty loop body
for i in range(5):
    pass  # Will do something later
```

## Combined Example

```python
# Process orders, skip invalid, stop at end of day
orders = ["order1", "INVALID", "order2", "END", "order3"]

for order in orders:
    if order == "END":
        print("End of day reached!")
        break

    if order == "INVALID":
        print("Skipping invalid order...")
        continue

    print(f"Processing: {order}")
```

## 🧪 Practice

### Exercise 1: Prime Checker
```python
num = int(input("Enter a number: "))

is_prime = True
for i in range(2, int(num**0.5) + 1):
    if num % i == 0:
        is_prime = False
        break

print(f"{num} is {'prime' if is_prime else 'not prime'}")
```

### Exercise 2: Filter and Sum
```python
numbers = [3, -1, 5, -2, 8, -4, 10]
total = 0

for num in numbers:
    if num < 0:
        continue
    total += num

print(f"Sum of positive numbers: {total}")
```

### Exercise 3: Menu with Pass
```python
while True:
    print("\n1. Feature A (coming soon)")
    print("2. Feature B (active)")
    print("3. Quit")

    choice = input("Select: ")

    if choice == "1":
        pass  # Not implemented yet
        print("Feature A is coming in v2.0!")
    elif choice == "2":
        print("Running Feature B...")
    elif choice == "3":
        break
```

### Exercise 4: Nested Loop Break
```python
# Find first pair that sums to 10
found = False
for i in range(5):
    for j in range(5):
        if i + j == 10:
            print(f"Found: {i} + {j} = 10")
            found = True
            break
    if found:
        break
```
