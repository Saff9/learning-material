## Variables

Variables are containers for storing data values.

```python
# Creating variables
name = "Alice"
age = 25
height = 1.75
is_student = True

# Python is dynamically typed
x = 5        # int
x = "hello"  # now it is a string
```

### Naming Rules

```python
# Valid names
my_var = 1
myVar = 2
_my_var = 3
MY_VAR = 4  # constant convention
my_var2 = 5

# Invalid names
# 2myvar = 1    # starts with number
# my-var = 2    # contains hyphen
# my var = 3    # contains space
# class = 4     # reserved keyword
```

### Naming Conventions (PEP 8)

```python
# snake_case for variables and functions
user_name = "Alice"

# PascalCase for classes
class UserProfile:
    pass

# UPPER_CASE for constants
MAX_CONNECTIONS = 100

# _prefix for internal use
_internal_var = "private-ish"
```

## Data Types

### 1. Integers (`int`)

```python
age = 25
negative = -10
big_number = 1_000_000  # underscores for readability

print(type(age))  # <class 'int'>
```

### 2. Floating Point (`float`)

```python
pi = 3.14159
price = 19.99
scientific = 1.5e-3  # 0.0015

print(type(pi))  # <class 'float'>
```

### 3. Strings (`str`)

```python
# Different ways to create strings
name = "Alice"
message = 'Hello'
multiline = """This is
a multiline
string"""

# String operations
full_name = "Alice" + " " + "Smith"  # concatenation
repeated = "Ha" * 3                   # "HaHaHa"
length = len("Hello")                 # 5

# String methods
upper = "hello".upper()      # "HELLO"
lower = "WORLD".lower()      # "world"
strip = "  hello  ".strip()  # "hello"
```

### 4. Booleans (`bool`)

```python
is_active = True
is_deleted = False

# Boolean operations
result = True and False   # False
result = True or False    # True
result = not True         # False
```

### 5. None Type (`NoneType`)

```python
value = None  # Represents absence of a value

print(value is None)  # True
print(type(value))    # <class 'NoneType'>
```

## Type Conversion (Casting)

```python
# String to int
num_str = "42"
num = int(num_str)  # 42

# Int to string
num = 42
num_str = str(num)  # "42"

# String to float
price_str = "19.99"
price = float(price_str)  # 19.99

# Int to float
x = 5
y = float(x)  # 5.0

# Float to int (truncates)
z = 3.9
w = int(z)  # 3 (not rounded!)

# To boolean
bool(1)     # True
bool(0)     # False
bool("")    # False
bool("hi")  # True
```

---

## Checking Types

```python
x = 42

print(type(x))           # <class 'int'>
print(isinstance(x, int))  # True
print(isinstance(x, (int, float)))  # True
```
