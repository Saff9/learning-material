## The `input()` Function

```python
# Basic input (always returns a string!)
name = input("Enter your name: ")
print(f"Hello, {name}!")

# Converting input to other types
age = int(input("Enter your age: "))
height = float(input("Enter your height in meters: "))

print(f"You are {age} years old and {height}m tall.")
```

### Important: Input is Always a String!

```python
# This will cause an error:
# num = input("Enter a number: ")
# result = num + 5  # TypeError!

# Correct way:
num = int(input("Enter a number: "))
result = num + 5
print(result)
```

## String Formatting

### Method 1: f-strings (Recommended)

```python
name = "Alice"
age = 25
pi = 3.14159

# Basic
print(f"My name is {name} and I am {age} years old.")

# Expressions inside
print(f"Next year I will be {age + 1}.")

# Formatting numbers
print(f"PI to 2 decimal places: {pi:.2f}")      # 3.14
print(f"PI to 4 decimal places: {pi:.4f}")      # 3.1416
print(f"Number with padding: {42:05d}")         # 00042
print(f"Percentage: {0.85:.1%}")                # 85.0%

# Alignment
print(f"{'Left':<10}|")   # Left      |
print(f"{'Right':>10}|")  #     Right |
print(f"{'Center':^10}|") #  Center   |
```

### Method 2: `.format()`

```python
print("My name is {} and I am {} years old.".format(name, age))
print("My name is {0} and I am {1} years old.".format(name, age))
print("My name is {n} and I am {a} years old.".format(n=name, a=age))
```

### Method 3: `%` Formatting (Old Style)

```python
print("My name is %s and I am %d years old." % (name, age))
print("PI = %.2f" % pi)
```

## Advanced Formatting

```python
# Number formatting
number = 1234567.89
print(f"{number:,.2f}")      # 1,234,567.89
print(f"{number:.2e}")       # 1.23e+06 (scientific)

# Binary, octal, hex
n = 42
print(f"Binary: {n:b}")      # 101010
print(f"Octal: {n:o}")       # 52
print(f"Hex: {n:x}")         # 2a
print(f"Hex: {n:X}")         # 2A

# Date formatting
from datetime import datetime
now = datetime.now()
print(f"Today is {now:%Y-%m-%d}")
print(f"Time: {now:%H:%M:%S}")
```

## Basic File I/O

```python
# Writing to a file
with open("output.txt", "w") as file:
    file.write("Hello, World!\n")
    file.write("This is line 2.\n")

# Reading from a file
with open("output.txt", "r") as file:
    content = file.read()
    print(content)

# Reading line by line
with open("output.txt", "r") as file:
    for line in file:
        print(line.strip())
```

### Exercise 2: Simple Calculator

### Exercise 3: Receipt Formatter
```python
item = input("Item name: ")
price = float(input("Price: $"))
quantity = int(input("Quantity: "))

total = price * quantity

print(f"\n{'RECEIPT':^30}")
print(f"{'='*30}")
print(f"{'Item:':<15} {item:>15}")
print(f"{'Price:':<15} ${price:>14.2f}")
print(f"{'Quantity:':<15} {quantity:>15}")
print(f"{'-'*30}")
print(f"{'Total:':<15} ${total:>14.2f}")
```

### Exercise 4: Save User Data

