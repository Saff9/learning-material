## Arithmetic Operators

```python
a = 10
b = 3

print(a + b)   # 13  (Addition)
print(a - b)   # 7   (Subtraction)
print(a * b)   # 30  (Multiplication)
print(a / b)   # 3.333... (Division - always float)
print(a // b)  # 3   (Floor Division)
print(a % b)   # 1   (Modulo - remainder)
print(a ** b)  # 1000 (Exponentiation)
```

### String Operations

```python
# Concatenation
"Hello" + " " + "World"  # "Hello World"

# Repetition
"Hi" * 3  # "HiHiHi"

# Cannot mix types!
# "Age: " + 25  # ERROR!
"Age: " + str(25)  # "Age: 25"
```

## Comparison Operators

```python
x = 5
y = 10

print(x == y)  # False (Equal to)
print(x != y)  # True  (Not equal to)
print(x > y)   # False (Greater than)
print(x < y)   # True  (Less than)
print(x >= y)  # False (Greater than or equal)
print(x <= y)  # True  (Less than or equal)
```

### Comparing Strings

```python
print("apple" == "apple")   # True
print("apple" < "banana")   # True (lexicographic order)
print("A" < "a")            # True (ASCII values)
```

---

## Logical Operators

```python
a = True
b = False

print(a and b)  # False (Both must be True)
print(a or b)   # True  (At least one True)
print(not a)    # False (Inverts boolean)

# Short-circuit evaluation
x = 5
print(x > 0 and x < 10)   # True
print(x < 0 or x > 3)     # True
print(not (x == 5))       # False
```

## Assignment Operators

```python
x = 5       # Basic assignment
x += 3      # x = x + 3  -> 8
x -= 2      # x = x - 2  -> 6
x *= 4      # x = x * 4  -> 24
x /= 3      # x = x / 3  -> 8.0
x //= 2     # x = x // 2 -> 4.0
x %= 3      # x = x % 3  -> 1.0
x **= 2     # x = x ** 2 -> 1.0
```

### Walrus Operator (`:=`) - Python 3.8+

```python
# Assign and use in one expression
if (n := len("hello")) > 3:
    print(f"Length is {n}")  # Length is 5

# Without walrus
n = len("hello")
if n > 3:
    print(f"Length is {n}")
```

## Identity and Membership Operators

```python
# Identity: is, is not
a = [1, 2, 3]
b = a
c = [1, 2, 3]

print(a is b)     # True (same object)
print(a is c)     # False (different objects)
print(a == c)     # True (same values)

# Membership: in, not in
fruits = ["apple", "banana", "cherry"]
print("apple" in fruits)      # True
print("grape" not in fruits)  # True

# String membership
text = "Hello, World!"
print("World" in text)  # True
```

## Bitwise Operators

```python
a = 5   # 101 in binary
b = 3   # 011 in binary

print(a & b)   # 1  (AND: 001)
print(a | b)   # 7  (OR: 111)
print(a ^ b)   # 6  (XOR: 110)
print(~a)      # -6 (NOT)
print(a << 1)  # 10 (Left shift: 1010)
print(a >> 1)  # 2  (Right shift: 10)
```

## Operator Precedence

Highest to lowest:

1. `()` - Parentheses
2. `**` - Exponentiation
3. `+x`, `-x`, `~x` - Unary
4. `*`, `/`, `//`, `%` - Multiplication/Division
5. `+`, `-` - Addition/Subtraction
6. `<<`, `>>` - Bitwise shifts
7. `&` - Bitwise AND
8. `^` - Bitwise XOR
9. `|` - Bitwise OR
10. `==`, `!=`, `>`, `<`, `>=`, `<=` - Comparisons
11. `not` - Logical NOT
12. `and` - Logical AND
13. `or` - Logical OR

```python
# Use parentheses for clarity!
result = (2 + 3) * 4  # 20, not 14
```
