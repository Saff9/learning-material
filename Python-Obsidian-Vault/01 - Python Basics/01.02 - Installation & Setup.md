## Installing Python

### Windows

1. Go to python.org and download the latest version
2. **IMPORTANT**: Check "Add Python to PATH" during installation
3. Verify installation:

```bash
python --version
# or
py --version
```

### macOS

Option 1 - Official Installer:
```bash
# Download from python.org or use Homebrew
brew install python
```

Option 2 - Using Homebrew:
```bash
brew install python
python3 --version
```

### Linux (Ubuntu/Debian)

```bash
sudo apt update
sudo apt install python3 python3-pip
python3 --version
```

---

## Setting Up VS Code

1. Download VS Code from code.visualstudio.com
2. Install the **Python extension** by Microsoft
3. Install the **Pylance** extension for better IntelliSense

### VS Code Settings

Create a `.vscode/settings.json` in your project:

```json
{
    "python.defaultInterpreterPath": "python3",
    "editor.formatOnSave": true,
    "editor.rulers": [79, 120]
}
```

## Running Python Code

### Method 1: Interactive Interpreter

```bash
python
# or
python3
```

```python
>>> print("Hello, World!")
Hello, World!
>>> 2 + 2
4
>>> exit()
```

### Method 2: Running a Script File

Create `hello.py`:

```python
# hello.py
print("Hello, World!")
name = input("What is your name? ")
print(f"Nice to meet you, {name}!")
```

Run it:
```bash
python hello.py
```

### Method 3: VS Code Integrated Terminal

Press `Ctrl + ~` (or `Cmd + ~` on Mac) to open the terminal inside VS Code.

## Understanding the Python Interpreter

```python
# The interpreter reads your code top-to-bottom
# It compiles to bytecode, then executes

# You can check the bytecode:
import dis

def example():
    x = 1 + 2
    return x

dis.dis(example)
```
