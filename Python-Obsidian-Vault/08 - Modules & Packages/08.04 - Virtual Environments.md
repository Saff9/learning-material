## What are Virtual Environments?

Virtual environments are isolated Python environments that allow you to manage dependencies for different projects separately.

## Creating a Virtual Environment

```bash
# Create environment
python -m venv myproject_env

# Or with specific Python version
python3 -m venv myproject_env
```

## Activating the Environment

```bash
# Linux/Mac
source myproject_env/bin/activate

# Windows (Command Prompt)
myproject_env\Scripts\activate.bat

# Windows (PowerShell)
myproject_env\Scripts\Activate.ps1
```

## Deactivating

```bash
deactivate
```

## Working with Environments

```bash
# After activation, pip installs into the environment
pip install requests numpy

# Check what is installed
pip list

# Save requirements
pip freeze > requirements.txt

# Install from requirements
pip install -r requirements.txt
```

## In Python Code

```python
import sys

# Check which Python is being used
print(sys.executable)

# Check path
print(sys.path)
```

## Using venv in Scripts

```python
import subprocess
import sys

def create_venv(env_name):
    subprocess.run([sys.executable, "-m", "venv", env_name])
    print(f"Created virtual environment: {env_name}")

def install_requirements(env_name, requirements_file):
    pip_path = f"{env_name}/bin/pip"
    subprocess.run([pip_path, "install", "-r", requirements_file])
```

## 🧪 Practice

### Exercise 1: Environment Setup Script
```python
import os
import subprocess
import sys

def setup_project(project_name):
    # Create project directory
    os.makedirs(project_name, exist_ok=True)

    # Create virtual environment
    env_path = os.path.join(project_name, "venv")
    subprocess.run([sys.executable, "-m", "venv", env_path])

    # Create basic files
    with open(os.path.join(project_name, "main.py"), "w") as f:
        f.write("print('Hello, World!')\n")

    with open(os.path.join(project_name, "requirements.txt"), "w") as f:
        f.write("# Add your dependencies here\n")

    print(f"Project {project_name} created!")
    print(f"To activate: source {env_path}/bin/activate")

setup_project("my_new_project")
```
