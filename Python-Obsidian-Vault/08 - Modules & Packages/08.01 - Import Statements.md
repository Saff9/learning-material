## Basic Import

```python
# Import entire module
import math
print(math.pi)
print(math.sqrt(16))

# Import specific items
from math import pi, sqrt
print(pi)
print(sqrt(16))

# Import with alias
import math as m
print(m.pi)

from math import pi as PI
print(PI)
```

## Import Patterns

```python
# Good: Import specific items
from datetime import datetime, timedelta

# Good: Import module with alias
import numpy as np
import pandas as pd

# Avoid: Import everything (pollutes namespace)
from math import *  # Don't do this!

# Good: Multiple imports
import os
import sys
import json

# Good: Grouped imports
from collections import (
    Counter,
    defaultdict,
    OrderedDict,
    deque
)
```

## How Imports Work

```python
# Python searches in this order:
# 1. Built-in modules
# 2. sys.path directories
#    - Current directory
#    - PYTHONPATH
#    - Installation-dependent defaults

import sys
print(sys.path)  # See the search path
```

## Conditional Import

```python
try:
    import json
except ImportError:
    import simplejson as json

# Platform-specific
import sys
if sys.platform == "win32":
    import winreg
else:
    import termios
```

## Dynamic Import

```python
# Using __import__
module_name = "math"
math = __import__(module_name)

# Using importlib
import importlib
math = importlib.import_module("math")

# Import from string
module = importlib.import_module("os.path")
```

### Exercise 2: Custom Import Function
```python
import importlib

def safe_import(module_name):
    try:
        module = importlib.import_module(module_name)
        print(f"Successfully imported {module_name}")
        return module
    except ImportError as e:
        print(f"Failed to import {module_name}: {e}")
        return None

json = safe_import("json")
nonexistent = safe_import("nonexistent_module")
```
