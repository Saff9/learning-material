## Basic Requirements File

```
# requirements.txt
requests
numpy
pandas
flask
```

## Version Specifiers

```
# Exact version
requests==2.28.1

# Minimum version
requests>=2.28.0

# Compatible release (same major version)
requests~=2.28.0

# Range
requests>=2.27.0,<3.0.0

# No version (latest)
requests
```

## Generating Requirements

```bash
# From current environment
pip freeze > requirements.txt

# More readable (without versions)
pip freeze | sed 's/==.*//' > requirements.txt
```

## Installing from Requirements

```bash
pip install -r requirements.txt

# With specific index
pip install -r requirements.txt --index-url https://pypi.org/simple
```

## Best Practices

```
# requirements.txt - Production dependencies
flask==2.3.0
requests==2.31.0

# requirements-dev.txt - Development dependencies
-r requirements.txt
pytest==7.4.0
black==23.7.0
flake8==6.1.0
```

## In Python

```python
import subprocess
import sys

def install_requirements(filename="requirements.txt"):
    try:
        subprocess.check_call([sys.executable, "-m", "pip", "install", "-r", filename])
        print(f"Installed from {filename}")
    except subprocess.CalledProcessError:
        print(f"Failed to install from {filename}")

install_requirements()
```

## 🧪 Practice

### Exercise 1: Parse Requirements
```python
def parse_requirements(filename):
    requirements = []
    with open(filename, "r") as f:
        for line in f:
            line = line.strip()
            if line and not line.startswith("#"):
                requirements.append(line)
    return requirements

reqs = parse_requirements("requirements.txt")
for req in reqs:
    print(req)
```
