## Parameters vs Arguments

```python
# Parameters: in function definition
def greet(name, greeting):  # name and greeting are parameters
    print(f"{greeting}, {name}!")

# Arguments: in function call
greet("Alice", "Hello")  # "Alice" and "Hello" are arguments
```

## Positional Arguments

```python
def describe_pet(animal, name):
    print(f"I have a {animal} named {name}.")

describe_pet("dog", "Buddy")  # Position matters!
```

## Keyword Arguments

```python
describe_pet(name="Whiskers", animal="cat")
describe_pet(animal="hamster", name="Nibbles")
```

## Default Parameters

```python
def greet(name, greeting="Hello", punctuation="!"):
    print(f"{greeting}, {name}{punctuation}")

greet("Alice")                           # Hello, Alice!
greet("Bob", "Hi")                       # Hi, Bob!
greet("Carol", punctuation=".")          # Hello, Carol.
```

## Important: Mutable Default Trap!

```python
# WRONG!
def append_item(item, my_list=[]):
    my_list.append(item)
    return my_list

print(append_item(1))  # [1]
print(append_item(2))  # [1, 2] - Surprise!

# CORRECT!
def append_item(item, my_list=None):
    if my_list is None:
        my_list = []
    my_list.append(item)
    return my_list
```

## Unpacking Arguments

```python
def add(a, b, c):
    return a + b + c

# Unpack list/tuple
nums = [1, 2, 3]
print(add(*nums))  # 6

# Unpack dictionary
vals = {"a": 1, "b": 2, "c": 3}
print(add(**vals))  # 6
```

## 🧪 Practice

### Exercise 1: Flexible Formatter
```python
def format_name(first, last, middle="", title=""):
    parts = [p for p in [title, first, middle, last] if p]
    return " ".join(parts)

print(format_name("John", "Doe"))                    # John Doe
print(format_name("John", "Doe", "Q", "Dr."))        # Dr. John Q Doe
```

### Exercise 2: Safe Average
```python
def safe_average(*numbers):
    if not numbers:
        return 0
    return sum(numbers) / len(numbers)

print(safe_average(1, 2, 3, 4, 5))  # 3.0
print(safe_average())                # 0
```
