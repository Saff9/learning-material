## Basic Lambda

```python
# Regular function
def add(x, y):
    return x + y

# Equivalent lambda
add = lambda x, y: x + y

print(add(3, 5))  # 8
```

## Common Uses

```python
# With sorted
words = ["banana", "pie", "Washington"]
sorted_by_length = sorted(words, key=lambda x: len(x))

# With map
numbers = [1, 2, 3, 4]
squares = list(map(lambda x: x**2, numbers))

# With filter
evens = list(filter(lambda x: x % 2 == 0, numbers))

# With reduce
from functools import reduce
product = reduce(lambda x, y: x * y, numbers)
```

## In-Place Usage

```python
students = [
    {"name": "Alice", "grade": 85},
    {"name": "Bob", "grade": 92},
    {"name": "Carol", "grade": 78}
]

# Sort by grade
top_student = max(students, key=lambda s: s["grade"])
print(top_student["name"])  # Bob
```

## 🧪 Practice

### Exercise 1: Sort by Last Name
```python
names = ["John Smith", "Alice Johnson", "Bob Williams"]
sorted_names = sorted(names, key=lambda x: x.split()[-1])
print(sorted_names)
```

### Exercise 2: Conditional Lambda
```python
# Not recommended for complex logic, but possible
grade_check = lambda score: "Pass" if score >= 60 else "Fail"
print(grade_check(75))  # Pass
```
