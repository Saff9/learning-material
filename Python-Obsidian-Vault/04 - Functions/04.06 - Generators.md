## Basic Generator

```python
def count_up_to(n):
    count = 1
    while count <= n:
        yield count
        count += 1

for num in count_up_to(5):
    print(num)  # 1, 2, 3, 4, 5
```

## Generator Expressions

```python
# List comprehension (creates full list)
squares_list = [x**2 for x in range(1000000)]

# Generator expression (lazy)
squares_gen = (x**2 for x in range(1000000))

# Can iterate without storing all
total = sum(x**2 for x in range(1000000))
```

## Infinite Generators

```python
def fibonacci():
    a, b = 0, 1
    while True:
        yield a
        a, b = b, a + b

fib = fibonacci()
for _ in range(10):
    print(next(fib))
```

## Generator Methods

```python
def echo():
    while True:
        received = yield
        print(f"Echo: {received}")

e = echo()
next(e)  # Prime the generator
e.send("Hello")  # Echo: Hello
e.close()
```

## 🧪 Practice

### Exercise 1: File Reader
```python
def read_lines(filename):
    with open(filename) as f:
        for line in f:
            yield line.strip()

for line in read_lines("data.txt"):
    print(line)
```

### Exercise 2: Paged Data
```python
def paginate(items, page_size):
    for i in range(0, len(items), page_size):
        yield items[i:i + page_size]

for page in paginate(range(25), 10):
    print(page)
```
