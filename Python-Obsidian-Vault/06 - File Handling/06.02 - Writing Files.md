## Basic File Writing

```python
# Write mode (overwrites existing file)
with open("output.txt", "w") as f:
    f.write("Hello, World!\n")
    f.write("Second line\n")

# Append mode (adds to existing file)
with open("log.txt", "a") as f:
    f.write("New log entry\n")
```

## Write Modes

```python
# "w" - Write (creates new or truncates existing)
with open("new.txt", "w") as f:
    f.write("Fresh start")

# "a" - Append (adds to end)
with open("existing.txt", "a") as f:
    f.write("Added at the end")

# "x" - Exclusive creation (fails if exists)
try:
    with open("must_be_new.txt", "x") as f:
        f.write("First and only")
except FileExistsError:
    print("File already exists!")

# "wb" - Write binary
with open("data.bin", "wb") as f:
    f.write(b"\x00\x01\x02")
```

## Writing Multiple Lines

```python
lines = ["First line", "Second line", "Third line"]

# Using writelines
with open("lines.txt", "w") as f:
    f.writelines(line + "\n" for line in lines)

# Using print (adds newline automatically)
with open("lines.txt", "w") as f:
    for line in lines:
        print(line, file=f)
```

## Formatting Output

```python
data = [
    {"name": "Alice", "age": 25},
    {"name": "Bob", "age": 30}
]

with open("people.txt", "w") as f:
    for person in data:
        f.write(f"{person['name']}: {person['age']}\n")
```

## 🧪 Practice

### Exercise 1: Logger Function
```python
from datetime import datetime

def log_message(filename, message):
    timestamp = datetime.now().strftime("%Y-%m-%d %H:%M:%S")
    with open(filename, "a") as f:
        f.write(f"[{timestamp}] {message}\n")

log_message("app.log", "Application started")
log_message("app.log", "User logged in")
```

### Exercise 2: Save Data
```python
def save_numbers(filename, numbers):
    with open(filename, "w") as f:
        for num in numbers:
            f.write(f"{num}\n")

def load_numbers(filename):
    with open(filename, "r") as f:
        return [int(line.strip()) for line in f]

save_numbers("numbers.txt", [1, 2, 3, 4, 5])
loaded = load_numbers("numbers.txt")
print(loaded)
```

### Exercise 3: Backup File
```python
import shutil

def backup_file(filename):
    backup_name = f"{filename}.backup"
    shutil.copy(filename, backup_name)
    print(f"Backup created: {backup_name}")

backup_file("important.txt")
```
