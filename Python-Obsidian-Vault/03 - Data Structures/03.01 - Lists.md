## Creating Lists

```python
# Empty list
empty = []

# With elements
fruits = ["apple", "banana", "cherry"]

# Mixed types
mixed = [1, "hello", 3.14, True]

# From other iterables
chars = list("hello")  # ['h', 'e', 'l', 'l', 'o']
numbers = list(range(5))  # [0, 1, 2, 3, 4]
```

## Indexing and Slicing

```python
items = [10, 20, 30, 40, 50]

# Indexing
print(items[0])    # 10
print(items[-1])   # 50 (last)
print(items[-2])   # 40 (second to last)

# Slicing [start:end:step]
print(items[1:4])    # [20, 30, 40]
print(items[:3])     # [10, 20, 30]
print(items[2:])     # [30, 40, 50]
print(items[::2])    # [10, 30, 50]
print(items[::-1])   # [50, 40, 30, 20, 10] (reversed)
```

## Modifying Lists

```python
# Append
fruits = ["apple"]
fruits.append("banana")  # ["apple", "banana"]

# Extend
fruits.extend(["cherry", "date"])  # Add multiple

# Insert
fruits.insert(1, "apricot")  # Insert at index

# Remove
fruits.remove("banana")  # Remove first occurrence

# Pop
last = fruits.pop()      # Remove and return last
first = fruits.pop(0)    # Remove and return at index

# Clear
fruits.clear()  # Remove all
```

## List Methods

```python
numbers = [3, 1, 4, 1, 5, 9, 2, 6]

# Sort (in-place)
numbers.sort()
numbers.sort(reverse=True)

# Sorted (returns new list)
ascending = sorted(numbers)

# Reverse
numbers.reverse()

# Count
print(numbers.count(1))  # 2

# Index
print(numbers.index(5))  # First occurrence

# Copy
copy = numbers.copy()
copy = numbers[:]  # Slice copy
copy = list(numbers)
```

## List Operations

```python
a = [1, 2, 3]
b = [4, 5, 6]

# Concatenation
c = a + b  # [1, 2, 3, 4, 5, 6]

# Repetition
d = a * 3  # [1, 2, 3, 1, 2, 3, 1, 2, 3]

# Membership
print(2 in a)  # True

# Length
print(len(a))  # 3
```

## 🧪 Practice

### Exercise 1: List Reversal
```python
def reverse_list(items):
    return items[::-1]

print(reverse_list([1, 2, 3, 4, 5]))
```

### Exercise 2: Remove Duplicates
```python
def remove_duplicates(items):
    return list(dict.fromkeys(items))

print(remove_duplicates([1, 2, 2, 3, 3, 3]))
```

### Exercise 3: Flatten List
```python
nested = [[1, 2], [3, 4], [5, 6]]
flat = [x for sublist in nested for x in sublist]
print(flat)
```

### Exercise 4: Find Second Largest
```python
def second_largest(numbers):
    unique = list(set(numbers))
    unique.sort()
    return unique[-2] if len(unique) >= 2 else None

print(second_largest([10, 20, 4, 45, 99]))
```
