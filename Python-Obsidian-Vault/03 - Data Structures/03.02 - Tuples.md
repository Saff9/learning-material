## Creating Tuples

```python
# Empty tuple
empty = ()

# With elements
point = (3, 4)

# Single element (note the comma!)
single = (5,)  # NOT (5) which is just 5

# Without parentheses
coordinates = 10, 20, 30

# From other iterables
chars = tuple("hello")  # ('h', 'e', 'l', 'l', 'o')
```

## Tuple Immutability

```python
t = (1, 2, 3)

# This will ERROR:
# t[0] = 10  # TypeError!

# But mutable elements CAN be modified:
t2 = ([1, 2], [3, 4])
t2[0].append(3)  # Works! t2 is now ([1, 2, 3], [3, 4])
```

## Tuple Operations

```python
a = (1, 2, 3)
b = (4, 5, 6)

# Concatenation
c = a + b  # (1, 2, 3, 4, 5, 6)

# Repetition
d = a * 2  # (1, 2, 3, 1, 2, 3)

# Membership
print(2 in a)  # True

# Indexing and slicing (same as lists)
print(a[0])    # 1
print(a[1:])   # (2, 3)
```

## Tuple Unpacking

```python
# Basic unpacking
x, y = (10, 20)

# Swapping variables
a, b = 5, 10
a, b = b, a  # a=10, b=5

# Extended unpacking
first, *rest = (1, 2, 3, 4, 5)
# first=1, rest=[2, 3, 4, 5]

first, *middle, last = (1, 2, 3, 4, 5)
# first=1, middle=[2, 3, 4], last=5

# Ignoring values
x, _, y = (10, 20, 30)  # x=10, y=30

# Multiple assignments
x, y, z = 1, 2, 3
```

## Named Tuples

```python
from collections import namedtuple

# Create a named tuple class
Point = namedtuple("Point", ["x", "y"])

# Create instances
p = Point(3, 4)
print(p.x)  # 3
print(p.y)  # 4

# Alternative syntax
Person = namedtuple("Person", "name age city")
alice = Person("Alice", 25, "NYC")
print(alice.name)  # Alice
```

### Exercise 1: Coordinate Swap
```python

x, y = y, x
print(f"x={x}, y={y}")
```

### Exercise 2: Function Multiple Returns
```python
def min_max(numbers):
    return min(numbers), max(numbers)

minimum, maximum = min_max([3, 1, 4, 1, 5])
print(f"Min: {minimum}, Max: {maximum}")
```

### Exercise 3: CSV Parser
```python
data = "Alice,25,NYC\nBob,30,LA"
for line in data.split("\n"):
    name, age, city = line.split(",")
    print(f"{name} lives in {city} and is {age}")
```

### Exercise 4: Named Tuple Records
```python
from collections import namedtuple

Book = namedtuple("Book", "title author year")

library = [
    Book("1984", "Orwell", 1949),
    Book("Dune", "Herbert", 1965),
]

for book in library:
    print(f"{book.title} by {book.author} ({book.year})")
```
