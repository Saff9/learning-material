## Creating Sets

```python
# Empty set (note: {} creates dict!)
empty = set()

# With elements
fruits = {"apple", "banana", "cherry"}

# From iterable
chars = set("hello")  # {'h', 'e', 'l', 'o'}

# Set comprehension
evens = {x for x in range(10) if x % 2 == 0}
```

## Set Properties

```python
# Unordered (no indexing!)
s = {3, 1, 2}
# print(s[0])  # ERROR!

# No duplicates
unique = {1, 1, 2, 2, 3}  # {1, 2, 3}

# Mutable
s = {1, 2, 3}
s.add(4)
s.remove(2)
```

## Set Operations

```python
a = {1, 2, 3, 4}
b = {3, 4, 5, 6}

# Union
print(a | b)        # {1, 2, 3, 4, 5, 6}
print(a.union(b))

# Intersection
print(a & b)        # {3, 4}
print(a.intersection(b))

# Difference
print(a - b)        # {1, 2}
print(a.difference(b))

# Symmetric Difference
print(a ^ b)        # {1, 2, 5, 6}
print(a.symmetric_difference(b))

# Subset/Superset
print(a <= b)       # False
print({1, 2} <= a)  # True
```

## Set Methods

```python
s = {1, 2, 3}

# Add single element
s.add(4)

# Add multiple
s.update([5, 6])

# Remove (raises KeyError if missing)
s.remove(2)

# Discard (no error if missing)
s.discard(10)

# Pop random element
elem = s.pop()

# Clear
s.clear()
```

### Exercise 3: Unique to Each
```python
a = {"apple", "banana", "cherry"}
b = {"banana", "cherry", "date"}

only_a = a - b
only_b = b - a
print(f"Only in A: {only_a}")
print(f"Only in B: {only_b}")
```

### Exercise 4: Vowel Check
```python
def has_all_vowels(text):
    vowels = set("aeiou")
    return vowels <= set(text.lower())

print(has_all_vowels("The quick brown fox"))  # False
print(has_all_vowels("Sequoia"))  # True
```
