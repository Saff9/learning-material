## 📖 What is Mounting?

**Mounting** attaches a filesystem to a directory (mount point), making it accessible.

```
Before mounting:
/
├── bin/
├── etc/
├── home/
└── mnt/          <- Empty or placeholder

After mounting /dev/sdb1 to /mnt/usb:
/
├── bin/
├── etc/
├── home/
└── mnt/          <- Now contains USB contents
    ├── photos/
    ├── documents/
    └── music/
```

## 🔧 Mount Commands

### View Mounted Filesystems

```bash
# List all mounts
mount

# Cleaner view
cat /proc/mounts

# Human-readable
df -h

# Show filesystem types
mount | grep type
```

### Manual Mount

```bash
# Mount a device
sudo mount /dev/sdb1 /mnt/usb

# Mount with specific filesystem
sudo mount -t ext4 /dev/sdb1 /mnt/usb

# Mount with options
sudo mount -o rw,noexec /dev/sdb1 /mnt/usb

# Unmount
sudo umount /mnt/usb
```

### Common Mount Options

| Option | Meaning |
|--------|---------|
| `rw` | Read-write |
| `ro` | Read-only |
| `noexec` | No execution |
| `nosuid` | No setuid |
| `nodev` | No device files |
| `auto` | Mount at boot |
| `noauto` | Don't mount at boot |
| `user` | Allow user mount |

## 🪟 WSL Mounts

### Windows Drive Mounts

```bash
# WSL automatically mounts Windows drives
ls /mnt/
# c/  d/  e/

# C: drive is mounted at
cat /proc/mounts | grep /mnt/c
# C:\134  /mnt/c  9p  rw,dirsync,...  0  0
```

### WSL Mount Options

```bash
# Check mount options for C: drive
mount | grep /mnt/c

# Typical WSL mount:
# - 9p filesystem (Plan 9 protocol)
# - rw (read-write)
# - noatime (don't update access times)
# - cache=none (no caching)
```

### Configuring WSL Mounts

Create `/etc/wsl.conf`:

```ini
[automount]
enabled = true
mountFsTab = true
root = /mnt/
options = "metadata,umask=22,fmask=11"
```

```bash
# After creating wsl.conf, restart WSL
wsl --shutdown
# Then reopen WSL
```

## 📋 /etc/fstab

The filesystem table defines mounts at boot.

```bash
# View fstab
cat /etc/fstab

# Example entries:
# <device>        <mount point>   <type>   <options>           <dump>  <pass>
# /dev/sda1       /               ext4     errors=remount-ro   0       1
# /dev/sda2       /home           ext4     defaults            0       2
# UUID=abc123     /mnt/data       ext4     defaults,noauto     0       0
```

### Fields Explained

| Field | Meaning | Example |
|-------|---------|---------|
| 1 | Device or UUID | `/dev/sda1` or `UUID=abc` |
| 2 | Mount point | `/` or `/home` |
| 3 | Filesystem type | `ext4`, `ntfs`, `vfat` |
| 4 | Options | `defaults`, `noauto` |
| 5 | Dump | `0` (ignore) or `1` (backup) |
| 6 | Pass (fsck order) | `0` (skip), `1` (root), `2` (others) |

## 🧪 Practice

```bash
# 1. View all mounted filesystems
mount | head -20

# 2. Check disk usage
df -h

# 3. Check WSL mounts specifically
mount | grep -E "(9p|wsl|/mnt)"

# 4. View fstab
cat /etc/fstab

# 5. Check filesystem type of current directory
df -T .

# 6. Check mount options for /mnt/c
findmnt /mnt/c
```
