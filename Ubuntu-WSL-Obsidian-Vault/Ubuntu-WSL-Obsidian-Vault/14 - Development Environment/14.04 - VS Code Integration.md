## 🔌 Remote WSL Extension

1. Install VS Code on Windows
2. Install "Remote - WSL" extension
3. In WSL, type: `code .`

VS Code will:
- Install VS Code Server in WSL
- Connect from Windows
- All extensions run in WSL

---

## 🚀 Opening Projects

```bash
# Open current directory
code .

# Open specific file
code file.txt

# Open specific directory
code /path/to/project
```

---

## ⚙️ Settings

```json
// In VS Code settings (Windows side)
{
    "remote.WSL.fileWatcher.polling": true,
    "remote.WSL.useShellServer": true
}
```

## 🧪 Practice

```bash
# 1. Create test project
mkdir -p ~/vscode-test
cd ~/vscode-test
touch hello.py

# 2. Open in VS Code
code .

# 3. Edit file in VS Code
# Add: print("Hello from WSL!")

# 4. Run from terminal
python3 hello.py
```
