## 📝 Basic Usage

```bash
# Run command as root
sudo apt update

# Run command as another user
sudo -u username command

# Edit file as root
sudo nano /etc/hosts

# Open root shell
sudo -i

# Run previous command with sudo
sudo !!
```

---

## ⚙️ sudo Configuration

```bash
# Edit sudoers (use visudo!)
sudo visudo
```

### sudoers File Examples

```bash
# Allow user full sudo access
username ALL=(ALL:ALL) ALL

# Allow without password
username ALL=(ALL) NOPASSWD: ALL

# Allow specific commands
username ALL=(ALL) /usr/bin/apt, /usr/bin/systemctl

# Allow group
%admin ALL=(ALL) ALL
```

---

## 🆚 sudo vs su

| Feature | sudo | su |
|---------|------|-----|
| Authentication | Your password | Target user's password |
| Default | Run one command | Switch to user shell |
| Logging | Yes | No |
| Granularity | Per-command | All or nothing |

---

## 🧪 Practice

```bash
# 1. Check sudo access
sudo -l

# 2. Run command as root
sudo whoami

# 3. Check sudo logs
sudo grep sudo /var/log/auth.log
```
