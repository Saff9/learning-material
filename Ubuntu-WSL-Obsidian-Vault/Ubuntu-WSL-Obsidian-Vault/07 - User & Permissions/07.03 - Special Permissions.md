# Special Permissions

## 🎯 What You'll Learn
- SUID (Set User ID)
- SGID (Set Group ID)
- Sticky Bit
- When and why to use them

---

## 🔴 SUID (Set User ID) — 4000

When set on an executable, it runs with the owner's privileges.

```bash
# Check for SUID files
find / -perm /4000 2>/dev/null

# Example: /usr/bin/passwd
ls -l /usr/bin/passwd
# -rwsr-xr-x 1 root root ...
#     ^
#     s = SUID set
```

**Use case:** passwd needs to modify /etc/shadow (owned by root), but regular users run it.

```bash
# Set SUID
chmod u+s file
chmod 4755 file

# Remove SUID
chmod u-s file
```

---

## 🟡 SGID (Set Group ID) — 2000

When set on a directory, new files inherit the directory's group.

```bash
# Check for SGID directories
find / -perm /2000 -type d 2>/dev/null

# Set SGID on directory
chmod g+s /shared/project
chmod 2775 /shared/project
```

**Use case:** Shared project directory where all files should belong to the project group.

---

## 🟢 Sticky Bit — 1000

When set on a directory, only the owner can delete their files.

```bash
# Check sticky bit
ls -ld /tmp
# drwxrwxrwt  ... /tmp
#          ^
#          t = sticky bit

# Set sticky bit
chmod +t /shared/directory
chmod 1777 /shared/directory
```

**Use case:** /tmp — anyone can write, but only delete their own files.

---

## 📊 Special Permission Summary

| Permission | Numeric | Symbol | On File | On Directory |
|------------|---------|--------|---------|--------------|
| SUID | 4000 | `s` in user | Run as owner | — |
| SGID | 2000 | `s` in group | Run as group | Inherit group |
| Sticky | 1000 | `t` in other | — | Restrict deletion |

## 🧪 Practice

```bash
# 1. Check special permissions
ls -l /usr/bin/passwd
ls -ld /tmp

# 2. Create test directory
mkdir ~/sticky-test
chmod 1777 ~/sticky-test

# 3. Create file as current user
touch ~/sticky-test/myfile.txt

# 4. Try to see sticky bit in action
ls -ld ~/sticky-test

# 5. Clean up
rm -rf ~/sticky-test
```
