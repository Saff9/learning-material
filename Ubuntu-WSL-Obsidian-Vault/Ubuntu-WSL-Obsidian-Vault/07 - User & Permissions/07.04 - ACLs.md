# Access Control Lists (ACLs)

## 🎯 What You'll Learn
- Extend permissions beyond owner/group/other
- Use setfacl and getfacl
- Understand when ACLs are needed

---

## 📖 Why ACLs?

Standard permissions only allow:
- One owner
- One group
- Everyone else

ACLs allow:
- Multiple users with different permissions
- Multiple groups with different permissions
- Default permissions for new files

---

## 🔧 Commands

```bash
# View ACLs
getfacl file.txt

# Set ACL for user
setfacl -m u:username:rwx file.txt

# Set ACL for group
setfacl -m g:groupname:rx file.txt

# Remove ACL for user
setfacl -x u:username file.txt

# Set default ACL (for new files in directory)
setfacl -d -m u:username:rx directory/

# Remove all ACLs
setfacl -b file.txt

# Recursive
setfacl -R -m u:username:rwx directory/
```

---

## 📋 Examples

```bash
# View current ACLs
getfacl file.txt

# Add user with read-write
setfacl -m u:bob:rw file.txt

# Add group with read-only
setfacl -m g:developers:r file.txt

# Check with ls
ls -l file.txt
# -rw-rw-r--+   <- + means ACLs exist
```

---

## 🧪 Practice

```bash
# 1. Install ACL tools
sudo apt install acl

# 2. Create test file
touch acl-test.txt

# 3. View default ACL
getfacl acl-test.txt

# 4. Add user ACL
sudo setfacl -m u:root:rw acl-test.txt

# 5. Verify
getfacl acl-test.txt

# 6. Clean up
rm acl-test.txt
```
