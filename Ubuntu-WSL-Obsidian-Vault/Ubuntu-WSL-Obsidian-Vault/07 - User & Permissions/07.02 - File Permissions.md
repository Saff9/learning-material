## 📖 Permission Basics

```bash
ls -l file.txt
# -rw-r--r-- 1 user group 1234 Jul 15 10:00 file.txt
```

```
-rw-r--r--
 |  |  |
 |  |  +-- Others permissions
 |  +----- Group permissions
 +-------- Owner permissions
```

### Permission Types

| Symbol | File | Directory |
|--------|------|-----------|
| `r` (4) | Read contents | List files |
| `w` (2) | Write/modify | Create/delete files |
| `x` (1) | Execute | Enter directory |

---

## 🔢 Numeric (Octal) Mode

| Value | Binary | Permissions |
|-------|--------|-------------|
| 0 | 000 | --- |
| 1 | 001 | --x |
| 2 | 010 | -w- |
| 3 | 011 | -wx |
| 4 | 100 | r-- |
| 5 | 101 | r-x |
| 6 | 110 | rw- |
| 7 | 111 | rwx |

### Common Permission Combinations

| Numeric | Symbolic | Meaning |
|---------|----------|---------|
| 777 | rwxrwxrwx | Everyone full access |
| 755 | rwxr-xr-x | Owner full, others read+execute |
| 644 | rw-r--r-- | Owner read+write, others read |
| 700 | rwx------ | Owner only |
| 600 | rw------- | Owner read+write only |

---

## 🔧 chmod — Change Permissions

```bash
# Numeric mode
chmod 755 script.sh
chmod 644 file.txt
chmod 600 secret.txt

# Symbolic mode
chmod u+x script.sh      # Add execute for owner
chmod go-w file.txt      # Remove write for group and others
chmod a+r file.txt       # Add read for all
chmod u=rwx,go=rx dir/   # Set exactly

# Recursive
chmod -R 755 directory/

# Reference file
chmod --reference=file1 file2
```

### Symbolic Mode Reference

| Who | Meaning |
|-----|---------|
| `u` | User (owner) |
| `g` | Group |
| `o` | Others |
| `a` | All (u+g+o) |

| Operator | Meaning |
|----------|---------|
| `+` | Add permission |
| `-` | Remove permission |
| `=` | Set exactly |

---

## 👤 chown — Change Ownership

```bash
# Change owner
sudo chown newuser file.txt

# Change group
sudo chown :newgroup file.txt

# Change both
sudo chown newuser:newgroup file.txt

# Recursive
sudo chown -R user:group directory/

# Reference file
sudo chown --reference=file1 file2
```

## 🧪 Practice

```bash
# 1. Create test file
touch permissions.txt

# 2. Check current permissions
ls -l permissions.txt

# 3. Make executable
chmod +x permissions.txt
ls -l permissions.txt

# 4. Set specific permissions
chmod 640 permissions.txt
ls -l permissions.txt

# 5. Change owner
sudo chown root permissions.txt
ls -l permissions.txt

# 6. Change back
sudo chown $USER permissions.txt

# 7. Clean up
rm permissions.txt
```
