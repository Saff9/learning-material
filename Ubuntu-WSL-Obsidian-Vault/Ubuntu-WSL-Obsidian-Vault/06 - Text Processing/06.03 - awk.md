# awk — Text Processing Language

## 🎯 What You'll Learn
- Process text with awk
- Use fields and patterns
- Perform calculations
- Write awk scripts

---

## 📝 Basic Syntax

```bash
awk 'pattern { action }' file
```

If pattern matches, action is executed.

---

## 📊 Fields

```bash
# Print first field
awk '{print $1}' file.txt

# Print second and third fields
awk '{print $2, $3}' file.txt

# Print all fields
awk '{print $0}' file.txt
# or just
awk '{print}' file.txt

# Use custom field separator
awk -F: '{print $1}' /etc/passwd

# Multiple separators
awk -F'[ :,' '{print $1}' file.txt

# Number of fields
awk '{print NF}' file.txt

# Last field
awk '{print $NF}' file.txt
```

---

## 🔍 Patterns

```bash
# Match lines containing "pattern"
awk '/pattern/' file.txt

# Match specific line number
awk 'NR==5' file.txt

# Match range of lines
awk 'NR>=5 && NR<=10' file.txt

# Match lines where field equals value
awk '$3 == "value"' file.txt

# Match lines where field contains pattern
awk '$2 ~ /pattern/' file.txt

# Match lines NOT containing pattern
awk '!/pattern/' file.txt

# BEGIN and END blocks
awk 'BEGIN {print "Start"} {print $0} END {print "Done"}' file.txt
```

---

## 🧮 Variables and Calculations

```bash
# Sum of a column
awk '{sum += $1} END {print sum}' numbers.txt

# Average
awk '{sum += $1; count++} END {print sum/count}' numbers.txt

# Min and max
awk 'NR==1 {min=max=$1} {if($1<min) min=$1; if($1>max) max=$1} END {print "Min:", min, "Max:", max}' numbers.txt

# Running total
awk '{total += $1; print $1, total}' numbers.txt
```

---

## 🔗 Built-in Variables

| Variable | Meaning |
|----------|---------|
| `$0` | Entire line |
| `$1-$NF` | Fields |
| `NF` | Number of fields |
| `NR` | Current record (line) number |
| `FNR` | Record number in current file |
| `FS` | Field separator (default: space) |
| `OFS` | Output field separator |
| `RS` | Record separator (default: newline) |
| `ORS` | Output record separator |
| `FILENAME` | Current filename |

## 🧪 Practice

```bash
# 1. Print usernames from /etc/passwd
awk -F: '{print $1}' /etc/passwd

# 2. Print lines longer than 80 characters
awk 'length($0) > 80' file.txt

# 3. Print every other line
awk 'NR % 2 == 0' file.txt

# 4. Sum of file sizes in directory
ls -l | awk '{sum += $5} END {print "Total bytes:", sum}'

# 5. Format output
awk '{printf "Name: %-10s Age: %3d\n", $1, $2}' people.txt

# 6. Count occurrences
awk '{count[$1]++} END {for(word in count) print word, count[word]}' words.txt
```
