# wc and nl

## 🎯 What You'll Learn
- Count lines, words, bytes with wc
- Number lines with nl
- Practical use cases

---

## 🔢 wc — Word Count

```bash
# Count lines, words, bytes
wc file.txt

# Count lines only
wc -l file.txt

# Count words only
wc -w file.txt

# Count bytes only
wc -c file.txt

# Count characters
wc -m file.txt

# Maximum line length
wc -L file.txt

# Multiple files
wc file1.txt file2.txt

# Total
wc -l *.txt
```

---

## 🔢 nl — Number Lines

```bash
# Number all lines
nl file.txt

# Number non-empty lines (default)
nl file.txt

# Number all lines including empty
nl -ba file.txt

# Number only lines with text
nl -bt file.txt

# Use custom format
nl -n rz file.txt  # Right-aligned with zeros

# Set starting number
nl -v 10 file.txt

# Set increment
nl -i 5 file.txt

# Use custom separator
nl -s '. ' file.txt
```

---

## 🧪 Practice

```bash
# 1. Count lines in /etc/passwd
wc -l /etc/passwd

# 2. Count files in directory
ls | wc -l

# 3. Number lines in file
nl file.txt

# 4. Count words in all .txt files
wc -w *.txt
```
