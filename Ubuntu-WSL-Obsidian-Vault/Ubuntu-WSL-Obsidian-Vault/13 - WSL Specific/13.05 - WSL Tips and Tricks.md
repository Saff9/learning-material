## ⚡ Performance Tips

### 1. Keep Projects in WSL

```bash
# FAST
/home/you/projects

# SLOW
/mnt/c/Users/you/projects
```

### 2. Use Git in WSL, Not Windows

```bash
# In WSL
git clone https://github.com/user/repo.git ~/projects/repo
```

### 3. Disable Windows PATH if Not Needed

```ini
# /etc/wsl.conf
[interop]
appendWindowsPath = false
```

### 4. Limit Memory

```ini
# .wslconfig
[wsl2]
memory=6GB
```

## 🔧 Useful Workflows

### Open VS Code from WSL

```bash
# In project directory
code .

# Or specific file
code file.txt
```

### Use Windows Git Credentials

```bash
# Configure Git to use Windows credential manager
git config --global credential.helper "/mnt/c/Program\\ Files/Git/mingw64/bin/git-credential-manager.exe"
```

### Docker Integration

```bash
# Docker Desktop with WSL2 backend
# Just install Docker Desktop, enable WSL2 backend
# Then in WSL:
docker ps
docker run hello-world
```

## 🧪 Hidden Features

```bash
# WSL version
wsl --version

# Export/import distros
wsl --export Ubuntu C:\backup\ubuntu.tar
wsl --import UbuntuNew C:\WSL\UbuntuNew C:\backup\ubuntu.tar

# Terminate specific distro
wsl -t Ubuntu

# Run command without entering shell
wsl -e bash -c "echo Hello from WSL"

# Use specific user
wsl -u root
```
