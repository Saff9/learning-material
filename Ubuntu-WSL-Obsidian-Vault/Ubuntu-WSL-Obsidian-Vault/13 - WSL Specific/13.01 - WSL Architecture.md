## 🏗️ WSL1 Architecture

```
Windows Kernel
    |
    +-- LXSS Manager (Translation Layer)
          |
          +-- Ubuntu
                |
                +-- bash, ls, grep, etc.
```

**How it works:**
- Translates Linux system calls to Windows NT kernel calls
- No real Linux kernel
- Files stored on Windows filesystem

**Pros:**
- Fast file access (Windows files)
- Low memory overhead
- No VM boot time

**Cons:**
- Not all Linux apps work
- No Docker natively
- Some system calls fail

---

## 🏗️ WSL2 Architecture

```
Windows Host
    |
    +-- Hyper-V
          |
          +-- Lightweight VM
                |
                +-- Real Linux Kernel
                      |
                      +-- Ubuntu
                            |
                            +-- bash, ls, grep, etc.
```

**How it works:**
- Runs real Linux kernel in lightweight VM
- Uses virtual hard disk (ext4)
- 9P protocol for Windows filesystem access

**Pros:**
- Full Linux compatibility
- Native Docker support
- Fast Linux filesystem operations

**Cons:**
- Slower Windows file access
- Uses more memory
- ~1 second boot time

---

## 📊 Comparison

| Feature | WSL1 | WSL2 |
|---------|------|------|
| Kernel | Translation | Real Linux |
| Boot | Instant | ~1 second |
| Linux compat | ~90% | 100% |
| Windows file access | Fast | Slow |
| Linux file access | Slow | Fast |
| Memory | Shared | Dynamic allocation |
| Docker | Desktop only | Native |
| Networking | Shared | Virtual NAT |

## 🧪 Practice

```bash
# Check your WSL version
wsl -l -v

# Convert distro
wsl --set-version Ubuntu 2

# Set default
wsl --set-default-version 2
```
