# Debugging Commands

## 🎯 What You'll Learn
- Trace system calls
- Check kernel messages
- List open files

---

## 🔍 strace — System Call Tracer

```bash
# Trace a command
strace ls

# Trace specific calls
strace -e open,read,write ls

# Trace a running process
sudo strace -p 1234

# Save to file
strace -o output.txt ls

# Count calls
strace -c ls
```

---

## 📋 dmesg — Kernel Messages

```bash
# View all messages
dmesg

# Human-readable timestamps
dmesg -T

# Follow new messages
dmesg -w

# Filter by level
dmesg -l err

# Clear buffer
sudo dmesg -C
```

---

## 📂 lsof — List Open Files

```bash
# All open files
sudo lsof

# Files by process
lsof -p 1234

# Processes using file
lsof /path/to/file

# Network connections
lsof -i
lsof -i :80

# Files by user
lsof -u username
```

---

## 🧪 Practice

```bash
# 1. Trace ls
strace -e trace=openat ls

# 2. Check kernel errors
dmesg | grep -i error

# 3. Check what's using port 80
sudo lsof -i :80
```
