# Background and Foreground

## 🎯 What You'll Learn
- Run processes in background
- Switch between foreground and background
- Understand job control
- Use screen and tmux

---

## 🚀 Background Execution

```bash
# Run in background
command &

# Example
sleep 10 &
```

---

## 🔄 Switching

```bash
# Suspend foreground process
Ctrl+Z

# List jobs
jobs

# Bring to foreground
fg %1

# Send to background
bg %1
```

---

## 🖥️ screen — Terminal Multiplexer

```bash
# Install
sudo apt install screen

# New session
screen

# Detach: Ctrl+A, D

# List sessions
screen -ls

# Reattach
screen -r

# Named session
screen -S mysession
```

---

## 🖥️ tmux — Modern Multiplexer

```bash
# Install
sudo apt install tmux

# New session
tmux

# Detach: Ctrl+B, D

# List sessions
tmux ls

# Reattach
tmux attach

# Named session
tmux new -s mysession
```

### tmux Prefix: Ctrl+B

| Key | Action |
|-----|--------|
| `d` | Detach |
| `c` | New window |
| `n` | Next window |
| `p` | Previous window |
| `%` | Split vertically |
| `"` | Split horizontally |
| `o` | Next pane |
| `?` | Help |
