## 📖 Process Basics

A **process** is a running instance of a program.

```bash
# Every process has:
# - PID (Process ID)
# - PPID (Parent Process ID)
# - UID (User ID who started it)
# - State (running, sleeping, etc.)
```

---

## 🔍 Viewing Process Info

```bash
# Current shell's PID
echo $$

# Process tree
pstree

# Detailed process info
ps -f -p $$
```

---

## 🌳 Process Hierarchy

```
init/systemd (PID 1)
    |
    +-- sshd
    |     +-- sshd (user session)
    |           +-- bash
    |                 +-- nano
    |
    +-- cron
    +-- nginx
          +-- worker processes
```

---

## 📊 Process States

| State | Meaning |
|-------|---------|
| R | Running |
| S | Sleeping (interruptible) |
| D | Sleeping (uninterruptible) |
| T | Stopped |
| Z | Zombie |
| I | Idle |
