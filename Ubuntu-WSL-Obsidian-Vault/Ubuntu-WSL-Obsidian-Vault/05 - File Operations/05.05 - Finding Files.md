## 🔍 find — The Ultimate Search Tool

```bash
# Find by name
find /path -name "file.txt"

# Find by name (case-insensitive)
find /path -iname "File.Txt"

# Find by type
find /path -type f          # Files
find /path -type d          # Directories
find /path -type l          # Symbolic links

# Find by size
find /path -size +100M      # Larger than 100MB
find /path -size -1k        # Smaller than 1KB
find /path -size 10M        # Exactly 10MB

# Find by modification time
find /path -mtime -7        # Modified in last 7 days
find /path -mtime +30       # Modified more than 30 days ago
find /path -mmin -60        # Modified in last 60 minutes

# Find by access time
find /path -atime +90       # Not accessed in 90 days

# Find empty files/directories
find /path -empty

# Find by permissions
find /path -perm 644
find /path -perm /u=s       # SUID files

# Find by owner
find /path -user username
find /path -group groupname
```

### find Actions

```bash
# Execute command on found files
find /path -name "*.log" -exec rm {} \;

# Execute with multiple files at once
find /path -name "*.log" -exec rm {} +

# Execute with confirmation
find /path -name "*.tmp" -ok rm {} \;

# Print with details
find /path -name "*.txt" -ls

# Print only filenames
find /path -name "*.txt" -print

# Limit depth
find /path -maxdepth 2 -name "*.txt"

# Exclude directories
find /path -name "*.txt" -not -path "*/node_modules/*"
```

### find Logical Operators

```bash
# AND (default)
find /path -name "*.txt" -size +1M

# OR
find /path -name "*.txt" -o -name "*.md"

# NOT
find /path -not -name "*.tmp"
find /path ! -name "*.tmp"

# Group with parentheses (escape them!)
find /path \( -name "*.txt" -o -name "*.md" \) -size +1M
```

## ⚡ locate — Fast Database Search

```bash
# Update database (run periodically)
sudo updatedb

# Search for files
locate filename

# Case-insensitive
locate -i filename

# Show existing files only
locate -e filename

# Show count
locate -c filename

# Limit results
locate -n 10 filename
```

> **Pros:** Extremely fast
> **Cons:** Database may be outdated; doesn't search in real-time

## 📍 which — Find Command Location

```bash
# Find where a command is located
which ls
# /usr/bin/ls

which python3
# /usr/bin/python3

# Show all locations
which -a python

# Check if command exists
which git && echo "Git is installed"
```

---

## 📍 whereis — Find Binary, Source, and Man Pages

```bash
# Find all related files
whereis ls
# ls: /usr/bin/ls /usr/share/man/man1/ls.1.gz

# Find only binary
whereis -b ls

# Find only man page
whereis -m ls

# Find only source
whereis -s ls
```

## 🆚 Comparison

| Tool | Speed | Scope | Use Case |
|------|-------|-------|----------|
| `find` | Slow (real-time) | Any criteria | Complex searches |
| `locate` | Fast (database) | Name only | Quick name search |
| `which` | Instant | Commands in PATH | Find command location |
| `whereis` | Instant | Commands | Find binary/man/source |

## 🧪 Practice

```bash
# 1. Find all .txt files in home
find ~ -name "*.txt" 2>/dev/null

# 2. Find large files (>100MB)
find / -size +100M 2>/dev/null | head -10

# 3. Find files modified today
find . -mtime -1 -type f

# 4. Find and delete old log files
find /var/log -name "*.log" -mtime +30
# Then if correct:
# find /var/log -name "*.log" -mtime +30 -delete

# 5. Quick locate
locate bashrc

# 6. Find command location
which python3
whereis python3

# 7. Find empty directories
find . -type d -empty

# 8. Find SUID files (security check)
find / -perm /4000 2>/dev/null
```
