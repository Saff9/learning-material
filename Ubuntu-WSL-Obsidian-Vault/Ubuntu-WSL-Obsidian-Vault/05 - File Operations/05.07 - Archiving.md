## 📦 tar — Tape Archive

```bash
# Create archive
tar -cvf archive.tar files/

# Extract archive
tar -xvf archive.tar

# Create compressed archive (gzip)
tar -czvf archive.tar.gz files/

# Extract compressed archive
tar -xzvf archive.tar.gz

# List contents
tar -tvf archive.tar

# Extract specific file
tar -xvf archive.tar path/to/file
```

### tar Options

| Option | Meaning |
|--------|---------|
| `-c` | Create archive |
| `-x` | Extract archive |
| `-t` | List contents |
| `-v` | Verbose |
| `-f` | Specify filename |
| `-z` | Compress with gzip |
| `-j` | Compress with bzip2 |
| `-J` | Compress with xz |
| `-C` | Change to directory |
| `-p` | Preserve permissions |
| `--exclude` | Exclude files |

### Modern tar Syntax

```bash
# Create (auto-detect compression)
tar caf archive.tar.gz files/

# Extract (auto-detect compression)
tar xaf archive.tar.gz

# Create with xz (best compression)
tar cJf archive.tar.xz files/

# Create with bzip2
tar cjf archive.tar.bz2 files/
```

### tar Examples

```bash
# Archive current directory
tar czvf backup.tar.gz .

# Archive with exclusion
tar czvf backup.tar.gz --exclude='node_modules' --exclude='.git' .

# Extract to specific directory
tar xzvf archive.tar.gz -C /destination/

# Archive multiple directories
tar czvf backup.tar.gz /home/user/docs /home/user/pictures

# Incremental backup
tar czvf backup.tar.gz --listed-incremental=snapshot.snar files/
```

## 🗜️ gzip — Compression

```bash
# Compress file
gzip file.txt
# Creates file.txt.gz, removes original

# Decompress
gunzip file.txt.gz
# or
gzip -d file.txt.gz

# Keep original
gzip -k file.txt

# Compress with best ratio
gzip -9 file.txt

# Compress with speed
gzip -1 file.txt

# Test integrity
gzip -t file.txt.gz

# View compressed file without decompressing
zcat file.txt.gz
zless file.txt.gz
zgrep "pattern" file.txt.gz
```

---

## 🗜️ bzip2 — Better Compression

```bash
# Compress
bzip2 file.txt

# Decompress
bunzip2 file.txt.bz2

# Keep original
bzip2 -k file.txt

# View without decompressing
bzcat file.txt.bz2
```

---

## 🗜️ xz — Best Compression

```bash
# Compress
xz file.txt

# Decompress
unxz file.txt.xz

# Keep original
xz -k file.txt

# View without decompressing
xzcat file.txt.xz
```

## 📁 zip — ZIP Archives

```bash
# Create zip
zip archive.zip file1.txt file2.txt

# Create zip from directory
zip -r archive.zip directory/

# Extract zip
unzip archive.zip

# Extract to directory
unzip archive.zip -d /destination/

# List contents
unzip -l archive.zip

# Update zip
zip -u archive.zip newfile.txt

# Delete from zip
zip -d archive.zip file.txt

# Encrypt
zip -e secure.zip file.txt
```

## 📊 Compression Comparison

| Tool | Extension | Speed | Compression | Use Case |
|------|-----------|-------|-------------|----------|
| gzip | .gz | Fast | Good | General purpose |
| bzip2 | .bz2 | Medium | Better | Archives |
| xz | .xz | Slow | Best | Distribution |
| zip | .zip | Fast | Good | Windows compatibility |

## 🧪 Practice

```bash
# 1. Create test files
mkdir -p ~/archive-test/{dir1,dir2}
echo "content1" > ~/archive-test/dir1/file1.txt
echo "content2" > ~/archive-test/dir2/file2.txt

# 2. Create tar.gz
tar czvf ~/archive-test.tar.gz ~/archive-test/

# 3. List contents
tar tzvf ~/archive-test.tar.gz

# 4. Extract to temp
tar xzvf ~/archive-test.tar.gz -C /tmp/

# 5. Compress with different tools
gzip -k ~/archive-test/dir1/file1.txt
bzip2 -k ~/archive-test/dir1/file1.txt
xz -k ~/archive-test/dir1/file1.txt

# 6. Compare sizes
ls -lh ~/archive-test/dir1/file1.txt*

# 7. Create zip
zip -r ~/archive-test.zip ~/archive-test/

# 8. Clean up
rm -rf ~/archive-test ~/archive-test.tar.gz ~/archive-test.zip /tmp/home
```
