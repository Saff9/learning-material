# Copying and Moving Files

## 🎯 What You'll Learn
- Copy files and directories with cp
- Move and rename with mv
- Use rsync for advanced copying
- Understand when to use each tool

---

## 📋 cp — Copy

```bash
# Copy file
cp source.txt dest.txt

# Copy to directory
cp file.txt /backup/

# Copy multiple files
cp file1.txt file2.txt /backup/

# Copy directory (recursive)
cp -r source_dir/ dest_dir/

# Copy with verbose output
cp -v file.txt /backup/

# Preserve attributes (permissions, timestamps)
cp -p file.txt /backup/

# Copy and overwrite without prompting
cp -f file.txt /backup/

# Copy and prompt before overwrite
cp -i file.txt /backup/
```

### cp Options

| Option | Short | Meaning |
|--------|-------|---------|
| `--recursive` | `-r` | Copy directories recursively |
| `--verbose` | `-v` | Show what's being copied |
| `--preserve` | `-p` | Preserve mode, ownership, timestamps |
| `--force` | `-f` | Overwrite without prompting |
| `--interactive` | `-i` | Prompt before overwrite |
| `--update` | `-u` | Copy only if source is newer |
| `--backup` | `-b` | Make backup of existing destination |

### Advanced cp

```bash
# Copy only newer files
cp -u source.txt dest.txt

# Copy with backup
cp -b file.txt /backup/
# Creates file.txt~ as backup

# Copy and create directories as needed
cp --parents dir/file.txt /backup/
# Creates /backup/dir/file.txt

# Copy with progress (using pv)
pv source.iso | cp /dev/stdin dest.iso
```

## 🚚 mv — Move and Rename

```bash
# Rename file
mv oldname.txt newname.txt

# Move file to directory
mv file.txt /backup/

# Move multiple files
mv file1.txt file2.txt /backup/

# Move directory
mv source_dir/ /destination/

# Prompt before overwrite
mv -i file.txt /backup/

# Don't overwrite existing
mv -n file.txt /backup/

# Force overwrite
mv -f file.txt /backup/
```

### mv Options

| Option | Meaning |
|--------|---------|
| `-i` | Interactive (prompt before overwrite) |
| `-n` | No clobber (don't overwrite) |
| `-f` | Force (overwrite without prompting) |
| `-v` | Verbose |
| `-u` | Update (move only if source is newer) |

## 🔄 rsync — Advanced Copying

rsync is the ultimate file copying tool. It's fast, efficient, and powerful.

```bash
# Basic sync (local)
rsync -av source/ dest/

# Sync to remote server
rsync -av source/ user@server:/path/

# Sync from remote server
rsync -av user@server:/path/ local/

# Dry run (show what would happen)
rsync -avn source/ dest/

# Delete files in dest that don't exist in source
rsync -av --delete source/ dest/

# Exclude files
rsync -av --exclude='*.tmp' source/ dest/

# Show progress
rsync -av --progress source/ dest/

# Compress during transfer
rsync -avz source/ user@server:/path/
```

### rsync Options

| Option | Meaning |
|--------|---------|
| `-a` | Archive mode (recursive, preserve permissions, etc.) |
| `-v` | Verbose |
| `-n` | Dry run |
| `-z` | Compress during transfer |
| `-P` | Show progress and resume partial transfers |
| `--delete` | Delete extraneous files in destination |
| `--exclude` | Exclude files matching pattern |
| `--include` | Include files matching pattern |

### rsync Trailing Slash

```bash
# IMPORTANT: Trailing slash matters!

# Copy CONTENTS of source into dest/
rsync -av source/ dest/
# Result: dest/file1, dest/file2

# Copy source DIRECTORY into dest/
rsync -av source dest/
# Result: dest/source/file1, dest/source/file2
```

## 🆚 cp vs mv vs rsync

| Task | Tool | Why |
|------|------|-----|
| Simple file copy | `cp` | Simple, fast |
| Rename file | `mv` | Atomic operation |
| Move file | `mv` | Fast (same filesystem) |
| Copy directory | `cp -r` or `rsync` | Recursive |
| Backup/sync | `rsync` | Incremental, resume, remote |
| Large file copy | `rsync -P` | Resume if interrupted |
| Mirror directories | `rsync --delete` | Exact copy |

## 🧪 Practice

```bash
# 1. Create test structure
mkdir -p ~/copy-test/{source,dest}
touch ~/copy-test/source/{a,b,c}.txt
echo "content" > ~/copy-test/source/a.txt

# 2. Copy a file
cp ~/copy-test/source/a.txt ~/copy-test/dest/

# 3. Copy directory
cp -r ~/copy-test/source/ ~/copy-test/dest2/

# 4. Rename file
mv ~/copy-test/dest/a.txt ~/copy-test/dest/alpha.txt

# 5. Move file
mv ~/copy-test/dest/alpha.txt ~/copy-test/source/

# 6. rsync with dry run
rsync -avn ~/copy-test/source/ ~/copy-test/dest/

# 7. Actually rsync
rsync -av ~/copy-test/source/ ~/copy-test/dest/

# 8. Clean up
rm -rf ~/copy-test
```
