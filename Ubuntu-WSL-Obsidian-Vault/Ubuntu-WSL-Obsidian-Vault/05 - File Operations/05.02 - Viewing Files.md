## 🐱 cat — Concatenate and Display

```bash
# Display file content
cat file.txt

# Display multiple files
cat file1.txt file2.txt

# Concatenate files
cat file1.txt file2.txt > combined.txt

# Number lines
cat -n file.txt

# Show non-printing characters
cat -A file.txt
# $ = end of line
# ^I = tab
# ^M = Windows line ending
```

### cat Options

| Option | Meaning |
|--------|---------|
| `-n` | Number all lines |
| `-b` | Number non-empty lines |
| `-s` | Squeeze multiple blank lines |
| `-E` | Show $ at end of lines |
| `-T` | Show tabs as ^I |
| `-A` | Show all non-printing (equivalent to -vET) |

> **Tip:** Don't use cat for large files! Use less instead.

## 📖 less — Page Through Files

```bash
# View file with less
less file.txt

# View with line numbers
less -N file.txt

# Start at line 100
less +100 file.txt

# Search from start
less +/pattern file.txt
```

### less Navigation

| Key | Action |
|-----|--------|
| `Space` or `Page Down` | Next page |
| `Page Up` or `b` | Previous page |
| `Down` or `j` | Next line |
| `Up` or `k` | Previous line |
| `g` | Go to beginning |
| `G` | Go to end |
| `/pattern` | Search forward |
| `?pattern` | Search backward |
| `n` | Next match |
| `N` | Previous match |
| `q` | Quit |
| `h` | Help |

### less Advantages

- Doesn't load entire file into memory
- Can scroll backward
- Search within file
- Works with pipes: `command | less`

## 📄 more — Simple Pager

```bash
more file.txt
```

**Navigation:**
- `Space` — Next page
- `Enter` — Next line
- `q` — Quit

> less is more! Use `less` instead of `more` — it's more powerful.

## 🔝 head — First Lines

```bash
# Show first 10 lines (default)
head file.txt

# Show first 5 lines
head -n 5 file.txt
head -5 file.txt

# Show first 20 bytes
head -c 20 file.txt

# Show first lines of multiple files
head file1.txt file2.txt

# With multiple files, show headers
head -n 5 file1.txt file2.txt
```

---

## 🔚 tail — Last Lines

```bash
# Show last 10 lines (default)
tail file.txt

# Show last 5 lines
tail -n 5 file.txt
tail -5 file.txt

# Show last 20 bytes
tail -c 20 file.txt

# Follow file (real-time updates)
tail -f /var/log/syslog

# Follow with retry (file may not exist yet)
tail -F /var/log/app.log

# Show lines starting from line 100
tail -n +100 file.txt
```

### tail -f (Follow)

```bash
# Watch log file in real-time
tail -f /var/log/syslog

# Watch multiple files
tail -f /var/log/syslog /var/log/auth.log

# Follow and grep
tail -f /var/log/syslog | grep "error"
```

> Press `Ctrl+C` to stop following.

## 🔍 grep — Search in Files

```bash
# Search for pattern
grep "pattern" file.txt

# Case-insensitive
grep -i "pattern" file.txt

# Invert match (lines NOT matching)
grep -v "pattern" file.txt

# Show line numbers
grep -n "pattern" file.txt

# Count matches
grep -c "pattern" file.txt

# Show context (2 lines before and after)
grep -C 2 "pattern" file.txt

# Recursive search
grep -r "pattern" /directory/

# Search multiple patterns
grep -E "pattern1|pattern2" file.txt

# Only matching part
grep -o "pattern" file.txt
```

> For more on grep, see [[06 - Text Processing/06.01 - grep]]

## 🧪 Practice

```bash
# 1. Create a test file
cat > test.txt << 'EOF'
Line 1: Introduction
Line 2: Getting Started
Line 3: Basics
Line 4: Intermediate
Line 5: Advanced
Line 6: Conclusion
EOF

# 2. View with cat
cat test.txt

# 3. View with less
less test.txt

# 4. First 3 lines
head -3 test.txt

# 5. Last 3 lines
tail -3 test.txt

# 6. Search for "Basics"
grep "Basics" test.txt

# 7. Watch a log file (in another terminal, write to it)
tail -f test.txt
# Then in another terminal: echo "New line" >> test.txt

# 8. Clean up
rm test.txt
```
