- **Database / ORM**: PostgreSQL 16+ (`pgvector`, PgBouncer) & SQLAlchemy 2.0 (`Mapped`, `mapped_column`, `db.session.get()`)

- **DevOps & Linux**: Ubuntu WSL2, Zsh/Tmux, Systemd, Nginx, Docker, Gunicorn, Pytest
